# 00 · 总览

> 本系列是 **Claude Code**（Anthropic 出品的终端 agentic 编码工具）的系统使用笔记，覆盖安装、登录与 API Key、基本使用、配置与权限、插件、MCP、子代理、四种 IDE 集成，以及故障排查。
> 每篇都按"先讲原理（why）再讲实操（how）"组织，Windows / Linux / macOS 三平台对照。
> 假设读者：会用终端、写过代码，但不一定用过 Claude Code。
> 资料核实时间 **2026-06**，Claude Code 处于 **v2.x**;迭代很快，命令与默认值以 `claude doctor` 和官方文档 `code.claude.com/docs` 为准。

## 1. Claude Code 是什么

Claude Code 是一个**活在终端里的 agentic 编码助手**:你用自然语言描述意图,它自己读代码、改文件、跑命令、查文档、提交 git——不是补全片段,而是端到端完成任务。

与"编辑器里的补全插件"的本质区别:

| 维度 | 传统补全(Copilot 式) | Claude Code |
|---|---|---|
| 交互单位 | 一行/一个函数 | 一个任务(可跨多文件、多步骤) |
| 主动性 | 你打字它补 | 它自己决定读哪些文件、跑哪些命令 |
| 工具能力 | 仅文本生成 | 能执行 Bash、编辑文件、联网、调 MCP 工具 |
| 运行位置 | 编辑器内 | 终端为主,IDE/CI/SDK 为辅 |

> 一句话:**Claude Code 把 LLM 从"会写字的人"变成"会动手的工程伙伴"。**

它能做:理解陌生代码库、实现功能、修 bug、写测试、重构、查官方文档、管理 git、跑构建与排错。它的边界:仍是概率模型,会犯错、会过度自信——所以**权限系统、计划模式、hooks** 这套"纪律设施"才是用好它的关键(见后续各篇)。

## 2. 四种工作形态

```
┌─────────────────────────────────────────────┐
│  Claude Code 同一套引擎,四种用法              │
├─────────────────────────────────────────────┤
│  ① CLI 交互模式   claude            ← 最常用  │
│  ② CLI 无头模式   claude -p "..."   ← 脚本/CI │
│  ③ IDE 集成       VS Code / JetBrains 扩展    │
│  ④ Agent SDK      在你自己的程序里编排         │
└─────────────────────────────────────────────┘
```

- **① 交互模式**:终端里跑 `claude`,进入对话式会话。本系列默认讲这种。
- **② 无头/print 模式**:`claude -p "提交前跑测试并总结"`,一次性输出后退出,适合脚本、CI、管道。
- **③ IDE 集成**:在 VS Code / JetBrains / Cursor / Windsurf 里用图形界面看 diff、共享选区。见 [[91.Claude Code/08-IDE-VSCode.md]] 起四篇。
- **④ Agent SDK**:把 Claude Code 的能力嵌入你自己的应用(本系列不展开,属编程接口)。

## 3. 接入方式速览

用 Claude Code 必须先"喂"它一个能调用 Claude 模型的凭证。四条路,任选其一:

| 接入方式 | 凭证 | 计费 | 适合 | 详见 |
|---|---|---|---|---|
| **订阅登录** | Pro / Max 账号(OAuth) | 包月固定 | 个人日常,最省心 | [[91.Claude Code/02-登录与API-Key.md]] |
| **Anthropic API Key** | `ANTHROPIC_API_KEY` | 按 token 用量 | 重度/团队/可编程 | 同上 |
| **第三方中转** | `ANTHROPIC_BASE_URL` + Token | 取决于服务商 | 用代理/中转网关 | 同上 |
| **企业云网关** | Amazon Bedrock / Google Vertex | 走云账单 | 企业合规部署 | 同上 |

> 免费版 Claude.ai 账号**不含** Claude Code,必须 Pro / Max / Team / Enterprise / Console 之一。

## 4. 模型速览

Claude Code 用 `--model` 或 `/model` 选模型,接受**别名**或**完整 model id**:

| 别名 | 当前指向(2026-06) | 定位 |
|---|---|---|
| `opus` | Claude Opus 4.x(如 `claude-opus-4-8`) | 最强,复杂任务/疑难调试 |
| `sonnet` | Claude Sonnet 4.x(如 `claude-sonnet-4-6`) | 均衡,日常主力 |
| `haiku` | Claude Haiku 4.5(`claude-haiku-4-5`) | 最快最省,轻量/子代理 |

要点:

- 完整 id **不要**自己拼日期后缀(用 `claude-opus-4-8`,不是 `claude-opus-4-8-20xxxxxx`)。
- Claude Code 默认 **effort = xhigh**(思考深度档位),这是它在编码任务上强的原因之一。
- 还有更强的 `claude-fable-5`(1M 上下文,顶配),按需选用。
- **定价随官方调整,本系列不写死数字**,以 Anthropic 官网价格页为准。

## 5. 核心概念地图

Claude Code 的"可配置面"由这几块拼成,后续各篇逐一展开:

```
                    ┌──────────────┐
                    │   你的意图    │
                    └──────┬───────┘
        ┌──────────────────┼──────────────────┐
        ▼                  ▼                  ▼
   CLAUDE.md          斜杠命令            权限系统
   (记忆/规则)        (/ 触发的动作)      (allow/deny/ask)
        │                  │                  │
        └────────► LLM 推理循环 ◄─────────────┘
                    │   │   │
        ┌───────────┘   │   └────────────┐
        ▼               ▼                ▼
      MCP            子代理(subagent)    hooks
   (外部工具)       (并行/隔离上下文)   (确定性自动化)
        │               │                │
        └──── 插件(plugin)把以上打包分发 ─┘
```

| 概念 | 一句话 | 详见 |
|---|---|---|
| **CLAUDE.md** | 项目/全局的记忆与规则,影响 LLM 怎么想 | [[91.Claude Code/04-配置与权限.md]] |
| **斜杠命令** | `/` 开头的内置或自定义动作 | [[91.Claude Code/03-基本使用与斜杠命令.md]] |
| **权限系统** | allow/deny/ask 决定哪些工具调用要批准 | [[91.Claude Code/04-配置与权限.md]] |
| **MCP** | 标准协议接入外部工具/数据源 | [[91.Claude Code/06-MCP.md]] |
| **子代理** | 独立上下文的子任务执行者,可并行 | [[91.Claude Code/07-Subagents与工作流.md]] |
| **hooks** | 在工具调用前后必然执行的脚本(改变环境) | [[32.hooks/06-claude-code-hooks.md]] |
| **插件** | 把命令/代理/技能/hooks/MCP 打包分发 | [[91.Claude Code/05-插件与Skills.md]] |

> 关键直觉:**CLAUDE.md / 提示词改变"LLM 想做什么";hooks / 权限改变"环境必然做/不做什么"。** 两者配合才可靠。

## 7. 版本、文档与术语约定

- **版本**:本系列基于 Claude Code **v2.x**(2026-06)。查自己的版本:`claude --version`。
- **官方文档**:`code.claude.com/docs`(旧 `docs.anthropic.com` 会跳转至此)。
- **诊断**:任何"装好了但不对劲",先跑 `claude doctor`——它一次性报告安装类型、版本、登录状态、Git、PATH。
- **术语**:本系列保留英文术语(hook、MCP、subagent、permission 等),包裹它们的句子用中文。
