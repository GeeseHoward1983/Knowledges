# 03 · 基本使用与斜杠命令

> 本篇讲怎么真正"用起来":启动、交互/无头两种模式、CLI 常用参数、引用文件、内置斜杠命令清单、快捷键、**计划模式**、会话与检查点管理。
> 假设你已装好并登录(见 [[91.Claude Code/01-安装.md]]、[[91.Claude Code/02-登录与API-Key.md]])。

---

## 1. 启动:两种模式

```bash
# ① 交互模式:进入对话式会话(最常用)
claude

# ② 无头/print 模式:一次性执行后退出,适合脚本/CI/管道
claude -p "审查未提交的改动并列出风险点"
git diff | claude -p "用中文总结这段 diff 改了什么"
```

> 交互模式像"结对编程";print 模式像"把 Claude 当一个 Unix 命令用"。

---

## 2. CLI 常用参数

| 参数 | 作用 |
|---|---|
| `-p, --print` | 无头模式,输出后退出 |
| `-c, --continue` | 继续**最近**一次会话 |
| `-r, --resume` | 从历史会话**列表**里挑一个恢复 |
| `--model opus\|sonnet\|haiku` | 指定模型 |
| `--permission-mode plan` | 以某权限模式启动(见 §6) |
| `--add-dir <路径>` | 把额外目录纳入工作范围 |
| `--agents '{...}'` | 临时定义子代理(JSON,见 [[91.Claude Code/07-Subagents与工作流.md]]) |
| `--dangerously-skip-permissions` | **跳过所有权限确认**(危险,仅隔离环境用) |

子命令(不进交互直接执行):`claude doctor`、`claude update`、`claude mcp ...`(见 [[91.Claude Code/06-MCP.md]])。

---

## 3. 交互模式里怎么干活

- **直接说人话**:"把 `utils/date.ts` 的时区 bug 修了,并补一个测试"。
- **`@` 引用文件/目录**:输入 `@` 触发路径补全,如 `@src/api/user.ts`,把文件喂给上下文。
- **多行输入**:行尾 `\` 续行,或用 `Shift+Enter`(终端支持时);`/terminal-setup` 可优化终端按键。
- **粘贴**:可直接粘贴报错、日志、甚至图片(支持的终端/IDE 里)。
- **`!` 前缀**:`!ls -la` 直接跑一条 shell 命令(不经 LLM)。
- **`#` 前缀**:`# 本项目用 pnpm 不用 npm` 快速把一条记忆写进 CLAUDE.md(见 [[91.Claude Code/04-配置与权限.md]])。

## 5. 快捷键

| 按键 | 作用 |
|---|---|
| `Shift+Tab` | **循环权限模式**:default → acceptEdits → auto → plan(见 §6) |
| `Esc` | 中断当前生成 |
| `Esc` `Esc` | 回退到上一个检查点(等同 `/rewind`) |
| `Ctrl+B` | 把正在跑的(子)任务**送后台**,你继续输入 |
| `Ctrl+C` | 取消 / 退出 |
| `↑` `↓` | 翻历史输入 |

---

## 6. 计划模式与权限模式循环

用 `Shift+Tab` 在四种模式间循环,决定 Claude 动手的"放手程度":

```
default ──► acceptEdits ──► auto ──► plan ──┐
   ▲                                         │
   └─────────────────────────────────────────┘
```

| 模式 | 行为 |
|---|---|
| **default** | 每个敏感动作(改文件、跑命令)都问你 |
| **acceptEdits** | 自动接受文件编辑,但跑命令等仍按权限规则 |
| **auto** | 更放手地自动执行(在权限允许范围内) |
| **plan** | **只读规划**:Claude 先调研、出方案,**不动文件**,等你批准 |

> **计划模式(plan)是重活前的安全垫**:让 Claude 先读代码、给出步骤方案,你确认后再切到执行模式动手。复杂改动强烈建议先 plan。也可启动即进:`claude --permission-mode plan`。

权限的**持久化规则**(哪些命令永久允许/禁止)在 settings.json 里配,见 [[91.Claude Code/04-配置与权限.md]]。

## 7. 会话与检查点管理

- **恢复会话**:`claude -c`(接最近)或 `claude -r`(从列表选)。
- **检查点(checkpoint)**:Claude 在每次改文件前自动存档。不满意就 `Esc Esc` 或 `/rewind` 回滚——**独立于 git**,不用先 commit。
- **上下文管理**:聊久了上下文会满。`/compact` 压缩历史保留要点;`/clear` 彻底重开。长任务善用这两个,见 [[91.Claude Code/12-故障排查与技巧.md]]。

## 8. 自定义斜杠命令(预览)

把常用提示词存成文件,变成你自己的 `/命令`:

```
.claude/commands/review-staged.md      # 项目级 → /review-staged
~/.claude/commands/standup.md           # 用户级(跨项目)
```

文件支持 YAML frontmatter 与参数占位 `$ARGUMENTS` / `$1 $2`:

```markdown
---
description: 审查暂存区改动的安全问题
allowed-tools: Read, Grep, Glob, Bash
model: opus
---
审查 `git diff --staged` 的安全风险,重点看 $ARGUMENTS。
```
