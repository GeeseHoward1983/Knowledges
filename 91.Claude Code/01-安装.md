# 01 · 安装

> 本篇覆盖在 **Windows / Linux / macOS** 上安装 Claude Code 的所有主流方式、升级、卸载与验证。
> 重点照顾 Windows(原生安装器、PATH、PowerShell 坑)与 Linux 两条路径。
> 资料核实 2026-06,Claude Code v2.x。装完务必跑 `claude doctor` 自检。

---

## 1. 安装前提

| 前提 | 说明 | 必需? |
|---|---|---|
| 付费账户 | Pro / Max / Team / Enterprise / Console 之一,或 API Key | **是** |
| 终端 | Windows 用 **Windows PowerShell**(非 x86 版)或 CMD;Linux/macOS 用任意 shell | 是 |
| Git for Windows | 装了 Claude Code 才能用 Bash 工具;否则退化为用 PowerShell 当 shell | 推荐 |
| Node.js 18+ | **仅 npm 安装法**需要;原生安装器不需要 | 否 |

> 关键变化:从前 Claude Code 靠 npm + Node 运行,现在**官方推荐"原生安装器"**——下载独立二进制,不依赖 Node,自动配 PATH、自动后台更新。npm 包如今也只是"交付同一个原生二进制"的一种途径,装好的 `claude` 不再走 Node 运行时。

---

## 2. Windows 安装

### 2.1 原生安装器(推荐)

打开 **Windows PowerShell**(开始菜单搜 "PowerShell",别用带 "x86" 的 32 位版),执行:

```powershell
irm https://claude.ai/install.ps1 | iex
```

`irm` = `Invoke-RestMethod`,`iex` = `Invoke-Expression`:下载安装脚本并执行。**无需管理员权限**。二进制装到:

```
C:\Users\<你的用户名>\.local\bin\claude.exe
```

装完**关闭当前终端、开一个新的**(PATH 只在新会话生效),然后验证:

```powershell
claude --version
```

### 2.2 CMD 版(命令提示符)

若用 CMD 而非 PowerShell:

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

### 2.3 WinGet

```powershell
winget install Anthropic.ClaudeCode
```

> WinGet 装的版本**不自动更新**,需手动 `winget upgrade`;原生安装器则后台自动更新。

### 2.4 npm(需要 Node 18+)

适合"团队统一锁版本"或已有 Node 工具链的人:

```powershell
npm install -g @anthropic-ai/claude-code
```

- 官方包名 `@anthropic-ai/claude-code`。
- **绝不要 `sudo npm install -g`**(Linux/macOS 同理),会引发权限混乱;遇 `EACCES` 应修 npm 目录权限,而非加 sudo。

### 2.5 WSL

在 WSL(Ubuntu 等)里,Claude Code 当作 **Linux** 安装(见第 3 节的 `install.sh` 或 npm)。注意:

- 在 WSL 里装的 `claude` 操作的是 WSL 文件系统(`/home/...`),不是 Windows 的 `C:\`;跨系统访问 `/mnt/c/...` 会很慢。
- 项目放 WSL 原生目录性能最好。

### 2.6 安装位置与 PATH 修复

原生安装器把 `claude.exe` 放在 `%USERPROFILE%\.local\bin`。若开新终端后仍提示 `claude` 不是命令,多半是该目录没进 PATH:

```powershell
[Environment]::SetEnvironmentVariable("PATH", "$env:PATH;$env:USERPROFILE\.local\bin", [EnvironmentVariableTarget]::User)
```

执行后**再开新终端**。更多 Windows 坑见 [[91.Claude Code/12-故障排查与技巧.md]]。

## 3. macOS / Linux 安装

### 3.1 原生安装器(推荐)

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

二进制装到 `~/.local/bin/claude`。若 PATH 没含该目录,在 `~/.bashrc` / `~/.zshrc` 追加:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

重开终端或 `source ~/.bashrc` 后生效。

### 3.2 Homebrew(macOS / Linuxbrew)

```bash
brew install claude-code
```

### 3.3 npm(需 Node 18+)

```bash
npm install -g @anthropic-ai/claude-code
```

同样**不要加 sudo**。

## 4. 验证安装

| 命令 | 作用 |
|---|---|
| `claude --version` | 看版本号,确认装上 |
| `claude doctor` | **一站式自检**:安装类型(native/npm/WinGet)、版本、登录状态、Git 健康、PATH 问题 |
| `claude` | 首次运行触发浏览器 OAuth 登录(见 [[91.Claude Code/02-登录与API-Key.md]]) |

> 任何"装好却跑不起来",第一步永远是 `claude doctor`。

---

## 5. 升级

| 安装方式 | 升级方式 |
|---|---|
| 原生安装器 | **自动**后台更新,无需手动 |
| WinGet | `winget upgrade Anthropic.ClaudeCode` |
| npm | `npm update -g @anthropic-ai/claude-code` |
| Homebrew | `brew upgrade claude-code` |

冻结自动更新(企业/复现环境):设环境变量 `DISABLE_AUTOUPDATER=1`。

---

## 6. 卸载

| 安装方式 | 卸载 |
|---|---|
| 原生(Win) | 删 `%USERPROFILE%\.local\bin\claude.exe`,并从 PATH 移除该目录 |
| 原生(Unix) | 删 `~/.local/bin/claude` |
| WinGet | `winget uninstall Anthropic.ClaudeCode` |
| npm | `npm uninstall -g @anthropic-ai/claude-code` |
| Homebrew | `brew uninstall claude-code` |

配置与凭证残留在 `~/.claude/`(Windows `%USERPROFILE%\.claude\`),要彻底清理可一并删除(会丢失登录、历史、settings)。

---

## 7. 安装期最常见的三个坑

1. **`claude` is not recognized**:PATH/会话问题,见 §2.6,或 `claude doctor`。
2. **用了 x86 PowerShell**:32 位进程在 64 位机上会失败,务必用普通 "Windows PowerShell"。
3. **在 Git Bash / MinTTY 里跑交互模式报 `Raw mode is not supported`**:Git Bash 不支持 Claude Code 交互 CLI 需要的 TTY 特性。解决:用 Windows PowerShell / CMD / Windows Terminal,或在 WSL 里跑。

> 这三个 + 更多疑难(代理、中文路径、编码)集中在 [[91.Claude Code/12-故障排查与技巧.md]]。
