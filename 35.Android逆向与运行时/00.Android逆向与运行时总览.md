```mermaid
graph TD
  REV["Android 逆向"] --> FMT["打包格式<br/>APK/DEX/smali"]
  REV --> RT["运行时<br/>ART/Zygote/JNI"]
  REV --> TOOL["工具与对抗<br/>jadx/Frida/脱壳"]
  FMT --> CODE["Java 层逻辑<br/>反编译/重打包"]
  RT --> NATIVE["native 层<br/>.so = ELF"]
  TOOL --> DYN["动态分析<br/>hook/调试/抓包"]
  NATIVE -.复用.-> ELF["ELF + 动态链接<br/>(11/14 系列)"]
  DYN -.复用.-> HOOK["Hook / 调试器<br/>(32/44 系列)"]
```

> 一句话：Android 逆向 = **看懂打包格式**（APK/DEX/smali 把 App 拆开）+ **理解运行时**（ART 如何执行、Zygote 如何起、JNI 如何跨到 native）+ **用对工具**（jadx 静态、Frida 动态、脱壳穿透加固）。读完本系列，你能独立分析一个真实 App 的 Java 与 native 逻辑。
