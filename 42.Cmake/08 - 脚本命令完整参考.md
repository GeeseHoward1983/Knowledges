# 第 08 章 · 脚本命令完整参考

> 基准版本：CMake 4.3.4

本章是 **字典式参考章**。CMake 的 **Scripting Commands（脚本命令）** 是在任何上下文都可用的命令——无论是用 `cmake -P script.cmake` 运行的脚本模式，还是在 `CMakeLists.txt` 项目中配置阶段，它们都成立。这与第 09 章的 **Project Commands（项目命令，如 `add_executable`、`target_link_libraries`）** 相对：后者只在生成构建系统时才有意义。

阅读约定：

- 签名中 `<x>` 表示必填占位，`[x]` 表示可选，`{A|B}` 表示多选一，`...` 表示可重复。
- 控制流命令（`if`/`foreach`/`function` 等）本章只做 **签名速查 + 一句话**，完整语义见 [[42.Cmake/02 - CMake 语言基础.md]]。
- 查找命令（`find_*`）本章只给签名与最小用法，完整策略见 [[42.Cmake/10 - 查找与依赖管理.md]]。
- 生成器表达式（`$<...>`）见 [[42.Cmake/07 - 生成器表达式.md]]。

## 一、变量与消息

### set

设置普通变量、缓存变量（CACHE）或环境变量（ENV）。

**签名**：

```cmake
set(<variable> <value>... [PARENT_SCOPE])
set(<variable> <value>... CACHE <type> <docstring> [FORCE])
set(ENV{<variable>} [<value>])
```

**参数/要点**：

- 多个 `<value>` 之间用 `;` 连接成 **列表**：`set(srcs a.c b.c)` → `a.c;b.c`。
- `PARENT_SCOPE`：写入上一层作用域（常用于 function 内向外回传结果）。
- `CACHE <type>`：`<type>` 为 `BOOL`/`FILEPATH`/`PATH`/`STRING`/`INTERNAL`。无 `FORCE` 时不覆盖已存在的缓存值；`INTERNAL` 隐含 `FORCE`。
- `set(ENV{X})` 不带值即清空该环境变量；环境变量只影响当前 CMake 进程。

```cmake
set(MY_LIST a b c)                              # 普通变量（列表）
set(OPT_LEVEL "2" CACHE STRING "优化级别")       # 缓存变量
set(ENV{LANG} "C")                              # 环境变量
```

### unset

删除变量。

**签名**：

```cmake
unset(<variable> [CACHE | PARENT_SCOPE])
unset(ENV{<variable>})
```

- 默认删除普通变量；`CACHE` 删缓存项；`PARENT_SCOPE` 删上层作用域中的变量；`ENV{}` 删环境变量。

```cmake
unset(MY_LIST)
unset(OPT_LEVEL CACHE)
```

### list

列表操作命令，子命令丰富。除 `LENGTH`/`GET`/`JOIN`/`SUBLIST`/`FIND` 是“读”操作（结果写入 `<out-var>`）外，其余多为“原地修改” `<list>`。

| 子命令 | 签名 | 说明 |
|---|---|---|
| `LENGTH` | `list(LENGTH <list> <out-var>)` | 求元素个数 |
| `GET` | `list(GET <list> <idx>... <out-var>)` | 取指定下标元素（支持负数） |
| `JOIN` | `list(JOIN <list> <glue> <out-var>)` | 用 `<glue>` 连接成字符串 |
| `SUBLIST` | `list(SUBLIST <list> <begin> <length> <out-var>)` | 取子列表（`<length>=-1` 到末尾） |
| `FIND` | `list(FIND <list> <value> <out-var>)` | 返回首个匹配下标，未找到为 `-1` |
| `APPEND` | `list(APPEND <list> <e>...)` | 末尾追加 |
| `PREPEND` | `list(PREPEND <list> <e>...)` | 头部插入 |
| `INSERT` | `list(INSERT <list> <idx> <e>...)` | 在下标处插入 |
| `POP_BACK` | `list(POP_BACK <list> [<out>...])` | 弹出末元素（可写入变量） |
| `POP_FRONT` | `list(POP_FRONT <list> [<out>...])` | 弹出首元素 |
| `REMOVE_ITEM` | `list(REMOVE_ITEM <list> <value>...)` | 按值删除全部匹配 |
| `REMOVE_AT` | `list(REMOVE_AT <list> <idx>...)` | 按下标删除 |
| `REMOVE_DUPLICATES` | `list(REMOVE_DUPLICATES <list>)` | 去重（保留首次出现顺序） |
| `TRANSFORM` | `list(TRANSFORM <list> <ACTION> [...] [OUTPUT_VARIABLE <out>])` | 批量变换，见下 |
| `SORT` | `list(SORT <list> [COMPARE ...] [CASE ...] [ORDER ...])` | 排序 |
| `REVERSE` | `list(REVERSE <list>)` | 反转 |
| `FILTER` | `list(FILTER <list> {INCLUDE|EXCLUDE} REGEX <re>)` | 按正则保留/剔除 |

**`TRANSFORM` 的 `<ACTION>`**：`APPEND <s>`、`PREPEND <s>`、`TOLOWER`、`TOUPPER`、`STRIP`、`GENEX_STRIP`、`REPLACE <re> <rep>`；可加 `AT <idx>...` 或 `FOR <s> <e> [<step>]` 限定范围、`REGEX <re>` 限定匹配项。
**`SORT` 选项**：`COMPARE {STRING|FILE_BASENAME|NATURAL}`、`CASE {SENSITIVE|INSENSITIVE}`、`ORDER {ASCENDING|DESCENDING}`。

```cmake
set(files /a/x.c /a/y.c /b/z.c)
list(LENGTH files n)                                   # n = 3
list(FILTER files INCLUDE REGEX "^/a/")               # 仅保留 /a/ 下
list(TRANSFORM files REPLACE "\\.c$" ".o" OUTPUT_VARIABLE objs)
list(SORT files COMPARE NATURAL ORDER DESCENDING)
```

### string

字符串操作命令，子命令繁多。多数为“结果写入 `<out-var>`”。

| 子命令 | 签名 | 说明 |
|---|---|---|
| `FIND` | `string(FIND <s> <sub> <out> [REVERSE])` | 子串位置，未找到 `-1` |
| `REPLACE` | `string(REPLACE <match> <rep> <out> <input>...)` | 普通子串替换 |
| `REGEX MATCH` | `string(REGEX MATCH <re> <out> <input>...)` | 匹配首处，结果存 `<out>` |
| `REGEX MATCHALL` | `string(REGEX MATCHALL <re> <out> <input>...)` | 匹配全部，结果为列表 |
| `REGEX REPLACE` | `string(REGEX REPLACE <re> <rep> <out> <input>...)` | 正则替换（`\\1` 反向引用） |
| `APPEND` | `string(APPEND <var> <input>...)` | 原地追加到 `<var>` |
| `PREPEND` | `string(PREPEND <var> <input>...)` | 原地前插 |
| `CONCAT` | `string(CONCAT <out> <input>...)` | 拼接到 `<out>` |
| `TOLOWER` | `string(TOLOWER <s> <out>)` | 转小写 |
| `TOUPPER` | `string(TOUPPER <s> <out>)` | 转大写 |
| `LENGTH` | `string(LENGTH <s> <out>)` | 字节长度 |
| `SUBSTRING` | `string(SUBSTRING <s> <begin> <length> <out>)` | 取子串（`-1` 到末尾） |
| `STRIP` | `string(STRIP <s> <out>)` | 去首尾空白 |
| `REPEAT` | `string(REPEAT <s> <count> <out>)` | 重复 N 次 |
| `COMPARE` | `string(COMPARE <op> <s1> <s2> <out>)` | `<op>`：`LESS`/`GREATER`/`EQUAL`/`NOTEQUAL`/`LESS_EQUAL`/`GREATER_EQUAL` |
| `HASH` | `string(<ALGO> <out> <s>)` | 计算哈希，见下 |
| `ASCII` | `string(ASCII <num>... <out>)` | 数字码点转字符 |
| `HEX` | `string(HEX <s> <out>)` | 字符串转十六进制（4.1+） |
| `MAKE_C_IDENTIFIER` | `string(MAKE_C_IDENTIFIER <s> <out>)` | 转合法 C 标识符（非法字符变 `_`） |
| `GENEX_STRIP` | `string(GENEX_STRIP <s> <out>)` | 删除其中的生成器表达式 |
| `TIMESTAMP` | `string(TIMESTAMP <out> [<fmt>] [UTC])` | 当前时间戳 |
| `UUID` | `string(UUID <out> NAMESPACE <ns> NAME <n> TYPE {MD5|SHA1} [UPPER])` | 生成名字型 UUID |
| `JSON` | `string(JSON <out> [ERROR_VARIABLE <e>] <op> ...)` | JSON 解析/修改，见下 |

**`HASH` 的 `<ALGO>`**：`MD5`/`SHA1`/`SHA224`/`SHA256`/`SHA384`/`SHA512`/`SHA3_224`/`SHA3_256`/`SHA3_384`/`SHA3_512`。这些算法名同样用于 `file(<ALGO>)` 与 `file(DOWNLOAD ... EXPECTED_HASH)`。
**`TIMESTAMP` 格式符**：`%Y %m %d %H %M %S %j %s`（`%s` 为 Unix 纪元秒）等；加 `UTC` 用协调世界时。
**`JSON` 子操作**：`GET`/`GET_RAW`/`TYPE`/`MEMBER`/`LENGTH`/`REMOVE`/`SET`/`EQUAL`。读取/修改 JSON 文档，路径由 `<member|index>...` 给出，可选 `ERROR_VARIABLE` 捕获错误而不致命。

```cmake
string(REGEX REPLACE "v([0-9]+)\\.([0-9]+)" "\\1_\\2" tag "v4.3")  # tag = 4_3
string(TIMESTAMP now "%Y-%m-%d %H:%M:%S" UTC)
string(JSON ver GET "${json_text}" package version)               # 取 .package.version
string(MAKE_C_IDENTIFIER "my-lib.0" id)                           # id = my_lib_0
```

### math

对整数做算术求值。

**签名**：

```cmake
math(EXPR <out-var> "<expression>" [OUTPUT_FORMAT {DECIMAL|HEXADECIMAL}])
```

- 支持 `+ - * / %`、位运算 `| & ^ ~ << >>`、括号；运算数为有符号整数（64 位）。
- `OUTPUT_FORMAT HEXADECIMAL` 以 `0x` 前缀输出。

```cmake
math(EXPR total "(3 + 4) * 2")              # total = 14
math(EXPR mask "1 << 8" OUTPUT_FORMAT HEXADECIMAL)  # mask = 0x100
```

### message

向用户输出消息，并控制日志级别。

**签名**：

```cmake
message([<mode>] "text"...)
message(<checkState> "text"...)
message(CONFIGURE_LOG "text"...)
```

**`<mode>` 级别**（由高到低）：`FATAL_ERROR`（终止）、`SEND_ERROR`（继续配置但不生成）、`WARNING`、`AUTHOR_WARNING`、`DEPRECATION`、`NOTICE`（默认，输出到 stderr）、`STATUS`、`VERBOSE`、`DEBUG`、`TRACE`。可用 `--log-level=` 或变量 `CMAKE_MESSAGE_LOG_LEVEL` 过滤。
**检查型 `<checkState>`**：`CHECK_START`（开始一项检查）、`CHECK_PASS <text>`（成功收尾）、`CHECK_FAIL <text>`（失败收尾）。配合 `CMAKE_MESSAGE_INDENT` 列表可缩进嵌套消息。

```cmake
message(STATUS "正在配置项目")
message(CHECK_START "查找 zlib")
message(CHECK_PASS "已找到")
message(FATAL_ERROR "缺少必要依赖")   # 立即终止
```

### mark_as_advanced

将缓存变量标记为“高级”，默认在 GUI（cmake-gui/ccmake）中隐藏。

**签名**：

```cmake
mark_as_advanced([CLEAR | FORCE] <var>...)
```

- `CLEAR` 取消高级标记；`FORCE` 强制覆盖已有标记。

```cmake
mark_as_advanced(FORCE MY_INTERNAL_PATH)
```

### option

定义一个布尔型缓存选项（`BOOL`），供用户在配置时开关。

**签名**：

```cmake
option(<variable> "<help text>" [value])
```

- `[value]` 缺省为 `OFF`。若已存在同名普通变量，CMake 3.13+ 在策略 `CMP0077` 为 `NEW` 时会尊重该普通变量。

```cmake
option(BUILD_TESTS "构建测试" ON)
```

### variable_watch

监视某变量的读写，触发回调（调试用）。

**签名**：

```cmake
variable_watch(<variable> [<command>])
```

- 不带 `<command>` 时把访问信息打印到 stderr；带回调时以 `(变量名 访问类型 值 当前列表文件 栈)` 调用之。

```cmake
variable_watch(CMAKE_BUILD_TYPE)
```

## 二、控制流（签名速查）

> 以下命令的完整语义、作用域规则与示例见 [[42.Cmake/02 - CMake 语言基础.md]]。本节仅作字典式速查。

### if / elseif / else / endif

条件分支。`if(<cond>) ... elseif(<cond>) ... else() ... endif()`。条件支持 `NOT`/`AND`/`OR`、比较（`EQUAL`/`STREQUAL`/`VERSION_LESS`/`MATCHES` 等）、存在性判断（`DEFINED`/`EXISTS`/`TARGET`/`COMMAND`）。

### foreach

遍历循环：`foreach(var IN ITEMS|LISTS ...)`、`foreach(var RANGE <stop>)`、`foreach(var RANGE <start> <stop> [<step>])`、`foreach(v1 v2 ... IN ZIP_LISTS a b ...)`。以 `endforeach()` 结束。

### while

条件循环：`while(<cond>) ... endwhile()`，条件语法同 `if`。

### break / continue

`break()` 跳出最内层 `foreach`/`while`；`continue()` 进入下一次迭代。

### function / endfunction

定义函数（**新作用域**，参数为变量）：`function(<name> [arg...]) ... endfunction()`。内置 `ARGC`/`ARGV`/`ARGN`/`ARGV0...`。

### macro / endmacro

定义宏（**无新作用域**，参数为文本替换）：`macro(<name> [arg...]) ... endmacro()`。

### return

从函数或被 `include` 的文件提前返回：`return([PROPAGATE <var>...])`。`PROPAGATE`（策略 `CMP0140` NEW）可把变量回传上层。

### block / endblock

引入显式变量/策略作用域：`block([SCOPE_FOR [VARIABLES] [POLICIES]] [PROPAGATE <var>...]) ... endblock()`。

### cmake_language

以编程方式调用命令、求值代码、安排延迟调用等。

| 子命令 | 签名 | 说明 |
|---|---|---|
| `CALL` | `cmake_language(CALL <command> [<arg>...])` | 动态调用命令名 |
| `EVAL` | `cmake_language(EVAL CODE <code>...)` | 把字符串当 CMake 代码执行 |
| `DEFER` | `cmake_language(DEFER [DIRECTORY <d>] [ID <id>|ID_VAR <v>] CALL <cmd> ...)` | 安排在当前目录处理结束时执行；`CANCEL_CALL <id>...`/`GET_CALL_IDS`/`GET_CALL <id>` 管理已排程调用 |
| `GET_MESSAGE_LOG_LEVEL` | `cmake_language(GET_MESSAGE_LOG_LEVEL <out>)` | 查询当前生效的消息日志级别 |
| `SET_DEPENDENCY_PROVIDER` | `cmake_language(SET_DEPENDENCY_PROVIDER <cmd> SUPPORTED_METHODS <m>...)` | 注册依赖提供器（拦截 `find_package`/`FetchContent`），仅可在 toolchain/provider 文件中调用 |

```cmake
cmake_language(CALL message STATUS "动态调用")
cmake_language(EVAL CODE "set(x 1)")
cmake_language(DEFER CALL message "目录处理结束时打印")
```

### include

读取并执行另一个 `.cmake` 文件或模块。

**签名**：

```cmake
include(<file|module> [OPTIONAL] [RESULT_VARIABLE <var>]
        [NO_POLICY_SCOPE])
```

- 先按模块名在 `CMAKE_MODULE_PATH` 与内置模块目录查找；`OPTIONAL` 时缺失不报错；`RESULT_VARIABLE` 写入完整路径或 `NOTFOUND`。

```cmake
include(CTest)
include(cmake/Helpers.cmake OPTIONAL)
```

### include_guard

防止同一文件在同一作用域内被重复 `include`（类似 C 的 `#pragma once`）。

**签名**：

```cmake
include_guard([DIRECTORY | GLOBAL])
```

- 无参：当前变量作用域内去重；`DIRECTORY`：当前目录及子目录；`GLOBAL`：整个运行期。

```cmake
include_guard(GLOBAL)
```

## 三、文件与路径

### file

最庞大的脚本命令，覆盖读写、目录、传输、归档、锁等。

| 子命令 | 签名 | 说明 |
|---|---|---|
| `READ` | `file(READ <path> <out> [OFFSET n] [LIMIT n] [HEX])` | 读文件全部/部分内容 |
| `STRINGS` | `file(STRINGS <path> <out> [LIMIT_COUNT n] [REGEX <re>] [ENCODING <e>] ...)` | 提取可打印字符串行 |
| `WRITE` | `file(WRITE <path> <content>...)` | 写文件（覆盖） |
| `APPEND` | `file(APPEND <path> <content>...)` | 追加写 |
| `TOUCH` | `file(TOUCH [<files>...])` / `file(TOUCH_NOCREATE ...)` | 更新时间戳/不创建 |
| `GLOB` | `file(GLOB <out> [LIST_DIRECTORIES t/f] [RELATIVE <p>] [CONFIGURE_DEPENDS] <glob>...)` | 当前层通配匹配 |
| `GLOB_RECURSE` | `file(GLOB_RECURSE <out> [FOLLOW_SYMLINKS] [CONFIGURE_DEPENDS] <glob>...)` | 递归通配匹配 |
| `RENAME` | `file(RENAME <old> <new> [RESULT <r>] [NO_REPLACE])` | 重命名/移动 |
| `COPY_FILE` | `file(COPY_FILE <src> <dst> [RESULT <r>] [ONLY_IF_DIFFERENT] [INPUT_MAY_BE_RECENT])` | 复制单个文件 |
| `COPY` | `file(COPY <files>... DESTINATION <d> [FILE_PERMISSIONS ...] [PATTERN ... EXCLUDE] ...)` | 复制并保留/设权限 |
| `INSTALL` | `file(INSTALL ...)` | `COPY` 的安装变体（带消息日志），多由生成的脚本调用 |
| `REMOVE` | `file(REMOVE [<files>...])` | 删除文件（缺失不报错） |
| `REMOVE_RECURSE` | `file(REMOVE_RECURSE [<files/dirs>...])` | 递归删除 |
| `MAKE_DIRECTORY` | `file(MAKE_DIRECTORY [<dirs>...])` | 创建目录（含父目录） |
| `SIZE` | `file(SIZE <path> <out>)` | 文件字节数 |
| `READ_SYMLINK` | `file(READ_SYMLINK <link> <out>)` | 读符号链接目标 |
| `CREATE_LINK` | `file(CREATE_LINK <orig> <link> [RESULT <r>] [COPY_ON_ERROR] [SYMBOLIC])` | 创建硬/符号链接 |
| `CHMOD` | `file(CHMOD <files>... [PERMISSIONS ...] [FILE_PERMISSIONS ...] [DIRECTORY_PERMISSIONS ...])` | 修改权限 |
| `CHMOD_RECURSE` | `file(CHMOD_RECURSE ...)` | 递归修改权限 |
| `REAL_PATH` | `file(REAL_PATH <path> <out> [BASE_DIRECTORY <d>] [EXPAND_TILDE])` | 解析为绝对真实路径（解 symlink） |
| `RELATIVE_PATH` | `file(RELATIVE_PATH <out> <dir> <file>)` | 计算相对路径 |
| `TO_CMAKE_PATH` | `file(TO_CMAKE_PATH "<path>" <out>)` | 平台路径→`/` 分隔、`;`→列表 |
| `TO_NATIVE_PATH` | `file(TO_NATIVE_PATH "<path>" <out>)` | →本地分隔符 |
| `DOWNLOAD` | `file(DOWNLOAD <url> [<file>] [EXPECTED_HASH ...] [SHOW_PROGRESS] [TIMEOUT n] [STATUS <s>] ...)` | 下载 |
| `UPLOAD` | `file(UPLOAD <file> <url> [STATUS <s>] [TIMEOUT n] ...)` | 上传 |
| `LOCK` | `file(LOCK <path> [DIRECTORY] [RELEASE] [GUARD {FUNCTION|FILE|PROCESS}] [RESULT_VARIABLE <r>] [TIMEOUT n])` | 文件锁 |
| `TIMESTAMP` | `file(TIMESTAMP <path> <out> [<fmt>] [UTC])` | 文件修改时间戳 |
| `GENERATE` | `file(GENERATE OUTPUT <o> {INPUT <i>|CONTENT <c>} [CONDITION <e>] [TARGET <t>] ...)` | 生成期产文件，支持生成器表达式 |
| `CONFIGURE` | `file(CONFIGURE OUTPUT <o> CONTENT <c> [@ONLY] [ESCAPE_QUOTES] [NEWLINE_STYLE ...])` | 类 `configure_file` 但内容内联 |
| `ARCHIVE_CREATE` | `file(ARCHIVE_CREATE OUTPUT <a> PATHS <p>... [FORMAT <f>] [COMPRESSION <c>] ...)` | 打包归档 |
| `ARCHIVE_EXTRACT` | `file(ARCHIVE_EXTRACT INPUT <a> [DESTINATION <d>] [PATTERNS <p>...] [LIST_ONLY] ...)` | 解包归档 |

**要点**：`GLOB` 默认不会随文件增删自动重配置，需加 `CONFIGURE_DEPENDS`（但官方建议显式列源文件而非 glob）。`ARCHIVE_CREATE` 的 `FORMAT` 取 `zip`/`7zip`/`gnutar`/`pax`/`paxr`/`raw`。

```cmake
file(READ "${CMAKE_SOURCE_DIR}/VERSION" ver)
file(WRITE "${CMAKE_BINARY_DIR}/info.txt" "build at ${ver}\n")
file(DOWNLOAD https://example.com/a.tar.gz a.tar.gz
     EXPECTED_HASH SHA256=deadbeef... SHOW_PROGRESS STATUS st)
file(GLOB_RECURSE headers CONFIGURE_DEPENDS "include/*.h")
file(ARCHIVE_CREATE OUTPUT out.tar.gz PATHS dist FORMAT gnutar COMPRESSION GZip)
```

### configure_file

把模板文件中的 `@VAR@`/`${VAR}` 占位符与 `#cmakedefine` 行替换为当前变量值后输出。

**签名**：

```cmake
configure_file(<input> <output>
               [NO_SOURCE_PERMISSIONS | USE_SOURCE_PERMISSIONS |
                FILE_PERMISSIONS <p>...]
               [COPYONLY] [ESCAPE_QUOTES] [@ONLY]
               [NEWLINE_STYLE {UNIX|DOS|WIN32|LF|CRLF}])
```

- `@ONLY`：只替换 `@VAR@`，忽略 `${VAR}`（避免冲突）。`COPYONLY`：仅复制不替换。`#cmakedefine FOO` 按 `FOO` 真假展开为 `#define`/注释。

```cmake
configure_file(config.h.in config.h @ONLY)
```

### get_filename_component

从路径中提取分量（**旧接口**；新代码推荐 `cmake_path`）。

**签名**：

```cmake
get_filename_component(<out> <path> <mode> [BASE_DIR <d>] [CACHE])
get_filename_component(<out> <path> PROGRAM [PROGRAM_ARGS <a>] [CACHE])
```

- `<mode>`：`DIRECTORY`/`NAME`/`EXT`/`NAME_WE`/`LAST_EXT`/`NAME_WLE`/`ABSOLUTE`/`REALPATH`。

```cmake
get_filename_component(dir "/a/b/c.txt" DIRECTORY)   # dir = /a/b
get_filename_component(we  "/a/b/c.txt" NAME_WE)     # we  = c
```

### cmake_path

对路径字符串做纯词法操作（不访问磁盘），是 `get_filename_component` 的现代替代。

| 子命令组 | 代表签名 | 说明 |
|---|---|---|
| `GET` | `cmake_path(GET <path-var> <component> <out>)` | 取分量：`ROOT_NAME`/`ROOT_DIRECTORY`/`ROOT_PATH`/`FILENAME`/`EXTENSION [LAST_ONLY]`/`STEM [LAST_ONLY]`/`RELATIVE_PART`/`PARENT_PATH` |
| 查询 | `cmake_path(HAS_* <path-var> <out>)`、`cmake_path(IS_ABSOLUTE <path-var> <out>)`、`cmake_path(IS_RELATIVE ...)`、`cmake_path(IS_PREFIX <path-var> <input> [NORMALIZE] <out>)` | 布尔判断 |
| `APPEND` | `cmake_path(APPEND <path-var> <input>... [OUTPUT_VARIABLE <o>])`、`APPEND_STRING` | 拼接路径段/拼接字符串 |
| `REMOVE` | `cmake_path(REMOVE_FILENAME <path-var> [...])`、`REMOVE_EXTENSION [LAST_ONLY]`、`REPLACE_FILENAME`、`REPLACE_EXTENSION` | 修改分量 |
| 规范化 | `cmake_path(NORMAL_PATH <path-var> [OUTPUT_VARIABLE <o>])`、`RELATIVE_PATH <path-var> [BASE_DIRECTORY <d>] ...`、`ABSOLUTE_PATH <path-var> [BASE_DIRECTORY <d>] [NORMALIZE] ...` | 归一/相对/绝对 |
| `CONVERT` | `cmake_path(CONVERT <input> TO_CMAKE_PATH_LIST <out> [NORMALIZE])`、`TO_NATIVE_PATH_LIST` | 列表/平台转换 |
| `NATIVE_PATH` | `cmake_path(NATIVE_PATH <path-var> [NORMALIZE] <out>)` | 转本地分隔符 |
| `COMPARE` | `cmake_path(COMPARE <p1> {EQUAL|NOT_EQUAL} <p2> <out>)` | 词法比较 |
| `HASH` | `cmake_path(HASH <path-var> <out>)` | 路径哈希（先规范化） |

注意：`GET`/`HASH`/规范化等子命令的输入是 **变量名**（不带 `${}`），而 `CONVERT` 的输入是 **字符串值**。

```cmake
set(p "/a/b/c.tar.gz")
cmake_path(GET p EXTENSION ext)            # ext = .tar.gz
cmake_path(GET p STEM LAST_ONLY stem)      # stem = c.tar
cmake_path(REPLACE_EXTENSION p ".zip" OUTPUT_VARIABLE q)
```

### separate_arguments

把单个字符串按命令行规则拆成列表（用于构造命令）。

**签名**：

```cmake
separate_arguments(<out> <UNIX_COMMAND|WINDOWS_COMMAND|NATIVE_COMMAND> [PROGRAM [SEPARATE_ARGS]] "<args>")
separate_arguments(<out>)                       # 旧式：按空白粗拆
```

- `UNIX_COMMAND` 识别引号与转义；`WINDOWS_COMMAND` 用 Windows 解析规则；`PROGRAM` 额外解析首个 token 为可执行文件。

```cmake
separate_arguments(args UNIX_COMMAND "-DNAME=\"a b\" -O2")
# args = -DNAME=a b;-O2
```

## 四、查找命令

> 以下命令的查找路径、`HINTS`/`PATHS`/`NO_*` 修饰、`<PackageName>_ROOT`、组件与版本约束等完整规则见 [[42.Cmake/10 - 查找与依赖管理.md]]。本节仅给签名与最小用法。

### find_file

查找具体文件的完整路径，结果写入缓存变量。

```cmake
find_file(<VAR> name1 [name2 ...]
          [HINTS <h>...] [PATHS <p>...] [PATH_SUFFIXES <s>...]
          [DOC "..."] [REQUIRED] [NO_DEFAULT_PATH] ...)
```

```cmake
find_file(STDIO_H stdio.h PATHS /usr/include)
```

### find_path

查找“包含某文件的目录”，常用于定位头文件目录。

```cmake
find_path(<VAR> name1 [name2 ...] [HINTS ...] [PATHS ...] [PATH_SUFFIXES ...] [REQUIRED] ...)
```

```cmake
find_path(ZLIB_INCLUDE_DIR zlib.h)
```

### find_program

查找可执行程序路径。

```cmake
find_program(<VAR> name1 [name2 ...] [HINTS ...] [PATHS ...] [REQUIRED] ...)
```

```cmake
find_program(CLANG_FORMAT clang-format REQUIRED)
```

### find_library

查找库文件，自动处理平台前后缀（`lib`/`.a`/`.so`/`.lib`…）。

```cmake
find_library(<VAR> name1 [name2 ...] [HINTS ...] [PATHS ...] [PATH_SUFFIXES ...] [REQUIRED] ...)
```

```cmake
find_library(M_LIB m)
```

### find_package

查找并加载外部包（Config 模式或 Module 模式），是依赖管理核心命令。

```cmake
find_package(<PackageName> [version] [EXACT] [QUIET] [REQUIRED]
             [COMPONENTS <c>...] [OPTIONAL_COMPONENTS <c>...]
             [CONFIG | MODULE] [GLOBAL] [NAMES <n>...] [HINTS ...] [PATHS ...] ...)
```

```cmake
find_package(Threads REQUIRED)
find_package(Boost 1.83 REQUIRED COMPONENTS filesystem system)
```

## 五、执行与系统

### execute_process

在配置阶段同步运行一个或多个子进程（可管道串联）。

**签名**：

```cmake
execute_process(COMMAND <cmd1> [<arg>...]
                [COMMAND <cmd2> [<arg>...]]...      # 前一命令 stdout 接入后一命令 stdin
                [WORKING_DIRECTORY <dir>]
                [TIMEOUT <seconds>]
                [RESULT_VARIABLE <var>] [RESULTS_VARIABLE <var>]
                [OUTPUT_VARIABLE <var>] [ERROR_VARIABLE <var>]
                [INPUT_FILE <f>] [OUTPUT_FILE <f>] [ERROR_FILE <f>]
                [OUTPUT_QUIET] [ERROR_QUIET]
                [COMMAND_ECHO <STDOUT|STDERR|NONE>]
                [ECHO_OUTPUT_VARIABLE] [ECHO_ERROR_VARIABLE]
                [OUTPUT_STRIP_TRAILING_WHITESPACE] [ERROR_STRIP_TRAILING_WHITESPACE]
                [ENCODING <name>] [ENVIRONMENT <var=value>...] [ENVIRONMENT_MODIFICATION ...]
                [COMMAND_ERROR_IS_FATAL <ANY|LAST|NONE>])
```

**要点**：

- `RESULT_VARIABLE` 取最后一个命令的退出码（或错误串）；`RESULTS_VARIABLE` 取 **每个** 命令的结果列表。
- `OUTPUT_VARIABLE`/`ERROR_VARIABLE` 捕获输出；`ECHO_OUTPUT_VARIABLE`/`ECHO_ERROR_VARIABLE` 表示捕获的同时仍回显。
- `COMMAND_ECHO` 在运行前打印命令本身；`COMMAND_ERROR_IS_FATAL ANY` 任一命令失败即报致命错误。

```cmake
execute_process(
  COMMAND git rev-parse --short HEAD
  WORKING_DIRECTORY ${CMAKE_SOURCE_DIR}
  OUTPUT_VARIABLE GIT_HASH
  OUTPUT_STRIP_TRAILING_WHITESPACE
  COMMAND_ERROR_IS_FATAL ANY)
```

### cmake_host_system_information

查询主机硬件/系统信息。

**签名**：

```cmake
cmake_host_system_information(RESULT <out> QUERY <key>...)
cmake_host_system_information(RESULT <out> QUERY WINDOWS_REGISTRY <key> [...])  # 注册表查询
```

- 常用 `<key>`：`NUMBER_OF_LOGICAL_CORES`/`NUMBER_OF_PHYSICAL_CORES`/`HOSTNAME`/`FQDN`/`TOTAL_PHYSICAL_MEMORY`/`AVAILABLE_PHYSICAL_MEMORY`/`OS_NAME`/`OS_RELEASE`/`OS_VERSION`/`OS_PLATFORM`/`PROCESSOR_NAME`/`PROCESSOR_DESCRIPTION` 等。

```cmake
cmake_host_system_information(RESULT ncpu QUERY NUMBER_OF_LOGICAL_CORES)
```

### site_name

获取本机主机名，写入变量（默认查 `SITE` 缓存或 `hostname`）。

**签名**：

```cmake
site_name(<variable>)
```

```cmake
site_name(THIS_HOST)
```

### cmake_minimum_required

声明项目所需的最低 CMake 版本，并据此设定策略默认值。**必须**位于顶层脚本/工程开头。

**签名**：

```cmake
cmake_minimum_required(VERSION <min>[...<max>] [FATAL_ERROR])
```

- `<min>...<max>` 形式：低于 `<min>` 报错；同时把不超过 `<max>` 的策略设为 `NEW`。

```cmake
cmake_minimum_required(VERSION 3.20...4.3)
```

### cmake_policy

精细控制策略（Policy）的 NEW/OLD 行为与版本栈。

**签名**：

```cmake
cmake_policy(VERSION <min>[...<max>])
cmake_policy(SET CMP<NNNN> {NEW|OLD})
cmake_policy(GET CMP<NNNN> <out>)
cmake_policy(PUSH)
cmake_policy(POP)
```

- `PUSH`/`POP` 成对保存/恢复策略栈（常用于模块内临时改策略）。

```cmake
cmake_policy(SET CMP0077 NEW)
```

### cmake_parse_arguments

在 function/macro 中解析具名参数（实现“关键字参数”风格 API）。

**签名**：

```cmake
cmake_parse_arguments(<prefix> "<options>" "<one_value_keywords>" "<multi_value_keywords>" <args>...)
cmake_parse_arguments(PARSE_ARGV <N> <prefix> "<options>" "<one>" "<multi>")
```

- `<options>` 为开关型（出现即 TRUE）；`<one_value_keywords>` 取单值；`<multi_value_keywords>` 取多值列表。
- 解析后得到 `<prefix>_<KEYWORD>` 变量，未识别参数进 `<prefix>_UNPARSED_ARGUMENTS`，缺值关键字进 `<prefix>_KEYWORDS_MISSING_VALUES`。
- `PARSE_ARGV <N>` 形式直接读 `ARGV`，能正确处理含 `;` 的参数，推荐在 function 中使用。

```cmake
function(my_add)
  cmake_parse_arguments(PARSE_ARGV 0 ARG "QUIET" "NAME" "SOURCES")
  if(ARG_QUIET)
    message(STATUS "name=${ARG_NAME} srcs=${ARG_SOURCES}")
  endif()
endfunction()
my_add(NAME foo SOURCES a.c b.c QUIET)
```

## 本章小结

本章逐条覆盖了 CMake 4.3.4 的 **脚本命令（Scripting Commands）**，按五组归纳：

- **变量与消息**：`set`/`unset` 管理变量三态（普通/缓存/环境）；`list`/`string` 是数据处理两大主力（子命令已逐一列表，含 `TRANSFORM`、`REGEX`、`JSON`、`HASH`、`TIMESTAMP`、`UUID`）；`math` 做整数运算；`message` 控制输出与检查流；`option`/`mark_as_advanced`/`variable_watch` 服务于配置交互与调试。
- **控制流**：`if`/`foreach`/`while`/`function`/`macro`/`block`/`return` 及 `cmake_language`、`include`/`include_guard` 构成脚本骨架（语义详见第 02 章）。
- **文件与路径**：`file` 一条命令囊括读写、目录、下载/上传、归档、锁与生成；`configure_file` 做模板替换；`cmake_path` 是现代词法路径接口，逐步取代 `get_filename_component`；`separate_arguments` 拆分命令行。
- **查找命令**：`find_file`/`find_path`/`find_program`/`find_library`/`find_package` 五件套（详解见第 10 章）。
- **执行与系统**：`execute_process` 跑子进程；`cmake_host_system_information`/`site_name` 探测主机；`cmake_minimum_required`/`cmake_policy` 管版本与策略；`cmake_parse_arguments` 让自定义命令拥有具名参数。

掌握这些命令后，你既能写出健壮的独立 `.cmake` 脚本，也能在工程中游刃有余地处理变量、文件与外部进程。下一章转向只在构建工程中生效的 **项目命令**。
