# 汇编指令集对比总览

本页是 5 种主流指令集架构（ISA）汇编笔记的统一入口，并从横向维度对它们做对比。逐篇详解见文末链接。

## 五架构速览

| 架构 | 代表实现 | 通用寄存器 | 地址空间（64 位实现） | 指令长度 | 整数标志位机制 | 设计风格 | 典型应用 |
|------|---------|-----------|----------------------|---------|---------------|---------|---------|
| [[21.Asm/11 ARM.md\|ARM]] | AArch32 / AArch64 | 16×32 位 / 32×64 位 | 通常 48 位（256TB） | 定长 32 位（Thumb 16/32） | 专用 NZCV 标志 | RISC | 移动设备、嵌入式、服务器 |
| [[21.Asm/12 MIPS.md\|MIPS]] | MIPS32 / MIPS64 | 32×32 位 / 32×64 位 | 理论 2^64 | 定长 32 位 | 无标志位（slt + 分支） | RISC | 嵌入式、网络设备、教学 |
| [[21.Asm/13 LoongArch64.md\|LoongArch]] | LoongArch32 / 64 | 32×32 位 / 32×64 位 | 48 位（256TB） | 定长 32 位 | 无整数标志（slt + 分支，浮点用 fcc） | RISC | 国产 PC、服务器 |

## 横向对比要点

### 1. 标志位与条件判断
- **x86**：CISC 代表，算术/逻辑指令隐式更新 CF/ZF/SF/OF 等，再由 `Jcc`/`SETcc`/`CMOVcc` 消费。
- **ARM**：保留专用条件标志 NZCV；AArch32 几乎所有指令可加条件后缀，AArch64 收敛为条件选择类指令（CSEL/CSET）。
- **MIPS / LoongArch / RISC-V**：彻底的 RISC 思路，**没有整数标志位**，用 `slt` 系列产生布尔值再配合分支。其中 **RISC-V 的分支指令可直接比较两个寄存器**（`blt`/`bge` 等），比 MIPS 少一条 `slt`；LoongArch 浮点比较结果写入专门的 fcc 条件标志，RISC-V 则写入整数寄存器。

### 2. 指令编码
- **定长 32 位**：ARM(AArch64)、MIPS、LoongArch、RISC-V —— 译码简单，利于流水线（RISC-V 的 C 扩展、ARM 的 Thumb 另有 16 位压缩编码）。
- **变长**：x86（1–15 字节）—— 代码密度高，但译码复杂。

### 3. 32 位 → 64 位的扩展方式
- **ARM**：AArch32 与 AArch64 几乎是两套指令集，寄存器从 16 个增至 32 个。
- **MIPS**：新增 `d` 前缀指令（dadd、dmult、dsll 等），比较类指令保持原名。
- **LoongArch**：新增 `.d` 后缀的 64 位操作指令（add.d、ld.d 等）。
- **RISC-V**：基础整数指令直接按 XLEN 运算，另加 `*w` 字指令（addw、sllw 等）高效处理 32 位值，并新增 ld/sd/lwu。
- **x86**：通过 REX 前缀启用 64 位操作数与扩展寄存器（R8–R15），写 32 位子寄存器自动零扩展。

### 4. 函数调用约定（64 位）
- **ARM AArch64**：X0–X7 传整数参数。
- **MIPS**：$a0–$a3（O32）/ 扩展 ABI 提供更多参数寄存器。
- **LoongArch**：$a0–$a7（r4–r11）传参。
- **RISC-V**：a0–a7（x10–x17）传参，a0–a1 兼返回值，栈 16 字节对齐。
- **x86-64**：Windows x64 用 RCX/RDX/R8/R9；System V（Linux/macOS）用 RDI/RSI/RDX/RCX/R8/R9 —— 二者不兼容，需特别注意。

### 5. 开放性与生态
- **x86**：Intel / AMD 专有。
- **ARM**：ARM 公司 IP 授权模式。
- **MIPS**：历史上商业授权，后期转向开放。
- **LoongArch**：龙芯自主，规范公开。
- **RISC-V**：完全开放、免版税的开放标准。
