# 寻址模式专题

**寻址模式**＝指令如何算出操作数在内存中的地址。它是 CISC 与 RISC 分野最直观的一处：x86 一条指令能算 `base + index×scale + disp`，而 RISC-V 只允许 `base + 偏移`，复杂地址得用通用指令显式拼出来。本页横向对比五大架构的寻址能力，并落到「**同一个 `arr[i]` 访问**」看梯度差异。

## x86：最丰富的 SIB 寻址

x86 的通用内存操作数形如 `disp(base, index, scale)`，**有效地址 = base + index×scale + disp**：

| 模式 | 写法（AT&T） | 含义 |
|------|-------------|------|
| 立即数 | `$0x10` | 常量本身 |
| 寄存器 | `%rax` | 寄存器值 |
| 寄存器间接 | `(%rax)` | M[rax] |
| 基址+偏移 | `8(%rbp)` | M[rbp+8] |
| 基址+变址 | `(%rax,%rcx)` | M[rax+rcx] |
| **完整 SIB** | `8(%rax,%rcx,4)` | M[rax + rcx×4 + 8] |
| RIP 相对（x86-64） | `sym(%rip)` | M[RIP+sym]，PIC 用 |

> `scale ∈ {1,2,4,8}` 恰好对应 1/2/4/8 字节元素。一条 `mov 8(%rax,%rcx,4), %edx` 就能取 `struct.arr[i]`——CISC 寻址威力的代表，但也是变长译码复杂的来源之一。

## ARM64：前/后变址是实用特色

| 模式 | 写法 | 含义 |
|------|------|------|
| 立即偏移 | `[Xn, #imm]` | M[Xn+imm] |
| 寄存器偏移 | `[Xn, Xm]` | M[Xn+Xm] |
| 扩展/移位偏移 | `[Xn, Xm, LSL #3]`、`[Xn, Wm, SXTW #2]` | M[Xn + (Xm<<3)]；Wm 符号扩展再缩放 |
| **前变址**（回写） | `[Xn, #imm]!` | 先 Xn+=imm，再访问新地址 |
| **后变址**（回写） | `[Xn], #imm` | 先访问 Xn，再 Xn+=imm |
| PC 相对 | `ldr Xt, label` / `adr`/`adrp` | 文字池 / PC 相对取址 |

> **前/后变址**是 ARM 在 RISC 框架里保留的高价值便利：`ldr x0, [x1], #8` 一条边遍历边步进；压栈 `stp x29, x30, [sp, #-16]!` 一条完成「下移 sp + 存」。`SXTW` 让「`int` 索引符号扩展再缩放」内联进访存。

## RISC-V：最精简——唯一 base+偏移

RISC-V **只有一种**访存寻址：`imm(rs1)` = rs1 + 符号扩展的 12 位立即数。

```asm
    lw   t0, 8(a0)     # t0 = M[a0+8]，仅此一种形式
```

**没有寄存器变址、没有比例、没有前/后变址。** 复杂地址必须用通用整数指令显式算出来。这是极致 load-store 哲学：访存指令只做最简单的事，地址运算交给通用指令，换取编码规整、流水线友好。PC 相对靠 `auipc`（`la` 伪指令即其展开）。

## LoongArch：居中——三种寻址模式

LoongArch 访存比纯 RISC 丰富，官方分**三族**（已核实）：

| 族 | 格式 | 写法 | 含义 |
|----|------|------|------|
| `ld.w`/`st.w` 等 | 2RI12 | `ld.w rd, rj, si12` | rj + 12 位立即偏移 |
| `ldx.w`/`stx.w` 等 | 3R | `ldx.w rd, rj, rk` | **rj + rk（寄存器变址）** |
| `ldptr.w`/`stptr.w` | 2RI14 | `ldptr.w rd, rj, si14` | rj + 14 位移位偏移，**为 PIC/GOT 设计**（配 `addu16i.d` 加速） |

> 比 RISC-V/MIPS 多了**寄存器变址 `ldx`**（运行时索引数组省一条 `add`）和**指针寻址 `ldptr`**；另有 `preld`/`preldx` 预取。PC 相对用 `pcaddi`/`pcalau12i`。LoongArch 在 x86 的"全能 SIB"与纯 RISC 的"只有 base+offset"之间取了折中。

## MIPS：精简但偏移更宽

```asm
    lw   $t0, 8($sp)   # $t0 = M[sp+8]，唯一形式：offset(base)
```

与 RISC-V 同样只有 `base + 偏移`，但**立即偏移是 16 位**（±32KB，比 RISC-V/LoongArch 的 12 位更宽）。无变址、无比例、无前后变址。经典 MIPS 无 PC 相对寻址，**MIPS R6** 才补上 `addiupc`/`auipc` 等。

## 对照表

| 寻址模式 | x86 | ARM64 | RISC-V | LoongArch | MIPS |
|----------|-----|-------|--------|-----------|------|
| 立即偏移 base+disp | ✓ | ✓ | ✓ | ✓ | ✓ |
| 寄存器变址 base+index | ✓ | ✓ | ✗ | ✓（`ldx`） | ✗ |
| 比例变址 ×{1,2,4,8} | ✓（SIB） | ✓（LSL/扩展） | ✗ | ✗ | ✗ |
| 前变址（回写） | ✗ | ✓ | ✗ | ✗ | ✗ |
| 后变址（回写） | ✗ | ✓ | ✗ | ✗ | ✗ |
| PC 相对 | ✓（RIP） | ✓（adr/literal） | ✓（auipc） | ✓（pcaddi/ldptr） | R6 ✓ |
| 立即偏移位宽 | 8/32 位 | 9/12 位※ | 12 位 | 12 位（`ld`）/14 位（`ldptr`） | 16 位 |

※ ARM64 偏移随指令而异：无缩放约 ±256（9 位），缩放后 12 位。

## 同一个 `arr[i]` 的访问梯度

最能体现差异：取 `int arr[i]`（基址在第一参数，索引在第二参数）——从 x86 一条到 RISC-V/MIPS 三条：

```asm
# x86：一条搞定（SIB，scale=4）
    mov    (%rdi,%rsi,4), %eax        # eax = arr[i]

# ARM64：扩展寄存器偏移，一条（lsl #2 = ×4）
    ldr    w0, [x0, x1, lsl #2]       # w0 = arr[i]

# LoongArch：ldx 寄存器变址，先算字节偏移（省了 add）
    slli.d $t1, $a1, 2                # t1 = i*4
    ldx.w  $t0, $a0, $t1              # t0 = arr[i]

# RISC-V：必须显式算地址（无变址）
    slli   t1, a1, 2                  # t1 = i*4
    add    t1, a0, t1                 # t1 = &arr[i]
    lw     t0, 0(t1)                  # t0 = arr[i]

# MIPS：同样显式算地址
    sll    $t1, $a1, 2
    addu   $t1, $a0, $t1
    lw     $t0, 0($t1)
```

梯度一目了然：**x86（1 条 SIB）→ ARM64（1 条带缩放）→ LoongArch（ldx，2 条）→ RISC-V/MIPS（3 条）**。

## 设计哲学与位宽影响

1. **复杂度放哪**：CISC 把寻址交给**硬件译码器（运行期）**，单指令做更多；RISC 把它交给**通用指令/编译器（编译期）**，指令多但规整——与伪指令、代码密度同源（见 [[21.Asm/22 伪指令与宏汇编对照.md|伪指令]]、[[21.Asm/30 各架构性能特性对比.md|性能特性对比]]）。
2. **ARM 的折中最实用**：前/后变址 + 扩展寄存器偏移，覆盖了数组遍历、栈操作、`int` 索引等高频场景，是 RISC 里性价比极高的补充。
3. **偏移位宽决定单指令可达范围**：RISC-V/LoongArch 12 位（±2KB）、MIPS 16 位（±32KB）；**超范围需多条指令拼地址**（`lui`+`addi` / `lu12i.w`+…），大栈帧、结构体大偏移字段会触发这种展开——这正是大立即数需要伪指令的根源（呼应 [[21.Asm/22 伪指令与宏汇编对照.md|伪指令]]）。

## 总结

- 寻址模式从丰富到精简：**x86（全能 SIB）＞ ARM64（前后变址+扩展偏移）＞ LoongArch（+ldx/ldptr）＞ RISC-V/MIPS（仅 base+offset）**。
- 同一数组访问，CISC 一条、纯 RISC 三条，是寻址哲学的直接量度。
- 偏移位宽限定单指令触及范围，超出即落回多指令地址计算——与代码密度、伪指令的取舍一脉相承。
