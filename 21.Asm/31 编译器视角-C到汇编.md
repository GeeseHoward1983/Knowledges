# 编译器视角：C 语句 → 各架构汇编

本页是一篇**综合应用**：看编译器把常见 C 构造翻译成各架构汇编长什么样，借此把前面的标志位、寻址模式、调用约定、条件执行、位运算等专题串成一条线。

> 说明：以下汇编为 **GCC `-O2` 风格的示意**，实际输出随编译器、版本、优化级别而变；寄存器分配也会不同。重点看**结构差异**而非逐字节对应。x86 用 AT&T 语法。

## 1. 算术与返回值

```c
int add(int a, int b) { return a + b; }
```

```asm
# x86-64（a=edi, b=esi → eax）
add:  lea  (%rdi,%rsi), %eax        # 用 LEA 顺带完成加法
      ret
# ARM64（a=w0, b=w1 → w0）
add:  add  w0, w0, w1
      ret
# RISC-V（a=a0, b=a1）：RV64 下 32 位运算用 addw 保证符号扩展
add:  addw a0, a0, a1
      ret
# LoongArch（a=$a0, b=$a1）
add:  add.w $a0, $a0, $a1
      jr    $ra
# MIPS（a=$a0, b=$a1 → $v0）
add:  addu  $v0, $a0, $a1
      jr    $ra
      nop                            # ← 分支延迟槽
```

> 细节：RV64/LA64 处理 `int`（32 位）要用 `addw`/`add.w` 而非 64 位加，以正确产生符号扩展结果（见 [[21.Asm/01 汇编指令集对比.md|对比总览]] 的 32→64 扩展段）；MIPS `jr $ra` 后有延迟槽。

## 2. 条件分支（if）

```c
int branch(int a, int b) { if (a < b) return 1; return 0; }
```

各架构「比较 + 分支」正是标志位哲学的分水岭：

```asm
# x86：cmp 设 EFLAGS，再条件跳转
      cmp  %esi, %edi
      jl   .L1                # a<b 跳
# ARM64：cmp 设 NZCV，再条件分支
      cmp  w0, w1
      b.lt .L1
# RISC-V：分支指令直接比较两寄存器（无标志、少一条）
      blt  a0, a1, .L1
# LoongArch：同样分支直接比较
      blt  $a0, $a1, .L1
# MIPS：无 < 分支，先 slt 出布尔，再 bne
      slt  $t0, $a0, $a1
      bne  $t0, $zero, .L1
      nop
```

> **RISC-V/LoongArch 的 `blt` 一条到位**，MIPS 需 `slt`+`bne` 两条，x86/ARM 需 `cmp`+`Jcc`/`b.cc` 两条且经过标志位——这正是 [[21.Asm/01 汇编指令集对比.md|总览]] 标志位对比的实证。

## 3. for 循环 + 数组访问

```c
int sum(int *a, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += a[i];
    return s;
}
```

循环体里的 `a[i]` 访问，把 [[21.Asm/21 寻址模式专题.md|寻址模式]] 的差异暴露得淋漓尽致：

```asm
# x86-64：SIB 寻址，a[i] 一条到位
sum:  xor  %eax, %eax              # s=0
      xor  %ecx, %ecx              # i=0
.L:   add  (%rdi,%rcx,4), %eax     # s += a[i]，base+index*4
      inc  %ecx
      cmp  %esi, %ecx
      jl   .L
      ret

# ARM64：移位内联进寻址
sum:  mov  w2, #0
      mov  x3, #0
.L:   ldr  w4, [x0, x3, lsl #2]    # a[i]，lsl #2 内嵌
      add  w2, w2, w4
      add  x3, x3, #1
      cmp  w3, w1
      b.lt .L
      mov  w0, w2
      ret

# RISC-V：无变址寻址，必须显式算地址（多 2 条）
sum:  li   a2, 0
      li   a3, 0
.L:   slli t0, a3, 2               # i*4
      add  t0, a0, t0              # &a[i]
      lw   t1, 0(t0)              # a[i]
      addw a2, a2, t1
      addiw a3, a3, 1
      blt  a3, a1, .L
      mv   a0, a2
      ret
```

> 同一个 `a[i]`：x86 一条、ARM 一条（移位内联）、RISC-V 三条——CISC 把寻址交给硬件，RISC 交给通用指令（LoongArch 居中，可用 `ldx.w` 省一条）。

## 4. 三元运算符 → 条件选择（五种风格）

```c
int max(int a, int b) { return a > b ? a : b; }
```

「按条件二选一」最能体现各架构的**条件执行**设计，五家五样：

```asm
# x86：条件传送 CMOV（无分支）
max:  mov   %edi, %eax
      cmp   %esi, %edi
      cmovl %esi, %eax           # 若 a<b 则取 b
      ret
# ARM64：条件选择 CSEL（无分支）
max:  cmp   w0, w1
      csel  w0, w0, w1, gt       # w0 = (a>b)?a:b
      ret
# RISC-V（基础集）：只能分支；有 Zbb 时一条 max a0,a0,a1
max:  blt   a1, a0, .keep        # a>b 则保留 a0
      mv    a0, a1
.keep: ret
# LoongArch：无条件传送，用 maskeqz/masknez 拼无分支选择
max:  slt     $t0, $a1, $a0      # t0 = (a>b)
      maskeqz $t1, $a0, $t0      # t0? a:0
      masknez $t2, $a1, $t0      # t0? 0:b
      or      $a0, $t1, $t2
      jr      $ra
# MIPS：条件传送 movn（MIPS R6 改用 seleqz/selnez）
max:  slt   $t0, $a1, $a0
      move  $v0, $a1
      movn  $v0, $a0, $t0        # 若 t0!=0 则 v0=a0
      jr    $ra
      nop
```

> 五种「条件二选一」：x86 `CMOV`、ARM `CSEL`、RISC-V 分支（或 Zbb `max`）、LoongArch `maskeqz/masknez`、MIPS `movn/movz`——无分支的条件选择能避免分支误预测（见 [[21.Asm/30 各架构性能特性对比.md|性能特性]]）。

## 5. 函数调用与 switch

**函数调用**：编译器按 [[21.Asm/23 调用约定对比.md|调用约定]] 把实参装进参数寄存器，再 `call`(x86)/`bl`(ARM)/`jal`(RISC-V)/`bl`(LoongArch)/`jal`(MIPS)，返回值取自 `rax`/`x0`/`a0`/`$a0`/`$v0`。非叶函数序言里要保存返回地址寄存器（见 [[21.Asm/33 逆向反汇编速查.md|逆向速查]] 的序言/尾声）。

**switch**：稠密 `case` 编译器多用**跳转表**——O(1) 间接跳转；稀疏则退化为比较链或二分。

```asm
# x86-64 稠密 switch：越界查默认，否则按值索引跳转表
      cmp   $3, %edi
      ja    .Ldefault
      jmp   *.Ltable(,%rdi,8)     # 按 x 跳
.Ltable: .quad .L0, .L1, .L2, .L3
```

> 跳转表是逆向时还原 `switch` 的关键特征（见 [[21.Asm/33 逆向反汇编速查.md|逆向速查]] 的常见模式）。

## 6. 编译器优化要点（读汇编时常见）

- **强度削减**：`x*8`→`x<<3`、`x/2`→算术右移、`x%2`→`and 1`——乘除化为移位/位运算（见 [[21.Asm/25 位操作与移位指令对比.md|位操作]]）。
- **常量折叠/传播**：编译期能算的不留到运行期。
- **公共子表达式消除 / 循环不变量外提**：重复计算只做一次、不变量移出循环。
- **内联与尾调用**：小函数内联消除调用开销；尾调用用 `jmp`/`b` 复用栈帧。
- **寄存器分配**：寄存器越多越少 spill（见 [[21.Asm/30 各架构性能特性对比.md|性能特性]]），x86-64 的 16 个 vs RISC 的 32 个在此体现。

## 总结

- 简单算术五架构高度相似；差异从**条件分支**（标志位 vs 直接比较）、**数组寻址**（SIB vs 多条算地址）、**条件选择**（CMOV/CSEL/maskeqz/movn/分支）开始显现。
- 这页的每个例子都指回某个专题：if→标志位、`a[i]`→寻址模式、`?:`→条件执行、调用→调用约定、`*8`→位移、switch→跳转表。
- 想真正读懂汇编，**对照 C 源码看编译器输出**（`gcc -O2 -S` 或反汇编）是最快的路径。
