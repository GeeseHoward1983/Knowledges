# x86 汇编指令详解：32 位与 64 位对比及标志位分析

## x86 汇编指令分类详解

### 1. 数据传输指令
这些指令用于在寄存器、内存和立即数之间移动数据：
- `MOV` - 将数据从源操作数复制到目标操作数
- `PUSH` - 将值推入堆栈
- `POP` - 从堆栈弹出值
- `PUSHA/PUSHAD` - 推入所有通用寄存器（仅 16/32 位模式，64 位下不可用）
- `POPA/POPAD` - 弹出所有通用寄存器（仅 16/32 位模式，64 位下不可用）
- `XCHG` - 交换两个操作数的值
- `XLAT/XLATB` - 查表转换

示例：
```asm
mov eax, ebx      ; 将ebx的值复制到eax
push ecx          ; 将ecx压入堆栈
pop edx           ; 将堆栈顶部的值弹出到edx
```

### 2. 算术运算指令
这些指令执行数学运算：
- `ADD` - 加法
- `SUB` - 减法
- `INC` - 增加 1
- `DEC` - 减少 1
- `NEG` - 取负数
- `CMP` - 比较两个值
- `MUL` - 无符号乘法
- `IMUL` - 有符号乘法
- `DIV` - 无符号除法
- `IDIV` - 有符号除法

#### DIV（无符号除法）
- **字节操作数**：被除数在 AX 寄存器中，除数可以是内存操作数或寄存器。结果：商存入 AL，余数存入 AH
- **字操作数**：被除数在 DX:AX 中（DX 存高 16 位，AX 存低 16 位），除数可以是内存操作数或寄存器。结果：商存入 AX，余数存入 DX
- **双字操作数**：被除数在 EDX:EAX 中（EDX 存高 32 位，EAX 存低 32 位），除数可以是内存操作数或寄存器。结果：商存入 EAX，余数存入 EDX
- **四字操作数（64 位模式）**：被除数在 RDX:RAX 中（RDX 存高 64 位，RAX 存低 64 位），除数可以是内存操作数或寄存器。结果：商存入 RAX，余数存入 RDX

#### IDIV（有符号除法）
- **字节操作数**：被除数在 AX 寄存器中，除数可以是内存操作数或寄存器。结果：商存入 AL，余数存入 AH
- **字操作数**：被除数在 DX:AX 中（DX 存高 16 位，AX 存低 16 位），除数可以是内存操作数或寄存器。结果：商存入 AX，余数存入 DX
- **双字操作数**：被除数在 EDX:EAX 中（EDX 存高 32 位，EAX 存低 32 位），除数可以是内存操作数或寄存器。结果：商存入 EAX，余数存入 EDX
- **四字操作数（64 位模式）**：被除数在 RDX:RAX 中（RDX 存高 64 位，RAX 存低 64 位），除数可以是内存操作数或寄存器。结果：商存入 RAX，余数存入 RDX

注意：当除法结果溢出（商太大无法存入目标寄存器）时，处理器会产生 #DE（除法错误异常，向量 0）。在执行除法前，通常需要确保被除数已经被正确扩展（如用 CDQ/CQO 符号扩展），以便适应除法指令的约定。

示例：
```asm
; 无符号字节除法
mov ax, 257      ; 被除数为257
mov bl, 10       ; 除数为10
div bl           ; AL=25(商), AH=7(余数)

; 无符号字除法
mov dx, 0        ; 被除数高16位
mov ax, 1000     ; 被除数低16位
mov bx, 100      ; 除数
div bx           ; AX=10(商), DX=0(余数)

; 有符号双字除法
mov edx, 0       ; 被除数高32位
mov eax, 100000  ; 被除数低32位
mov ebx, -100    ; 除数
idiv ebx         ; EAX=-1000(商), EDX=0(余数)
```

### 3. 逻辑运算指令
这些指令执行布尔操作：
- `AND` - 逻辑与
- `OR` - 逻辑或
- `XOR` - 逻辑异或
- `NOT` - 逻辑非
- `TEST` - 测试位（AND 但不保存结果）

示例：
```asm
and eax, 0xFF     ; eax = eax AND 0xFF
xor eax, eax      ; 清零eax（最常用的方法）
```

### 4. 移位和循环移位指令
这些指令移动位的位置：
- `SHL/SAL` - 逻辑/算术左移
- `SHR` - 逻辑右移
- `SAR` - 算术右移
- `ROL` - 循环左移
- `ROR` - 循环右移
- `RCL` - 带进位循环左移
- `RCR` - 带进位循环右移

### 5. 控制转移指令
这些指令改变程序的执行流程：
- `JMP` - 无条件跳转
- `JE/JZ` - 相等/零时跳转
- `JNE/JNZ` - 不相等/非零时跳转
- `JA/JNBE` - 大于/不低于等于时跳转（无符号）
- `JB/JNAE` - 小于/不高于等于时跳转（无符号）
- `JG/JNLE` - 大于/不小于等于时跳转（有符号）
- `JL/JNGE` - 小于/不大于等于时跳转（有符号）
- `CALL` - 调用子程序
- `RET` - 从子程序返回

### 6. 字符串指令
用于处理字符串操作：
- `MOVS` - 移动字符串
- `LODS` - 加载字符串
- `STOS` - 存储字符串
- `CMPS` - 比较字符串
- `SCAS` - 扫描字符串

### 7. 栈操作指令
- `ENTER` - 进入过程框架
- `LEAVE` - 离开过程框架

### 8. 系统指令
用于操作系统级功能：
- `INT` - 中断调用
- `IRET` - 中断返回
- `CLI` - 清除中断标志
- `STI` - 设置中断标志
- `HLT` - 停机

## x86 架构内存寻址方式详解

x86 架构提供了多种灵活的内存寻址方式，允许程序员以不同的方式访问内存位置。这些寻址方式在 32 位和 64 位模式下略有不同，但在概念上是相似的。

### 1. 直接寻址（Direct Addressing）

直接寻址是指令中直接包含内存地址的方式。在操作数中指定的是内存位置的有效地址（偏移量）。

```asm
mov eax, [0x401000]    ; 将地址0x401000处的值加载到EAX
mov [buffer], eax      ; 将EAX的值存储到名为buffer的内存地址
```

在直接寻址中，指令明确指出要访问的内存地址。方括号表示间接寻址，即地址中的内容，而不是地址本身。

### 2. 寄存器间接寻址（Register Indirect Addressing）

寄存器间接寻址使用寄存器的值作为内存地址。

```asm
mov eax, [ebx]         ; 将EBX寄存器中地址指向的内存值加载到EAX
mov [esi], edx         ; 将EDX的值存储到ESI寄存器中地址指向的内存
```

### 3. 寄存器相对寻址（Register Relative Addressing）

这种寻址方式将寄存器的值加上一个偏移量作为内存地址。

```asm
mov eax, [ebx + 8]     ; 将EBX+8地址处的值加载到EAX
mov [ebp - 4], ecx     ; 将ECX的值存储到EBP-4地址处
```

### 4. 基址变址寻址（Based Indexed Addressing）

使用两个寄存器，一个作为基址寄存器，另一个作为变址寄存器。

```asm
mov eax, [ebx + esi]   ; 将EBX+ESI地址处的值加载到EAX
mov [edi + ecx], eax   ; 将EAX的值存储到EDI+ECX地址处
```

### 5. 相对基址变址寻址（Relative Based Indexed Addressing）

这是较复杂的寻址方式，结合了基址、变址和偏移量。

```asm
mov eax, [ebx + esi + 10]   ; 将EBX+ESI+10地址处的值加载到EAX
mov [ebp + edi - 8], edx    ; 将EDX的值存储到EBP+EDI-8地址处
```

### 6. 比例变址寻址（Scaled Index Addressing）

这种寻址方式允许变址寄存器乘以比例因子（1、2、4 或 8），常用于数组访问。

```asm
mov eax, [ebx + esi*4]      ; 将EBX+ESI*4地址处的值加载到EAX（访问DWORD数组）
mov [edi + ecx*2 + 100], ax ; 将AX的值存储到EDI+ECX*2+100地址处（访问WORD数组）
```

### 7. 完整的寻址公式

x86 内存操作数的一般形式是：`[Base + Index * Scale + Displacement]`

其中：
- Base：基址寄存器（EAX, EBX, ECX, EDX, ESI, EDI, EBP, ESP 之一）
- Index：变址寄存器（EAX, EBX, ECX, EDX, ESI, EDI, EBP 之一，但不能是 ESP）
- Scale：比例因子（1, 2, 4, 或 8）
- Displacement：位移量（8 位或 32 位的有符号值）

例如：
```asm
mov eax, [ebx + ecx*4 - 12]  ; 完整的寻址模式示例
```

### 8. 64 位模式下的扩展寻址

在 64 位模式下，寻址方式得到了扩展，可以使用更多的寄存器，并新增了 RIP 相对寻址：
- 基址寄存器：RAX, RBX, RCX, RDX, RSI, RDI, RBP, RSP, R8-R15
- 变址寄存器：RAX, RBX, RCX, RDX, RSI, RDI, RBP, R8-R15（RSP 除外）

```asm
mov rax, [rbx + rcx*8 + 16]  ; 64位模式下的寻址
mov [r8 + r9*4], edx         ; 使用扩展寄存器的寻址
mov rax, [rip + var]         ; RIP相对寻址（64位新增，常用于位置无关代码）
```

### 9. 段寄存器前缀

在保护模式下，虽然默认段通常是数据段（DS），但仍可以通过段寄存器前缀指定其他段：

```asm
mov eax, [fs:0x30]      ; 从FS段的0x30偏移处加载
mov [gs:variable], ebx  ; 将EBX存储到GS段的variable偏移处
```

## 32 位与 64 位 x86 汇编的主要区别

### 1. 寄存器扩展
**32 位（IA-32）：**
- 8 个通用寄存器：EAX、EBX、ECX、EDX、ESI、EDI、ESP、EBP
- 每个寄存器为 32 位大小

**64 位（x86-64）：**
- 16 个通用寄存器：RAX、RBX、RCX、RDX、RSI、RDI、RSP、RBP、R8-R15
- 每个寄存器为 64 位大小
- 新增 8 个寄存器（R8-R15）

### 2. 地址空间
**32 位：**
- 最大支持 4GB 物理内存（开启 PAE 后物理可更大，但单进程线性地址仍为 4GB）
- 32 位地址空间

**64 位：**
- 理论上支持高达 2^64 字节的内存
- 当前实现通常支持 48 位地址空间（256TB）

### 3. 参数传递
**32 位（常见 cdecl 约定）：**
- 参数通过堆栈传递
- 调用者负责清理堆栈

**64 位（Windows x64 调用约定）：**
- 前四个整数参数通过寄存器 RCX、RDX、R8、R9 传递
- 浮点参数通过 XMM0-XMM3 传递
- 其余参数通过堆栈传递
- **调用者**负责清理堆栈，并需为前四个参数预留 32 字节 “shadow space”

**64 位（System V AMD64 调用约定，Linux/macOS）：**
- 前六个整数参数通过 RDI、RSI、RDX、RCX、R8、R9 传递
- 前八个浮点参数通过 XMM0-XMM7 传递
- 其余参数通过堆栈传递，**调用者**负责清理堆栈

### 4. 指令指针和栈指针
**32 位：**
- EIP（指令指针）是 32 位
- ESP（栈指针）是 32 位

**64 位：**
- RIP（指令指针）是 64 位
- RSP（栈指针）是 64 位

### 5. 操作数大小
在 64 位模式下，某些默认行为有所不同：
- 对 32 位寄存器的写入会自动零扩展到对应的 64 位寄存器（如写 EAX 会清零 RAX 高 32 位）
- 默认操作数大小通常仍为 32 位，需 REX.W 前缀才使用 64 位操作数

### 6. 新指令和功能
**64 位扩展增加了：**
- 64 位操作数大小支持
- RIP 相对寻址
- 更多的 SIMD 指令支持

### 示例对比
**32 位代码：**
```asm
mov eax, [ebp+8]      ; 从堆栈获取第一个参数
add eax, [ebp+12]     ; 加上第二个参数
```

**64 位代码（System V）：**
```asm
mov rax, rdi          ; 第一个参数在RDI中
add rax, rsi          ; 加上第二个参数（在RSI中）
```

### 7. 模式切换
处理器可以在不同模式间切换：
- 实模式（16 位）
- 保护模式（32 位）
- 长模式（64 位），包括：
  - 兼容子模式（运行 32 位代码）
  - 64 位子模式

## 标志位详解

### 状态标志位
- **CF (Carry Flag)** - 进位标志：当算术运算导致最高有效位产生进位或借位时设置
- **PF (Parity Flag)** - 奇偶标志：当结果最低字节中有偶数个 1 时设置
- **AF (Auxiliary Carry Flag)** - 辅助进位标志：当低 4 位向高 4 位产生进位时设置
- **ZF (Zero Flag)** - 零标志：当结果为零时设置
- **SF (Sign Flag)** - 符号标志：当结果为负数时设置
- **OF (Overflow Flag)** - 溢出标志：当有符号算术运算溢出时设置

### 控制标志位
- **TF (Trap Flag)** - 单步陷阱标志：启用单步调试模式
- **IF (Interrupt Flag)** - 中断允许标志：控制可屏蔽中断
- **DF (Direction Flag)** - 方向标志：控制字符串操作的方向

### 系统标志位
- **IOPL (I/O Privilege Level)** - I/O 特权级
- **NT (Nested Task)** - 嵌套任务标志
- **RF (Resume Flag)** - 恢复标志
- **VM (Virtual 8086 Mode)** - 虚拟 8086 模式
- **AC (Alignment Check)** - 对齐检查
- **VIF (Virtual Interrupt Flag)** - 虚拟中断标志
- **VIP (Virtual Interrupt Pending)** - 虚拟中断等待
- **ID (ID Flag)** - 标识标志

## XMM 指令（SSE 指令集）

SSE（Streaming SIMD Extensions）指令集引入了 128 位宽的 XMM 寄存器，用于并行处理多个数据元素。

### SSE 指令分类

#### 1. 数据传输指令
- `MOVAPS` - 在 XMM 寄存器和内存之间移动打包的单精度值（要求 16 字节对齐）
- `MOVUPS` - 移动未对齐的打包单精度值
- `MOVLPS` - 移动低打包单精度值
- `MOVHPS` - 移动高打包单精度值
- `MOVSS` - 移动标量单精度值
- `MOVAPD` - 移动打包双精度值（对齐）
- `MOVUPD` - 移动未对齐的打包双精度值
- `MOVLPD` - 移动低双精度值
- `MOVHPD` - 移动高双精度值
- `MOVSD` - 移动标量双精度值

#### 2. 算术指令
- `ADDPS` - 加法打包单精度
- `ADDPD` - 加法打包双精度
- `ADDSS` - 加法标量单精度
- `ADDSD` - 加法标量双精度
- `SUBPS` - 减法打包单精度
- `SUBPD` - 减法打包双精度
- `SUBSS` - 减法标量单精度
- `SUBSD` - 减法标量双精度
- `MULPS` - 乘法打包单精度
- `MULPD` - 乘法打包双精度
- `MULSS` - 乘法标量单精度
- `MULSD` - 乘法标量双精度
- `DIVPS` - 除法打包单精度
- `DIVPD` - 除法打包双精度
- `DIVSS` - 除法标量单精度
- `DIVSD` - 除法标量双精度
- `SQRTPS` - 平方根打包单精度
- `SQRTPD` - 平方根打包双精度
- `SQRTSS` - 平方根标量单精度
- `SQRTSD` - 平方根标量双精度

#### 3. 比较指令
- `CMPPS` - 比较打包单精度
- `CMPPD` - 比较打包双精度
- `CMPSS` - 比较标量单精度
- `CMPSD` - 比较标量双精度
- `COMISS` - 比较有序标量单精度并设置标志
- `COMISD` - 比较有序标量双精度并设置标志
- `UCOMISS` - 无序比较标量单精度并设置标志
- `UCOMISD` - 无序比较标量双精度并设置标志

#### 4. 逻辑指令
- `ANDPS` - 逻辑与打包单精度
- `ANDPD` - 逻辑与打包双精度
- `ANDNPS` - 逻辑与非打包单精度
- `ANDNPD` - 逻辑与非打包双精度
- `ORPS` - 逻辑或打包单精度
- `ORPD` - 逻辑或打包双精度
- `XORPS` - 逻辑异或打包单精度
- `XORPD` - 逻辑异或打包双精度

#### 5. 转换指令
- `CVTPS2PI` - 转换打包单精度到打包整数（MMX）
- `CVTPD2PI` - 转换打包双精度到打包整数（MMX）
- `CVTSI2SS` - 转换整数到标量单精度
- `CVTSI2SD` - 转换整数到标量双精度
- `CVTPI2PS` - 转换打包整数（MMX）到打包单精度
- `CVTPI2PD` - 转换打包整数（MMX）到打包双精度
- `CVTTSS2SI` - 截断标量单精度到整数
- `CVTTSD2SI` - 截断标量双精度到整数
- `CVTTPS2PI` - 截断打包单精度到打包整数（MMX）
- `CVTTPD2PI` - 截断打包双精度到打包整数（MMX）

#### 6. 杂项指令
- `SHUFPS` - 洗牌打包单精度
- `SHUFPD` - 洗牌打包双精度
- `UNPCKLPS` - 解包低打包单精度
- `UNPCKLPD` - 解包低打包双精度
- `UNPCKHPS` - 解包高打包单精度
- `UNPCKHPD` - 解包高打包双精度
- `MAXPS` - 最大值打包单精度
- `MAXPD` - 最大值打包双精度
- `MINPS` - 最小值打包单精度
- `MINPD` - 最小值打包双精度

## FPU（浮点单元）指令

FPU 指令集用于处理浮点数运算，使用 8 个 80 位的 ST(0) 到 ST(7) 寄存器组成的栈结构。

### FPU 数据传输指令
- `FLD` - 加载浮点数到栈顶
- `FST` - 存储浮点数（复制）
- `FSTP` - 存储浮点数（弹出）
- `FXCH` - 交换浮点寄存器
- `FLD1` - 加载常数 1
- `FLDZ` - 加载常数 0
- `FLDCW` - 加载控制字
- `FSTCW` - 存储控制字
- `FNSTCW` - 无检查存储控制字
- `FSTSW` - 存储状态字
- `FNSTSW` - 无检查存储状态字
- `FFREE` - 释放浮点寄存器

### FPU 算术指令
- `FADD` - 浮点加法
- `FIADD` - 整数加法（整数到浮点转换）
- `FADDP` - 加法并弹出
- `FSUB` - 浮点减法
- `FSUBP` - 减法并弹出
- `FSUBR` - 反向减法
- `FSUBRP` - 反向减法并弹出
- `FMUL` - 浮点乘法
- `FIMUL` - 整数乘法
- `FMULP` - 乘法并弹出
- `FDIV` - 浮点除法
- `FIDIV` - 整数除法
- `FDIVP` - 除法并弹出
- `FDIVR` - 反向除法
- `FDIVRP` - 反向除法并弹出
- `FABS` - 绝对值
- `FCHS` - 改变符号
- `FSQRT` - 平方根
- `FSCALE` - 缩放
- `FRNDINT` - 舍入到整数

## 指令对标志位的影响

### 1. 算术运算指令对标志位的影响

#### ADD / ADC（带进位加法）
- **CF**：如果操作产生进位则置 1，否则清 0
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1，否则清 0
- **AF**：如果第 3 位向第 4 位产生进位则置 1，否则清 0
- **ZF**：如果结果为 0 则置 1，否则清 0
- **SF**：如果结果的最高位为 1 则置 1，否则清 0
- **OF**：如果有符号数运算溢出则置 1，否则清 0

```asm
mov al, 0FEh      ; AL = 254
add al, 4         ; AL = 2, CF=1, OF=0
; 结果为2，ZF=0, SF=0, PF=0(2的二进制是00000010，有1个1，为奇数，PF=0)
```

#### SUB / SBB（带借位减法）
- **CF**：如果发生借位则置 1，否则清 0
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **AF**：如果第 3 位向第 4 位产生借位则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **OF**：如果有符号数运算溢出则置 1

```asm
mov al, 10        ; AL = 10
sub al, 20        ; AL = 246, CF=1, OF=0
; 结果为-10的补码形式，SF=1, ZF=0, PF=1(246的二进制是11110110，有6个1，为偶数，PF=1)
```

#### CMP（比较）
- 影响所有状态标志位（CF, PF, AF, ZF, SF, OF）
- 类似 SUB 指令，但不保存结果，只设置标志位
- 用于后续的条件跳转指令

```asm
mov ax, 100
cmp ax, 200       ; AX-200, CF=1, SF=1, OF=0, ZF=0
je equal_label    ; 不会跳转(ZF=0)
jb below_label    ; 会跳转(CF=1)
```

#### NEG（取负）
- **CF**：如果操作数非 0 则置 1，如果是 0 则清 0
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **AF**：如果结果相应位有效则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **OF**：如果操作数为 -128(字节)、-32768(字)、-2147483648(双字) 则置 1

```asm
mov al, -128      ; AL = 10000000b
neg al            ; 结果还是-128，但OF=1（溢出）
```

### 2. 逻辑运算指令对标志位的影响

#### AND / OR / XOR
- **CF**：清 0
- **OF**：清 0
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **AF**：未定义

```asm
mov al, 0FFh
and al, 0F0h      ; AL = 0F0h, CF=0, OF=0, SF=1, ZF=0, PF=1
```

#### TEST（测试）
- 类似 AND 指令，但不保存结果，只设置标志位
- **CF**：清 0
- **OF**：清 0
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **AF**：未定义

```asm
mov ax, 0101h
test ax, 0001h    ; 检查最低位是否为1，ZF=0, SF=0, PF=0
jnz odd_number    ; 跳转，因为ZF=0
```

### 3. 增减指令对标志位的影响

#### INC（增加）
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **OF**：如果操作数从 127 变为 -128 或从 32767 变为 -32768 则置 1
- **AF**：如果第 3 位向第 4 位产生进位则置 1
- **CF**：不受影响

```asm
mov al, 127       ; AL = 01111111b
inc al            ; AL = 10000000b, OF=1, SF=1, ZF=0, AF=1, PF=0
```

#### DEC（减少）
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **OF**：如果操作数从 -128 变为 127 或从 -32768 变为 32767 则置 1
- **AF**：如果第 3 位向第 4 位产生借位则置 1
- **CF**：不受影响

```asm
mov al, 80h       ; AL = 10000000b
dec al            ; AL = 01111111b, OF=1, SF=0, ZF=0, AF=1, PF=0
```

### 4. 移位指令对标志位的影响

#### SHL / SAL（逻辑/算术左移）
- **CF**：移出的最高位
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：如果结果的最高位为 1 则置 1
- **OF**：仅对单次移位有定义：如果符号位发生变化则置 1；多次移位时未定义
- **AF**：未定义

```asm
mov al, 80h       ; AL = 10000000b
shl al, 1         ; AL = 00000000b, CF=1, OF=1(单次移位，符号位变化), ZF=1, PF=1
```

#### SHR / SAR（逻辑/算术右移）
- **CF**：移出的最低位
- **PF**：如果结果低 8 位中 1 的个数为偶数则置 1
- **ZF**：如果结果为 0 则置 1
- **SF**：等于结果最高位（SHR 后最高位补 0，故通常为 0；SAR 保持符号位）
- **OF**：对于 SHR 单次移位等于原最高位，对于 SAR 始终为 0；多次移位未定义
- **AF**：未定义

```asm
mov al, 82h       ; AL = 10000010b
shr al, 1         ; AL = 01000001b, CF=0, OF=1(单次SHR且原最高位为1), SF=0
```

## 与标志位相关的指令详解

### 1. 状态标志位操作指令

#### STC / CLC / CMC（进位标志操作）
- **STC (Set Carry flag)**：设置 CF=1
- **CLC (Clear Carry flag)**：清除 CF=0
- **CMC (Complement Carry flag)**：翻转 CF 的值

```asm
clc               ; CF = 0
stc               ; CF = 1
cmc               ; 翻转CF的值
```

#### STD / CLD（方向标志操作）
- **STD (Set Direction flag)**：设置 DF=1，使字符串操作向低地址方向进行
- **CLD (Clear Direction flag)**：清除 DF=0，使字符串操作向高地址方向进行

```asm
cld               ; DF = 0，字符串操作向高地址方向进行
std               ; DF = 1，字符串操作向低地址方向进行
```

#### STI / CLI（中断标志操作）
- **STI (Set Interrupt flag)**：设置 IF=1，允许可屏蔽中断
- **CLI (Clear Interrupt flag)**：清除 IF=0，禁止可屏蔽中断

```asm
cli               ; IF = 0，禁止可屏蔽中断
sti               ; IF = 1，允许可屏蔽中断
```

#### SAHF / LAHF（标志与 AH 寄存器交换）
- **SAHF (Store AH into Flags)**：将 AH 寄存器加载到标志寄存器的低 8 位
  - AH 的位 7→SF，位 6→ZF，位 4→AF，位 2→PF，位 0→CF
- **LAHF (Load Flags into AH)**：将标志寄存器的低 8 位加载到 AH 寄存器

```asm
lahf              ; 将SF,ZF,AF,PF,CF加载到AH寄存器
sahf              ; 将AH的内容加载到对应的标志位
```

### 2. 标志位状态检测指令

#### 条件跳转指令（基于标志位）
这些指令根据标志位的组合来决定是否跳转：
- **JC / JNC**：如果 CF=1/0 则跳转
- **JB / JNB**：如果 CF=1/0 则跳转（无符号比较）
- **JA / JNA**：如果 CF=0 且 ZF=0 / CF=1 或 ZF=1 则跳转（无符号比较）
- **JZ / JNZ**：如果 ZF=1/0 则跳转
- **JE / JNE**：如果 ZF=1/0 则跳转
- **JS / JNS**：如果 SF=1/0 则跳转
- **JO / JNO**：如果 OF=1/0 则跳转
- **JP / JNP**：如果 PF=1/0 则跳转
- **JL / JNL**：如果 SF≠OF / SF=OF 则跳转（有符号比较）
- **JG / JNG**：如果 ZF=0 且 SF=OF / ZF=1 或 SF≠OF 则跳转（有符号比较）

```asm
cmp eax, ebx      ; 比较EAX和EBX
je equal_label    ; 如果EAX=EBX(ZF=1)则跳转
jl less_label     ; 如果EAX<EBX(SF≠OF)则跳转
jg greater_label  ; 如果EAX>EBX(ZF=0且SF=OF)则跳转
ja above_label    ; 如果EAX>EBX(CF=0且ZF=0)则跳转（无符号）
jb below_label    ; 如果EAX<EBX(CF=1)则跳转（无符号）
```

#### 条件传送指令（CMOVcc，P6/Pentium Pro 引入）
- **CMOVB / CMOVAE**：如果 CF=1/0 则传送（无符号比较）
- **CMOVZ / CMOVNZ**：如果 ZF=1/0 则传送
- **CMOVS / CMOVNS**：如果 SF=1/0 则传送
- **CMOVO / CMOVNO**：如果 OF=1/0 则传送
- **CMOVP / CMOVNP**：如果 PF=1/0 则传送
- **CMOVL / CMOVNL**：如果 SF≠OF / SF=OF 则传送（有符号比较）
- **CMOVG / CMOVNG**：如果 ZF=0 且 SF=OF / ZF=1 或 SF≠OF 则传送（有符号比较）
- **CMOVA / CMOVNA**：如果 CF=0 且 ZF=0 / CF=1 或 ZF=1 则传送（无符号比较）

```asm
cmovz eax, ebx    ; 如果ZF=1，则EAX=EBX
cmovge eax, ecx   ; 如果SF=OF，则EAX=ECX（有符号大于等于）
```

### 3. 条件设置指令（SETcc）

这些指令根据标志位的状态设置字节操作数：
- **SETC / SETNC**：如果 CF=1/0 则设置字节为 1，否则为 0
- **SETB / SETNB**：如果 CF=1/0 则设置字节为 1，否则为 0（无符号比较）
- **SETZ / SETNZ**：如果 ZF=1/0 则设置字节为 1，否则为 0
- **SETE / SETNE**：如果 ZF=1/0 则设置字节为 1，否则为 0
- **SETS / SETNS**：如果 SF=1/0 则设置字节为 1，否则为 0
- **SETO / SETNO**：如果 OF=1/0 则设置字节为 1，否则为 0
- **SETP / SETNP**：如果 PF=1/0 则设置字节为 1，否则为 0
- **SETL / SETNL**：如果 SF≠OF / SF=OF 则设置字节为 1，否则为 0（有符号比较）
- **SETG / SETNG**：如果 ZF=0 且 SF=OF / ZF=1 或 SF≠OF 则设置字节为 1，否则为 0（有符号比较）
- **SETA / SETNA**：如果 CF=0 且 ZF=0 / CF=1 或 ZF=1 则设置字节为 1，否则为 0（无符号比较）

```asm
cmp eax, ebx      ; 比较EAX和EBX
sete cl           ; 如果EAX=EBX(ZF=1)，则CL=1，否则CL=0
setl bl           ; 如果EAX<EBX(SF≠OF)，则BL=1，否则BL=0
setg dl           ; 如果EAX>EBX(ZF=0且SF=OF)，则DL=1，否则DL=0
```

### 4. 标志位控制指令

#### PUSHF / POPF（标志寄存器压栈/出栈）
- **PUSHF**：将标志寄存器压入堆栈
- **POPF**：从堆栈弹出值到标志寄存器

```asm
pushf             ; 保存当前标志
; 修改标志的操作
popf              ; 恢复之前的标志
```

#### PUSHFD / POPFD（32 位标志寄存器）
- 32 位模式下的标志寄存器操作指令

#### PUSHFQ / POPFQ（64 位标志寄存器）
- 64 位模式下的标志寄存器操作指令

### 5. 位操作指令

#### 位测试和修改指令
- **BT (Bit Test)**：测试位并将结果放入 CF
- **BTS (Bit Test and Set)**：测试并设置位
- **BTR (Bit Test and Reset)**：测试并重置位
- **BTC (Bit Test and Complement)**：测试并翻转位

```asm

```

### 6. 字符串比较指令

- **SCASB / SCASW / SCASD / SCASQ**：影响所有状态标志
- **CMPSB / CMPSW / CMPSD / CMPSQ**：影响所有状态标志

### 7. 条件重复指令

- **REPE / REPZ**：当 CX/ECX/RCX 不为 0 且 ZF=1 时重复

## 浮点寄存器详解

x86-64 架构支持多种类型的浮点寄存器，用于执行浮点运算和向量运算。

### 1. x87 FPU 寄存器

x87 浮点单元（Floating Point Unit）包含 8 个 80 位的寄存器（ST(0) 到 ST(7)），形成一个栈结构：

- **ST(0) 至 ST(7)** - 80 位扩展精度浮点寄存器
- 这些寄存器组织成一个 8 层深的栈，ST(0) 是栈顶
- 每个寄存器可以存储 64 位有效数字的扩展精度浮点数

#### x87 FPU 寄存器特点：
- 使用 80 位扩展双精度格式存储数值
- 1 位符号位，15 位指数，64 位有效数字
- 支持整数、单精度、双精度和扩展精度操作数

### 2. XMM 寄存器（SSE）

SSE（Streaming SIMD Extensions）引入了 128 位宽的 XMM 寄存器：

- **XMM0-XMM15** - 128 位寄存器（在 64 位模式下）
- **XMM0-XMM7** - 32 位模式下可用的寄存器数量

#### XMM 寄存器用途：
- 存储 4 个单精度浮点数（4 × 32 位）
- 存储 2 个双精度浮点数（2 × 64 位）
- 存储整数向量（4 个 32 位、8 个 16 位或 16 个 8 位）

### 3. YMM 寄存器（AVX）

AVX（Advanced Vector Extensions）扩展了寄存器宽度：

- **YMM0-YMM15** - 256 位寄存器（在 64 位模式下）
- **YMM0-YMM7** - 32 位模式下可用的寄存器数量

#### YMM 寄存器特点：
- 每个 YMM 寄存器包含相应的 XMM 寄存器作为其低 128 位
- 支持 8 个单精度或 4 个双精度浮点运算

### 4. ZMM 寄存器（AVX-512）

AVX-512 进一步扩展了寄存器宽度：

- **ZMM0-ZMM31** - 512 位寄存器（仅在 64 位模式下）
- 每个 ZMM 寄存器包含相应的 YMM 寄存器作为其低 256 位

#### ZMM 寄存器特点：
- 支持 16 个单精度或 8 个双精度浮点运算
- 包含额外的掩码寄存器（k0-k7）用于细粒度控制

### 5. 浮点控制寄存器

#### MXCSR 寄存器
- 32 位控制和状态寄存器
- 控制 SSE/SSE2 指令的舍入模式和异常处理
- 包含异常标志和掩码位

#### x87 FPU 控制字
- 控制浮点运算的舍入精度和模式
- 管理异常掩码和状态标志

### 6. 浮点运算示例

#### x87 FPU 运算示例：
```asm
fld qword ptr [var1]     ; 将双精度变量var1加载到ST(0)
fld qword ptr [var2]     ; 将双精度变量var2加载到ST(0)，原值移到ST(1)
faddp                    ; 将ST(0)和ST(1)相加，结果存入ST(0)并弹出
fstp qword ptr [result]  ; 将结果存储到内存并弹出栈顶
```

#### SSE 浮点运算示例：
```asm
; 加载两个打包的单精度数到XMM寄存器
movaps xmm0, [array1]    ; 从内存加载4个单精度数到xmm0
movaps xmm1, [array2]    ; 从内存加载4个单精度数到xmm1
addps xmm0, xmm1         ; 并行计算4个单精度数的和
movaps [result], xmm0    ; 将结果存储回内存
```

#### AVX 浮点运算示例：
```asm
; 使用256位寄存器进行双精度运算
vmovapd ymm0, [array1]   ; 加载4个双精度数到ymm0
vmovapd ymm1, [array2]   ; 加载4个双精度数到ymm1
vaddpd ymm0, ymm0, ymm1  ; 并行计算4个双精度数的和（三操作数）
vmovapd [result], ymm0   ; 将结果存储回内存
```

## 常用指令补充

### 1. 无操作指令
- `NOP` - 无操作指令，占用一个时钟周期

### 2. 自旋等待提示
- `PAUSE` - 提示处理器处于自旋等待状态，优化自旋锁性能

## 总结

x86/x86-64 是典型的 CISC 架构，与本系列的 RISC 架构形成鲜明对比：

- **变长指令、丰富寻址**：`[Base + Index*Scale + Disp]` 一条指令即可完成复杂寻址，64 位还新增 RIP 相对寻址。
- **丰富的标志位（EFLAGS/RFLAGS）**：算术逻辑指令隐式更新 CF/ZF/SF/OF 等，配合 Jcc/SETcc/CMOVcc 实现条件控制。
- **历史包袱与扩展叠加**：从 x87 FPU 到 SSE/AVX/AVX-512，浮点与向量单元层层叠加；32 位到 64 位主要靠 REX 前缀和寄存器扩展（R8-R15）。
- **调用约定分裂**：64 位下 Windows x64 与 System V AMD64 在参数寄存器上不同，逆向与跨平台开发时务必区分。

掌握 x86 标志位语义与寻址方式，是逆向工程、性能调优和理解编译器输出的关键。
