## 一、装饰器概述:ArkTS的"魔法"本质

### 1.1 什么是装饰器?

装饰器(Decorator)是一种特殊的语法,用`@`符号标记,可以附加在**类、方法、属性、参数**上,为其添加额外功能。

**基础示例**:
```typescript
// ✅ 可运行代码
@Component  // ← 这就是装饰器
struct MyComponent {
  @State count: number = 0;  // ← 属性装饰器

  build() {
    Text(`Count: ${this.count}`)
  }
}
```

### 1.2 装饰器在ArkTS中的三大角色

| 角色 | 作用 | 典型装饰器 |
|------|------|-----------|
| **状态管理** | 实现数据响应式更新 | @State, @Prop, @Link, @Observed |
| **UI构建** | 声明UI组件结构 | @Component, @Builder, @Extend |
| **并发编程** | 保证线程安全 | @Concurrent, @Sendable |

### 1.3 装饰器 vs 传统方式对比

**传统方式**(如React):
```typescript
// ✅ 可运行代码
// React: 需要手动调用setState
class Counter extends React.Component {
  state = { count: 0 };

  increment() {
    this.setState({ count: this.state.count + 1 });
  }
}
```

**ArkTS装饰器方式**:
```typescript
// ✅ 可运行代码
@Component
struct Counter {
  @State count: number = 0;

  increment() {
    this.count++;  // 自动触发UI更新!
  }

  build() {
    Column() {
      Text(`${this.count}`)
      Button("增加").onClick(() => this.increment())
    }
  }
}
```

**优势**:
- ✅ **代码更简洁**: 无需手动调用更新方法
- ✅ **性能更优**: 编译时优化,精确更新
- ✅ **类型安全**: 编译时检查,避免运行时错误

### 2.2 @State: 组件私有状态

**原理**: 标记为@State的变量变化时,会自动触发组件的`build()`方法重新执行。

**完整示例**:
```typescript
// ✅ 可运行代码
@Entry
@Component
struct CounterPage {
  @State count: number = 0;
  @State message: string = "Hello";

  build() {
    Column({ space: 20 }) {
      // 当count变化时,这个Text会自动更新
      Text(`Count: ${this.count}`)
        .fontSize(24)

      Button("增加")
        .onClick(() => {
          this.count++;  // 触发更新
        })

      Button("重置")
        .onClick(() => {
          this.count = 0;
          this.message = "Reset!";  // 两个状态都会触发更新
        })

      Text(this.message)
    }
    .width('100%')
    .height('100%')
    .justifyContent(FlexAlign.Center)
  }
}
```

**关键要点**:
- ✅ 只能用于`@Component`装饰的struct
- ✅ 初始化时必须赋值
- ✅ 支持基本类型、对象、数组
- ⚠️ 对象/数组的深层属性变化**不会**触发更新(需要用@Observed)

### 2.3 @Prop与@Link: 父子组件通信

**@Prop**: 单向数据流(父→子)

```typescript
// ✅ 可运行代码
@Component
struct ChildComponent {
  @Prop count: number;  // 从父组件接收

  build() {
    Text(`Child count: ${this.count}`)
      .onClick(() => {
        this.count++;  // ⚠️ 只影响子组件,不影响父组件
      })
  }
}

@Entry
@Component
struct ParentComponent {
  @State parentCount: number = 0;

  build() {
    Column() {
      Text(`Parent: ${this.parentCount}`)

      ChildComponent({ count: this.parentCount })  // 传递给子组件

      Button("Parent +1")
        .onClick(() => this.parentCount++)
    }
  }
}
```

**@Link**: 双向绑定(父↔子)

```typescript
// ✅ 可运行代码
@Component
struct ChildComponent {
  @Link count: number;  // 双向绑定

  build() {
    Text(`Child: ${this.count}`)
      .onClick(() => {
        this.count++;  // ✅ 会同步更新父组件!
      })
  }
}

@Entry
@Component
struct ParentComponent {
  @State parentCount: number = 0;

  build() {
    Column() {
      Text(`Parent: ${this.parentCount}`)

      // 注意这里用$符号传递引用
      ChildComponent({ count: $parentCount })

      Button("Parent +1")
        .onClick(() => this.parentCount++)
    }
  }
}
```

**@Prop vs @Link 对比**:

| 特性 | @Prop | @Link |
|------|-------|-------|
| 数据流向 | 单向(父→子) | 双向(父↔子) |
| 子组件修改 | 不影响父组件 | 影响父组件 |
| 传递语法 | `{ count: value }` | `{ count: $value }` |
| 使用场景 | 只读展示 | 表单输入、开关 |

### 2.4 @Observed与@ObjectLink: 嵌套对象响应式

**问题**: @State只能检测第一层属性变化

```typescript
@State user: { name: string, age: number } = { name: "张三", age: 25 };

// ❌ 这样不会触发更新!
this.user.age = 26;

// ✅ 必须整体替换才能更新
this.user = { name: "张三", age: 26 };
```

**解决方案**: 使用@Observed + @ObjectLink

```typescript
// ✅ 可运行代码
@Observed
class User {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}

@Component
struct UserCard {
  @ObjectLink user: User;  // 引用Observed对象

  build() {
    Column() {
      Text(`姓名: ${this.user.name}`)
      Text(`年龄: ${this.user.age}`)

      Button("年龄+1")
        .onClick(() => {
          this.user.age++;  // ✅ 会触发更新!
        })
    }
  }
}

@Entry
@Component
struct UserPage {
  @State user: User = new User("张三", 25);

  build() {
    Column() {
      UserCard({ user: this.user })  // 传递对象

      Button("修改姓名")
        .onClick(() => {
          this.user.name = "李四";  // ✅ 也会触发更新
        })
    }
  }
}
```

**原理**: @Observed会为类的每个属性添加getter/setter,实现细粒度的变化检测。

### 2.5 @StorageProp与@StorageLink: 应用级全局状态

**AppStorage**: 应用级的单例存储,适合全局配置、用户信息等。

```typescript
// ✅ 可运行代码
// 1. 初始化全局状态
AppStorage.setOrCreate('userToken', '');
AppStorage.setOrCreate('theme', 'light');

// 2. 单向读取(@StorageProp)
@Entry
@Component
struct SettingsPage {
  @StorageProp('theme') theme: string = 'light';

  build() {
    Column() {
      Text(`当前主题: ${this.theme}`)
      // ⚠️ 修改theme不会影响AppStorage
    }
  }
}

// 3. 双向绑定(@StorageLink)
@Entry
@Component
struct ThemePage {
  @StorageLink('theme') theme: string = 'light';

  build() {
    Column() {
      Text(`主题: ${this.theme}`)

      Button("切换主题")
        .onClick(() => {
          this.theme = this.theme === 'light' ? 'dark' : 'light';
          // ✅ 会同步到AppStorage,其他页面也会更新!
        })
    }
  }
}
```

**PersistentStorage**: 持久化存储

```typescript
// ✅ 可运行代码
// 将AppStorage中的数据持久化到磁盘
PersistentStorage.persistProp('theme', 'light');
PersistentStorage.persistProp('userToken', '');

// 下次启动应用时自动恢复
```

### 2.6 @Provide与@Consume: 跨层级通信

**场景**: 祖孙组件之间传值,避免逐层传递。

```typescript
// ✅ 可运行代码
@Entry
@Component
struct GrandparentPage {
  @Provide('sharedData') data: string = "来自祖先的数据";

  build() {
    Column() {
      Text(`祖先组件: ${this.data}`)
      ParentComponent()  // 中间组件
    }
  }
}

@Component
struct ParentComponent {
  // 父组件不需要接收和传递
  build() {
    Column() {
      Text("父组件(不参与)")
      ChildComponent()
    }
  }
}

@Component
struct ChildComponent {
  @Consume('sharedData') data: string;  // 直接消费祖先数据

  build() {
    Column() {
      Text(`孙组件: ${this.data}`)

      Button("修改")
        .onClick(() => {
          this.data = "孙组件修改了数据";
          // ✅ 祖先组件也会更新!
        })
    }
  }
}
```

**关键要点**:
- ✅ key必须一致(`'sharedData'`)
- ✅ 支持双向绑定
- ✅ 适合主题、语言等全局配置
- ⚠️ 滥用会导致数据流混乱,建议配合命名约定

## 三、UI构建装饰器

### 3.1 @Component: 声明自定义组件

**作用**: 标记struct为可复用的UI组件。

```typescript
// ✅ 可运行代码
@Component
struct CustomButton {
  private text: string = "";
  private onClick: () => void = () => {};

  build() {
    Button(this.text)
      .width(200)
      .height(50)
      .onClick(this.onClick)
  }
}

// 使用
@Entry
@Component
struct HomePage {
  build() {
    Column() {
      CustomButton({
        text: "点击我",
        onClick: () => console.log("Clicked!")
      })
    }
  }
}
```

### 3.2 @Builder: 自定义构建函数

**场景**: 复用UI片段,避免重复代码。

```typescript
// ✅ 可运行代码
@Entry
@Component
struct ProductPage {
  @State products: string[] = ["商品A", "商品B", "商品C"];

  // 全局@Builder(无this上下文)
  @Builder
  static HeaderBuilder() {
    Row() {
      Text("商品列表").fontSize(24).fontWeight(FontWeight.Bold)
    }
    .width('100%')
    .height(60)
    .backgroundColor('#f0f0f0')
  }

  // 实例@Builder(可访问this)
  @Builder
  ProductItemBuilder(name: string) {
    Row() {
      Text(name).fontSize(18)
      Blank()
      Button("购买")
    }
    .width('100%')
    .padding(10)
    .borderWidth(1)
  }

  build() {
    Column() {
      ProductPage.HeaderBuilder()  // 静态Builder

      ForEach(this.products, (item: string) => {
        this.ProductItemBuilder(item)  // 实例Builder
      })
    }
  }
}
```

**@Builder vs 组件对比**:

| 特性 | @Builder | @Component |
|------|----------|-----------|
| 状态管理 | 使用父组件状态 | 独立状态 |
| 复用性 | 轻量级复用 | 完整组件复用 |
| 生命周期 | 无 | 有 |
| 使用场景 | 局部UI片段 | 独立功能模块 |

### 3.3 @Extend: 扩展组件样式

**作用**: 为系统组件添加自定义样式集合。

```typescript
// ✅ 可运行代码
// 定义扩展样式
@Extend(Text)
function fancyText() {
  .fontSize(20)
  .fontColor(Color.Blue)
  .fontWeight(FontWeight.Bold)

}

@Extend(Button)
function primaryButton() {
  .width(200)
  .height(50)
  .backgroundColor('#007AFF')

}

// 使用
@Entry
@Component
struct StyledPage {
  build() {
    Column({ space: 20 }) {
      Text("标题文字").fancyText()
      Text("副标题").fancyText()

      Button("提交").primaryButton()
      Button("取消").primaryButton()
        .backgroundColor('#FF3B30')  // 可覆盖
    }
  }
}
```

**高级用法**: 带参数的@Extend

```typescript
// ✅ 可运行代码
@Extend(Text)
function coloredText(color: Color | string) {
  .fontColor(color)
  .fontSize(18)
}

// 使用
Text("红色文字").coloredText(Color.Red)
Text("蓝色文字").coloredText('#007AFF')
```

### 3.4 @Styles: 可复用的样式集合

**作用**: 定义一组样式,可用于多个组件。

```typescript
// ✅ 可运行代码
@Styles
function cardStyle() {
  .width('90%')
  .padding(20)
  .backgroundColor(Color.White)
  .borderRadius(12)
  .shadow({ radius: 5, color: '#00000020' })
}

@Entry
@Component
struct CardPage {
  build() {
    Column({ space: 15 }) {

        Text("卡片1内容")
      }

      Row() {
        Text("卡片2内容")
      }
      .cardStyle()  // 可用于不同组件
    }
  }
}
```

**@Styles vs @Extend**:

| 特性 | @Styles | @Extend |
|------|---------|---------|
| 适用对象 | 所有组件 | 特定组件类型 |
| 参数支持 | ❌ 不支持 | ✅ 支持 |
| 类型安全 | 较弱 | 强 |
| 使用场景 | 通用样式 | 组件专属样式 |

## 四、并发编程装饰器

### 4.1 @Concurrent: 标记并发任务

**作用**: 声明函数可以在TaskPool中并发执行。

```typescript
// ✅ 可运行代码
import taskpool from '@ohos.taskpool';

// 标记为并发函数
@Concurrent
function heavyComputation(data: number[]): number {
  // 执行耗时计算
  return data.reduce((sum, val) => sum + val, 0);
}

@Entry
@Component
struct TaskPage {
  @State result: number = 0;

  async executeTask() {
    const data = Array.from({ length: 10000 }, (_, i) => i);

    // 在TaskPool中并发执行
    const task = new taskpool.Task(heavyComputation, data);
    this.result = await taskpool.execute(task) as number;
  }

  build() {
    Column() {
      Text(`结果: ${this.result}`)
      Button("执行任务").onClick(() => this.executeTask())
    }
  }
}
```

**限制**:
- ✅ 只能是普通函数或静态方法
- ❌ 不能访问闭包变量
- ❌ 不能使用`this`
- ✅ 参数必须可序列化

### 4.2 @Sendable: 标记可共享对象

**作用**: 声明类的实例可以在线程间安全共享。

```typescript
// ✅ 可运行代码
import { collections } from '@kit.ArkTS';

@Sendable
class SharedData {
  name: string;
  value: number;

  constructor(name: string, value: number) {
    this.name = name;
    this.value = value;
  }
}

@Concurrent
function processData(data: SharedData): number {
  return data.value * 2;
}

@Entry
@Component
struct SendablePage {
  async runTask() {
    const data = new SharedData("test", 100);

    // ✅ SharedData实例可以直接传递给并发任务
    const task = new taskpool.Task(processData, data);
    const result = await taskpool.execute(task);
    console.log(`Result: ${result}`);  // 200
  }

  build() {
    Column() {
      Button("运行任务").onClick(() => this.runTask())
    }
  }
}
```

**@Sendable容器**:

```typescript
// ✅ 可运行代码
import { collections } from '@kit.ArkTS';

// 使用Sendable容器
@Concurrent
function processArray(arr: collections.Array<number>): number {
  let sum = 0;
  for (let i = 0; i < arr.length; i++) {
    sum += arr[i];
  }
  return sum;
}

// 普通数组 ❌ 不能跨线程
const normalArray = [1, 2, 3];

// Sendable数组 ✅ 可以跨线程
const sendableArray = new collections.Array<number>(1, 2, 3);
```

## 五、装饰器编译时转换

### 5.1 @State的编译时魔法

**源代码**:
```typescript
// ✅ 可运行代码
@Component
struct Counter {
  @State count: number = 0;

  build() {
    Text(`${this.count}`)
      .onClick(() => this.count++)
  }
}
```

**编译后(伪代码)**:
```typescript
// ✅ 可运行代码
class Counter {
  private __count: number = 0;
  private __observedProperties = new Set();

  get count(): number {
    return this.__count;
  }

  set count(value: number) {
    if (this.__count !== value) {
      this.__count = value;
      this.markNeedUpdate();  // 标记需要重新渲染
    }
  }

  markNeedUpdate() {
    // 通知ArkUI框架重新执行build()
    ArkUI.scheduleUpdate(this);
  }

  build() {
    // 框架会跟踪哪些变量被访问
    return Text(`${this.count}`)
      .onClick(() => this.count++);
  }
}
```

### 5.2 装饰器性能影响

**响应式开销测试**:

```typescript
// ✅ 可运行代码
import { hiTraceMeter } from '@kit.PerformanceAnalysisKit';

@Entry
@Component
struct PerformanceTest {
  @State stateValue: number = 0;
  private normalValue: number = 0;

  testStateUpdate() {
    hiTraceMeter.startTrace("StateUpdate", 1);
    for (let i = 0; i < 1000; i++) {
      this.stateValue = i;  // 每次触发setter
    }
    hiTraceMeter.finishTrace("StateUpdate", 1);
  }

  testNormalUpdate() {
    hiTraceMeter.startTrace("NormalUpdate", 2);
    for (let i = 0; i < 1000; i++) {
      this.normalValue = i;  // 直接赋值
    }
    hiTraceMeter.finishTrace("NormalUpdate", 2);
  }

  build() {
    Column() {
      Button("测试@State性能").onClick(() => this.testStateUpdate())
      Button("测试普通变量性能").onClick(() => this.testNormalUpdate())
    }
  }
}
```

**性能对比**:
- @State赋值: ~0.05ms/次
- 普通变量赋值: ~0.001ms/次
- **性能差距**: 50倍

**优化建议**:
- ✅ 避免在循环中频繁更新@State
- ✅ 批量更新改为一次性更新
- ✅ 使用@ObjectLink管理嵌套对象
- ✅ 非UI相关数据不用装饰器

## 六、装饰器最佳实践

### 6.1 合理选择装饰器

**决策树**:
```typescript
// ✅ 可运行代码
需要状态管理?
├─ 是 → 需要父子通信?
│       ├─ 是 → 单向? @Prop : 双向? @Link
│       └─ 否 → 组件内? @State : 全局? @StorageLink
├─ 否 → 需要UI复用?
│       ├─ 是 → 完整组件? @Component : 片段? @Builder
│       └─ 否 → 并发任务? @Concurrent/@Sendable
└─ 否 → 普通属性即可
```

### 6.2 常见陷阱

**陷阱1: @State与深层对象**

```typescript
// ❌ 错误: 深层属性变化不会触发更新
@State user = { info: { name: "张三" } };
this.user.info.name = "李四";  // 不会更新UI!

// ✅ 正确: 使用@Observed + @ObjectLink
@Observed class UserInfo {
  name: string = "";
}
@State user = new UserInfo();
this.user.name = "李四";  // 会更新UI
```

**陷阱2: @Prop的单向性**

```typescript
// ✅ 可运行代码
@Component
struct Child {
  @Prop value: number;

  build() {
    Text(`${this.value}`)
      .onClick(() => {
        this.value++;  // ⚠️ 只改变子组件,父组件不变!
      })
  }
}
```

**陷阱3: 循环引用**

```typescript
// ❌ 错误: @Link形成循环引用
@Component
struct A {
  @Link data: number;
  build() { B({ data: $data }) }
}

@Component
struct B {
  @Link data: number;
  build() { A({ data: $data }) }  // 死循环!
}
```

### 6.3 性能优化技巧

**技巧1: 避免不必要的响应式**

```typescript
// ❌ 性能差: 所有属性都是@State
@Component
struct BadExample {
  @State title: string = "";
  @State content: string = "";
  @State createdAt: number = Date.now();
  @State author: string = "";
  // ...
}

// ✅ 优化: 只有会变化的才用@State
@Component
struct GoodExample {
  @State content: string = "";  // 只有这个会变

  private readonly title: string = "";
  private readonly createdAt: number = Date.now();
  private readonly author: string = "";
}
```

**技巧2: 使用@ObjectLink管理复杂对象**

```typescript
// ✅ 可运行代码
@Observed
class FormData {
  username: string = "";
  email: string = "";
  age: number = 0;
}

@Component
struct FormPage {
  @State form: FormData = new FormData();

  build() {
    Column() {
      // ✅ 将整个对象传递
      FormInput({ data: this.form })
    }
  }
}

@Component
struct FormInput {
  @ObjectLink data: FormData;

  build() {
    Column() {
      TextInput({ text: this.data.username })
        .onChange(v => this.data.username = v)  // 精确更新
    }
  }
}
```

**技巧3: 使用@Builder减少嵌套**

```typescript
// ❌ 嵌套过深,难以维护
build() {
  Column() {
    Row() {
      Column() {
        Text("...")
        Button("...")
      }
    }
    Row() {
      Column() {
        Text("...")
        Button("...")
      }
    }
  }
}

// ✅ 使用@Builder拆分
@Builder
CardBuilder(title: string, action: string) {
  Row() {
    Column() {
      Text(title)
      Button(action)
    }
  }
}

build() {
  Column() {
    this.CardBuilder("标题1", "操作1")
    this.CardBuilder("标题2", "操作2")
  }
}
```

## 七、实战案例:购物车装饰器应用

### 7.1 数据模型设计

```typescript
// ✅ 可运行代码
@Observed
class CartItem {
  id: number;
  name: string;
  price: number;
  @Track quantity: number;  // 只跟踪quantity变化

  constructor(id: number, name: string, price: number, quantity: number) {
    this.id = id;
    this.name = name;
    this.price = price;
    this.quantity = quantity;
  }

  get total(): number {
    return this.price * this.quantity;
  }
}

@Observed
class ShoppingCart {
  @Track items: CartItem[] = [];

  get totalAmount(): number {
    return this.items.reduce((sum, item) => sum + item.total, 0);
  }

  addItem(item: CartItem) {
    this.items.push(item);
  }

  removeItem(id: number) {
    this.items = this.items.filter(item => item.id !== id);
  }
}
```

### 7.2 组件实现

```typescript
// ✅ 可运行代码
@Entry
@Component
struct CartPage {
  @Provide('cart') cart: ShoppingCart = new ShoppingCart();

  aboutToAppear() {
    // 初始化数据
    this.cart.addItem(new CartItem(1, "商品A", 99, 1));
    this.cart.addItem(new CartItem(2, "商品B", 199, 2));
  }

  build() {
    Column() {
      CartHeader()
      CartList()
      CartFooter()
    }
  }
}

@Component
struct CartHeader {
  @Consume('cart') cart: ShoppingCart;

  build() {
    Row() {
      Text(`购物车 (${this.cart.items.length}件)`)
        .fontSize(20)
        .fontWeight(FontWeight.Bold)
    }
    .width('100%')
    .height(60)
    .padding({ left: 15, right: 15 })
  }
}

@Component
struct CartList {
  @Consume('cart') cart: ShoppingCart;

  @Builder
  ItemBuilder(item: CartItem) {
    Row({ space: 10 }) {
      Text(item.name).layoutWeight(1)
      Text(`¥${item.price}`)

      Row({ space: 5 }) {
        Button("-")
          .width(30)
          .height(30)
          .onClick(() => {
            if (item.quantity > 1) {
              item.quantity--;  // ✅ 精确更新
            }
          })

        Text(`${item.quantity}`)

        Button("+")
          .width(30)
          .height(30)
          .onClick(() => item.quantity++)
      }

      Button("删除")
        .onClick(() => this.cart.removeItem(item.id))
    }
    .width('100%')
    .padding(15)
    .borderWidth({ bottom: 1 })
  }

  build() {
    List() {
      ForEach(this.cart.items, (item: CartItem) => {
        ListItem() {
          this.ItemBuilder(item)
        }
      }, (item: CartItem) => item.id.toString())
    }
    .layoutWeight(1)
  }
}

@Component
struct CartFooter {
  @Consume('cart') cart: ShoppingCart;

  build() {
    Row() {
      Text(`总计: ¥${this.cart.totalAmount.toFixed(2)}`)
        .fontSize(18)
        .fontWeight(FontWeight.Bold)
        .layoutWeight(1)

      Button("结算")
        .width(120)
        .backgroundColor('#FF6B6B')
        .onClick(() => {
          AlertDialog.show({
            message: `确认支付 ¥${this.cart.totalAmount.toFixed(2)} ?`
          })
        })
    }
    .width('100%')
    .height(80)
    .padding({ left: 15, right: 15 })
    .backgroundColor('#f8f8f8')
  }
}
```

**装饰器应用总结**:
- ✅ `@Observed` - 使CartItem和ShoppingCart可响应
- ✅ `@Track` - 精确跟踪quantity变化,避免全量更新
- ✅ `@Provide/@Consume` - 实现购物车状态的跨组件共享
- ✅ `@Builder` - 复用商品项UI

## 八、总结与展望

### 8.1 核心要点回顾

| 装饰器 | 作用 | 使用场景 |
|--------|------|----------|
| **@State** | 组件私有状态 | 组件内部变化的数据 |
| **@Prop** | 单向传递 | 父组件只读数据传递 |
| **@Link** | 双向绑定 | 父子组件数据同步 |
| **@Observed/@ObjectLink** | 嵌套对象响应式 | 复杂对象状态管理 |
| **@StorageLink** | 全局状态绑定 | 应用级配置、用户信息 |
| **@Provide/@Consume** | 跨层级通信 | 祖孙组件数据共享 |
| **@Component** | 声明组件 | 自定义UI组件 |
| **@Builder** | UI片段复用 | 局部UI模板 |
| **@Extend/@Styles** | 样式复用 | 样式封装 |
| **@Concurrent** | 并发任务 | 耗时计算 |
| **@Sendable** | 跨线程共享 | 线程安全对象 |

### 8.2 学习建议

**初级开发者**:
1. 先掌握 @State/@Prop/@Link
2. 理解单向数据流思想
3. 多写简单组件练习

**中级开发者**:
1. 深入学习 @Observed/@ObjectLink
2. 掌握 @Provide/@Consume
3. 理解响应式原理

**高级开发者**:
1. 研究装饰器编译机制

3. 自定义装饰器(如果支持)
