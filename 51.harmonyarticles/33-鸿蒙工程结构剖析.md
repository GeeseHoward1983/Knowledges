## 二、关键文件详解

### 2.1 app.json5（应用级配置）

**路径**: `AppScope/app.json5`

```json5
// ✅ 可运行代码
{
  "app": {
    "bundleName": "com.example.myapp",           // 应用包名（唯一标识）
    "vendor": "example",                          // 供应商名称
    "versionCode": 1000000,                       // 版本号（整数）
    "versionName": "1.0.0",                       // 版本名（字符串）
    "icon": "$media:app_icon",                    // 应用图标
    "label": "$string:app_name",                  // 应用名称
    "minAPIVersion": 12,                          // 最低API版本
    "targetAPIVersion": 12,                       // 目标API版本
    "apiReleaseType": "Release",                  // API发布类型
    "debug": false,                               // 是否调试版本

    // 多项目配置（可选）
    "multiProjects": false,

    // 应用内购配置（可选）
    "distributedNotificationEnabled": true,

    // 云服务配置（可选）
    "entityType": "unspecified"
  }
}
```

**关键字段说明**:
- `bundleName`: **必须全局唯一**，反向域名格式（如`com.company.app`）
- `versionCode`: **整数**，用于版本比较（新版本必须大于旧版本）
- `versionName`: **字符串**，显示给用户的版本号（如`1.0.0`）
- `minAPIVersion`: 支持的最低API版本（决定应用能运行的最低系统版本）

### 2.2 module.json5（模块级配置）

**路径**: `entry/src/main/module.json5`

```json5
// ✅ 可运行代码
{
  "module": {
    "name": "entry",                              // 模块名
    "type": "entry",                              // 模块类型: entry/feature/shared
    "description": "$string:module_desc",         // 模块描述
    "mainElement": "EntryAbility",                // 主Ability

    // 设备类型
    "deviceTypes": [
      "default",                                  // 默认设备
      "tablet",                                   // 平板
      "2in1"                                      // 二合一设备
    ],

    // 交付场景
    "deliveryWithInstall": true,                  // 是否随应用安装

    // 虚拟机配置
    "virtualMachine": "ark",                      // 使用ArkVM

    // 页面配置
    "pages": "$profile:main_pages",               // 页面路由配置

    // Ability配置
    "abilities": [
      {
        "name": "EntryAbility",                   // Ability名称
        "srcEntry": "./ets/entryability/EntryAbility.ets",  // 入口文件
        "description": "$string:EntryAbility_desc",
        "icon": "$media:icon",
        "label": "$string:EntryAbility_label",
        "startWindowIcon": "$media:startIcon",    // 启动图标
        "startWindowBackground": "$color:start_window_background",
        "exported": true,                         // 是否可被其他应用调用
        "skills": [                               // 意图过滤器
          {
            "entities": ["entity.system.home"],
            "actions": ["action.system.home"]
          }
        ]
      }
    ],

    // 权限请求
    "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET",       // 网络权限
        "reason": "$string:permission_internet",  // 申请原因
        "usedScene": {
          "abilities": ["EntryAbility"],
          "when": "inuse"                         // 使用时机: inuse/always
        }
      },
      {
        "name": "ohos.permission.LOCATION",       // 位置权限
        "reason": "$string:permission_location",
        "usedScene": {
          "abilities": ["EntryAbility"],
          "when": "inuse"
        }
      }
    ],

    // 扩展组件（可选）
    "extensionAbilities": [
      {
        "name": "MyServiceExtension",
        "srcEntry": "./ets/serviceextension/MyServiceExtension.ets",
        "type": "service",
        "exported": false
      }
    ]
  }
}
```

**模块类型**:
- `entry`: 主模块，应用入口（必须有且仅有一个）
- `feature`: 功能模块，可动态加载
- `shared`: 共享库模块（HSP）

## 三、HAP/HSP/HAR包详解

### 3.1 三种包类型对比

| 类型 | 全称 | 用途 | 包含内容 | 独立运行 |
|------|------|------|----------|----------|
| **HAP** | Harmony Ability Package | 应用模块 | 代码+资源+配置 | ✅ 可以 |
| **HSP** | Harmony Shared Package | 共享库（动态） | 代码+资源 | ❌ 不可以 |
| **HAR** | Harmony Archive | 静态库 | 代码+资源 | ❌ 不可以 |

---

### 3.2 HAP（应用包）

**特点**:
- 应用的基本单元
- 包含完整的Ability
- 可独立安装运行
- 一个应用可以有多个HAP

**示例**:
```typescript
// ✅ 可运行代码
MyApp.hap
├── ets/                  # 编译后的字节码
├── resources/            # 资源文件
├── libs/                 # Native库（.so）
└── module.json           # 模块配置
```

**使用场景**:
- 主应用模块（entry）
- 按功能拆分的独立模块
- 原子化服务的卡片

---

### 3.3 HSP（动态共享包）

**特点**:
- 运行时共享
- 多个HAP可共用一个HSP
- 减少包体积
- 支持资源共享

**创建HSP**:
```typescript
// ✅ 可运行代码
// 1. 创建HSP模块
右键项目 → New → Module → Shared Library

// 2. 导出接口（HSP的index.ets）
export { Utils } from './src/main/ets/utils/Utils'
export { CommonButton } from './src/main/ets/components/CommonButton'

// 3. 在HAP中引用
import { Utils, CommonButton } from '@ohos/my-hsp'
```

**HSP配置**:
```json5
// ✅ 可运行代码
// module.json5
{
  "module": {
    "name": "common",
    "type": "shared",           // 类型为shared
    "deviceTypes": ["default"]
  }
}
```

---

### 3.4 HAR（静态库）

**特点**:
- 编译时静态链接
- 代码和资源被打包到HAP中
- 无法共享（每个HAP都有副本）

**创建HAR**:
```typescript
// ✅ 可运行代码
// 1. 创建HAR模块
右键项目 → New → Module → Static Library

// 2. 导出接口（HAR的index.ets）
export { Logger } from './src/main/ets/utils/Logger'

// 3. 在HAP中引用
import { Logger } from '@ohos/my-har'
```

**HAR配置**:
```json5
// ✅ 可运行代码
// oh-package.json5（HAR模块）
{
  "name": "@ohos/my-har",
  "version": "1.0.0",
  "main": "index.ets"          // 入口文件
}
```

---

### 3.5 选择决策树

```typescript
// ✅ 可运行代码
需要共享代码/资源？
├─ 是 → 继续判断
│   ├─ 需要运行时共享？
│   │   ├─ 是 → HSP ✅（推荐，减少包体积）
│   │   └─ 否 → HAR ✅（编译时静态链接）
│   └─ 需要独立Ability？
│       └─ 是 → HAP ✅
└─ 否 → HAP ✅（独立模块）
```

## 五、编译构建流程

### 5.1 完整构建流程

```typescript
// ✅ 可运行代码
源码                     编译                    打包                     签名
  │                       │                       │                        │
  ├─ ArkTS (.ets)        ├─ ArkCompiler         ├─ 资源打包              ├─ 签名证书
  ├─ 资源 (.json/.png)   │  └─ .abc字节码       ├─ 合并.abc               │  └─ .p7b签名
  ├─ C++ (.cpp)          ├─ CMake               ├─ 压缩资源              └─ 最终HAP
  └─ Native库            │  └─ .so库             └─ 生成HAP包
                         └─ 资源编译
                            └─ resources.index

完整流程:
1. 源码编译  →  2. 资源编译  →  3. 打包  →  4. 签名  →  5. HAP输出
```

## 七、常见问题FAQ

### Q1: 修改bundleName后无法运行？
**A**: 卸载旧应用后重新安装

```bash
# ✅ 可运行代码
hdc uninstall com.old.bundlename
hdc install entry-default-signed.hap
```

---

### Q2: 资源引用失败？
**A**: 检查资源ID是否正确

```typescript
// ✅ 可运行代码
// ✅ 正确
Text($r('app.string.app_name'))

// ❌ 错误
Text($r('string.app_name'))  // 缺少app.
```

---

### Q3: HAP包过大如何优化？
**A**:
