# 编译器完整参考 · 总索引 (MOC)

> C/C++ 三大主流编译器 **GCC、Clang、MSVC** 的参数参考与横向对比合集。每篇按**功能分类**逐项详解命令行选项，对易混淆项给出辨析，关键结论以各家**官方文档**核实。
>
> **版本基准**：GCC 13+ / Clang 17+ / MSVC（VS2022，v143）及以上；涉及版本差异处均有标注。

C/C++ 没有"官方编译器"，GCC、Clang、MSVC 三足鼎立，各自的命令行选项体系差异巨大（前两者 `-` 风格且高度互通，MSVC 是 `/` 风格且**区分大小写**）。本合集把三者的高频选项、易错点与适用场景整理在一处，既可当**速查手册**，也可当**选型依据**。

## 📌 如何使用

- **查某个编译器的选项**：直接进对应参考页，按"优化 / 警告 / 调试 / 代码生成 / 链接"等分类检索。
- **跨编译器对照**：看 [[02.Compiler_Comparison|对比文档]] 里的选项对照表（阶段控制、优化级别、警告、语言标准、Sanitizer 一一对应）。
- **做技术选型**：看下方"🧭 选型速查"与对比文档的"总结与选型建议"。
- **排查易错点**：MSVC 的 `/Gz` vs `/GZ`、GCC 的 `-ftree-*` 含义等辨析，见各参考页对应小节。

## 🧭 选型速查

| 场景 | 推荐 | 理由 |
|------|------|------|
| Linux / 嵌入式 | **GCC** | 平台与架构覆盖最广，发行版默认 |
| macOS / iOS / Android | **Clang** | 苹果官方工具链、NDK 推荐 |
| Windows 桌面/服务端 | **MSVC** | 与 VS / Windows SDK 深度集成 |
| 需要最友好诊断 / 静态分析 / 多种 Sanitizer | **Clang** | 诊断体验与工具链最强 |
| 跨平台项目 CI | **三者并用** | 互相补盲，暴露不可移植写法 |

## ⚙️ 全局约定

- **选项风格**：GCC/Clang 用 `-` 引导且高度互通；**MSVC 用 `/` 引导且严格区分大小写**（`/Gz` ≠ `/GZ`）。
- **参数标注**：可选用 `[...]`、必填用 `<...>`，与各家官方手册一致。
- **核实来源**：MSVC 选项依据 [learn.microsoft.com/cpp](https://learn.microsoft.com/cpp/build/reference/compiler-options)，GCC/Clang 依据各自官方手册与命令指南。
- **"完整"的含义**：聚焦工程高频与易错选项，而非逐字罗列每个内部 pass；穷举清单请查各编译器的 `--help` 或官方 Option Index。
