# MSVC 编译器与链接器完整参数详解

> MSVC（Microsoft Visual C++）是微软的 C/C++ 工具链，编译器主程序为 `cl.exe`，链接器为 `link.exe`。它与 GCC/Clang 风格迥异：选项以 **`/`**（也接受 `-`）引导，且**与 Unix 工具链不通用**。
>
> ⚠️ **关键特性：MSVC 的编译器选项严格区分大小写**。这意味着 **`/Gz`（`__stdcall` 调用约定）与 `/GZ`（已弃用的运行时检查）是两个完全不同的选项**——本文多处辨析正源于此，阅读时务必看清字母大小写。
>
> **版本基准**：以 **Visual Studio 2022（MSVC v143 / 工具集 17.x）** 及以上为参考；标注"已弃用"者以官方 [MSVC 编译器选项](https://learn.microsoft.com/cpp/build/reference/compiler-options) 为准。
>

## MSVC 编译流程

`cl.exe` 把源码变成可执行程序，概念上分 4 步：

1. **预处理（Preprocessing）**：处理 `#include`、`#define`、`#ifdef` 等，生成 `.i`/`.ii` 中间文件。
2. **编译（Compilation）**：将预处理结果翻译为汇编。
3. **汇编（Assembly）**：将汇编翻译为机器码，生成 `.obj` 目标文件（COFF 格式）。
4. **链接（Linking）**：由 `link.exe` 合并 `.obj` 与库，生成 `.exe` 或 `.dll`。

> 💡 `cl.exe` 只能在 **"Developer Command Prompt / x64 Native Tools 命令提示符"** 中启动（依赖一系列环境变量），不能直接在普通 cmd 或资源管理器里运行。

## 一、编译器参数（cl.exe）

## 1. 优化选项

- **/Od**：禁用优化（调试默认）
- **/O1**：**最小化体积**（= `/Og /Os /Oy /Ob2 /GF /Gy` 等组合）
- **/O2**：**最大化速度**（发布推荐；= `/Og /Oi /Ot /Oy /Ob2 /GF /Gy` 等组合）
- **/Os**：优先代码体积
- **/Ot**：优先代码速度
- **/Og**：启用全局优化
- **/Oi**：把部分库函数作为内部函数（intrinsic）内联展开
- **/Oy**：省略帧指针（x86）
- **/Ob\<n>**：内联展开级别（`0` 禁用、`1` 仅 `__inline`/`inline` 标记、`2`/`3` 让编译器自行决定）
- **/Ox**：启用大多数速度优化（= `/Ob2 /Oi /Ot /Oy`），但**不含** `/O1`/`/O2` 才有的 `/GF`、`/Gy`。官方建议发布构建直接用 `/O2` 而非 `/Ox`

## 2. 代码生成 `/G` 选项

> 🔎 本节是 MSVC 最易混淆处。下面按"调用约定 / 安全 / 链接优化 / 钩子"分组，并标注大小写。

**调用约定（均仅 x86，x64 统一用一种 ABI）**
- **/Gd**：`__cdecl` 调用约定（x86 **默认**）
- **/Gr**：`__fastcall` 调用约定
- **/Gz**：`__stdcall` 调用约定 ← 注意是**小写 z**
- **/Gv**：`__vectorcall` 调用约定（x86 与 x64）

**安全与运行时检查**
- **/GS**：缓冲区安全检查（栈 cookie，默认开）；**/GS-** 关闭
- **/guard:cf**：控制流保护（Control Flow Guard）
- **/Gs[n]**：控制栈探测（stack probe）阈值
- **/GZ**：**（已弃用，VS2005 起）** 等同于 **/RTC1**，启用栈帧运行时错误检查，**仅用于 `/Od` 非优化构建**。现应改用 `/RTC`。← 注意是**大写 Z**，与 `/Gz` 毫无关系
- **/RTC1**：运行时检查（= `/RTCs` 栈帧检查 + `/RTCu` 未初始化变量检查）

**链接期优化相关**
- **/GL**：**全程序优化（Whole Program Optimization）**——让编译器跨所有模块做内联与全局分析，需配合链接器 **/LTCG**；同时使按概要引导优化（PGO）成为可能。`/GL-` 关闭
- **/Gy**：**函数级链接（function-level linking）**——为每个函数生成独立 COMDAT，便于链接器剔除未引用函数与折叠相同函数（`/OPT:REF,ICF`）
- **/Gw**：对全局数据也做类似 `/Gy` 的"按需保留"优化
- **/GF**：启用只读字符串池（相同字符串字面量合并且置于只读段）

**其他代码生成**
- **/GR**：启用 RTTI（默认）；**/GR-** 禁用
- **/GA**：为 Windows 应用程序优化（TLS 访问）
- **/GT**：支持基于静态 TLS 的纤程（fiber）安全
- **/Gm**：**（已弃用）** 启用最小重新生成（minimal rebuild）
- **/GX**：**（已弃用）** 同步异常处理，**请改用 /EH**
- **/Gh** / **/GH**：分别在每个函数**入口**调用 `_penter`、**出口**调用 `_pexit` 钩子函数（性能插桩用，需自行提供这两个函数实现）
- **/arch:**：指定指令集架构基线（如 `/arch:AVX2`、`/arch:AVX512`）

## 3. 预处理器选项

- **/D \<name>** / **/D \<name>=\<value>**：定义（带值）预处理器宏
- **/U \<name>**：取消某宏定义；**/u**：取消所有预定义宏
- **/I \<path>**：添加头文件包含路径
- **/FI \<file>**：强制（隐式）预包含某头文件
- **/FU \<file>**：强制 `#using` 某托管程序集
- **/C**：预处理时保留注释
- **/P**：预处理到 `.i` 文件
- **/showIncludes**：编译时打印所有被包含头文件（排查包含关系/编译慢）

## 4. 语言（一致性）选项

- **/std:c++14** / **/std:c++17** / **/std:c++20** / **/std:c++latest**：指定 C++ 标准（**`/std:c++14` 为下限，MSVC 没有 `/std:c++11`/`c++03` 开关**）
- **/std:c11** / **/std:c17**：指定 C 标准（VS2019 16.8+）
- **/permissive-**：**标准一致性模式**——关闭一批 MSVC 历史宽松行为，更贴近 ISO（强烈推荐新项目开启；在 `/std:c++20` 及以上**默认启用**）
- **/permissive**：关闭一致性模式（恢复宽松行为）
- **/Zc:\<feature>**：逐项一致性开关（如 `/Zc:__cplusplus` 让 `__cplusplus` 宏取正确值、`/Zc:preprocessor` 启用符合标准的预处理器）
- **/Za**：禁用语言扩展（C；C++ 下不推荐）
- **/openmp**：启用 OpenMP 支持

## 5. 调试选项

- **/Z7**：调试信息直接放进 `.obj`（CodeView/C7 格式，无独立 PDB）
- **/Zi**：生成独立程序数据库（PDB）调试信息
- **/ZI**：生成支持"编辑并继续"（Edit & Continue）的调试信息（仅 x86/调试）
- **/Fd\<file>**：指定 PDB 文件名
- **/FS**：强制串行化对 PDB 的写入（多进程编译时必需）
- **/Zo**：为优化代码生成增强调试信息
- **/Zp[n]**：设置结构体成员对齐

## 6. 异常处理

- **/EHsc**：标准 C++ 异常处理，并假定 `extern "C"` 函数不抛 C++ 异常（**最常用**）
- **/EHs**：同步异常处理（不做上面的 `extern "C"` 假定）
- **/EHa**：异步异常处理（可捕获结构化异常 SEH）
- **/GX**：**（已弃用）** 旧的异常处理开关，等价 `/EHsc`，请改用 `/EH`

## 7. 输出文件选项

- **/Fo\<file>**：指定 `.obj` 目标文件名
- **/Fe\<file>**：指定可执行文件名
- **/Fa\<file>** / **/FA**：生成汇编列表文件
- **/Fi\<file>**：指定预处理输出文件名
- **/Fm\<file>**：生成映射（map）文件
- **/Fp\<file>**：指定预编译头 `.pch` 文件名
- **/Fd\<file>**：指定 PDB 文件名

## 8. 预编译头选项

- **/Yc[file]**：**创建**预编译头
- **/Yu[file]**：**使用**预编译头
- **/Y-**：忽略其他所有预编译头选项
- **/Fp\<file>**：指定 `.pch` 文件名

## 9. 警告选项

> 🔧 本节区分**全局等级**（大写 `/W`）与**针对单条警告号**（小写 `/w` 后接编号）。原始资料常把二者混淆。

- **/W0 /W1 /W2 /W3 /W4**：设置警告**等级**（`0` 关闭全部 → `4` 最严格；工程推荐 `/W4`）
- **/Wall**：启用**所有**警告（包含大量默认关闭的、通常很嘈杂，仅排查时用）
- **/WX**：**将警告视为错误**（相当于 GCC/Clang 的 `-Werror`）；**/WX-** 取消
- **/wd\<n>**：禁用指定编号的警告（如 `/wd4996` 关闭"已弃用 API"警告）
- **/we\<n>**：把指定编号的警告**视为错误**（如 `/we4101`）
- **/wo\<n>**：指定编号的警告**只报告一次**
- **/w\<L>\<n>**：为指定编号警告设置等级 L（如 `/w34996` = 把 4996 设为等级 3 警告）
- **/external:W\<n>** / **/external:I\<path>**：对"外部头文件"单独设较低警告等级（避免第三方头刷屏）

## 10. 运行时库选项

- **/MD**：多线程 **DLL** 版运行时（`MSVCRT.lib`，发布常用）
- **/MDd**：多线程 DLL 调试版（`MSVCRTD.lib`）
- **/MT**：多线程**静态**运行时（`LIBCMT.lib`）
- **/MTd**：多线程静态调试版（`LIBCMTD.lib`）

> 📌 同一程序及其所有库必须使用**一致**的运行时库选项，否则会出现重复符号或堆跨边界释放等问题。

## 11. Sanitizer 与代码分析

- **/fsanitize=address**：启用 **AddressSanitizer（ASan）**——VS2019 **16.9+** 起支持，兼容所有优化级别（`/Od`~`/O2 /GL`）与静态/动态 CRT，可生成 EXE 或 DLL；建议配合 `/Zi`。命中即定位越界、use-after-free 等
- **/fsanitize=fuzzer**：启用 LibFuzzer 覆盖率引导模糊测试（VS2022 17.0+，实验性）
- **/fsanitize-coverage=...**：插入覆盖率插桩（供 fuzzer 等使用）
- **/analyze**：启用静态代码分析（C++ Core Guidelines / SAL 检查）

> ⚠️ `/fsanitize` 不支持逗号合并写法（不能 `/fsanitize=address,fuzzer`），需分别指定；且不支持配合 PGO。

## 12. 编译控制与杂项

- **/c**：只编译不链接
- **/link**：其后的参数透传给链接器 `link.exe`
- **/LD** / **/LDd**：创建（调试版）DLL
- **/nologo**：取消版权横幅输出
- **/TC** / **/TP**：把**所有**输入文件强制按 C / C++ 处理
- **/MP[n]**：多进程并行编译（充分利用多核）
- **/utf-8**：将源文件与执行字符集都设为 UTF-8（处理中文等非 ASCII 源码强烈推荐）

## 二、链接器参数（link.exe）

## 1. 基础选项

- **/OUT:\<file>**：指定输出文件名
- **/ENTRY:\<symbol>**：指定入口点函数
- **/SUBSYSTEM:\<type>**：指定子系统（`CONSOLE` / `WINDOWS` 等）
- **/DLL**：生成动态链接库
- **/MAP[:file]**：生成映射文件
- **/DEBUG**：生成调试信息（PDB）
- **/MACHINE:\<arch>**：指定目标平台（`X64`/`X86`/`ARM64`）
- **/BASE:\<addr>** / **/ALIGN**：设置基址 / 段对齐

## 2. 优化选项

- **/LTCG**：**链接时代码生成**——与编译器 `/GL` 配套，完成跨模块优化
- **/OPT:REF**：剔除未被引用的函数/数据；**/OPT:ICF**：折叠内容相同的 COMDAT（配合 `/Gy` 效果最佳）
- **/INCREMENTAL[:NO]**：启用/关闭增量链接（调试快、发布建议关）
- **/ORDER** / **/SECTION** / **/MERGE**：函数排序 / 段属性 / 合并段

## 3. 符号与库选项

- **/LIBPATH:\<dir>**：附加库搜索路径
- **/DEFAULTLIB:\<lib>** / **/NODEFAULTLIB**：添加 / 忽略默认库
- **/DEF:\<file>**：模块定义文件
- **/EXPORT:\<symbol>**：导出函数
- **/IMPLIB:\<file>**：指定生成的导入库名
- **/DELAYLOAD:\<dll>**：延迟加载某 DLL
- **/MANIFEST[:...]** / **/MANIFESTINPUT**：生成 / 输入清单

## 4. 安全与加固选项

- **/DYNAMICBASE**：启用地址空间布局随机化（ASLR，默认开）
- **/HIGHENTROPYVA**：启用 64 位高熵 ASLR
- **/NXCOMPAT**：兼容数据执行保护（DEP）
- **/GUARD:CF**：在映像中启用控制流保护
- **/CETCOMPAT**：标记为 CET（影子栈）兼容
- **/SAFESEH**：生成安全异常处理表（x86）

## 5. 其他常用

- **/STACK:\<n>** / **/HEAP:\<n>**：设置栈 / 堆大小
- **/VERSION:\<n>**：设置映像版本号
- **/PROFILE**：为性能分析/PGO 生成可用映像
- **/VERBOSE**：打印链接过程详细进度
- **/NOLOGO**：取消版权横幅
- **/IGNORE:\<n>** / **/ERRORREPORT**：忽略指定警告 / 错误报告行为

---

正确使用这些选项可以在性能、体积与安全之间取得平衡。MSVC 的两个高频"现代化"建议：**新项目开启 `/permissive-` 与 `/std:c++20`** 提升标准一致性，**用 `/W4 /WX` 把缺陷拦在编译期**，调试构建再加 `/fsanitize=address` 暴露内存问题。
