# 20 · 渐变流光 / Aurora-Gradient

> 一套真在动的极光背景 + 玻璃面板 + 渐变文字 + 流光环的明亮高情绪后台。

## 设计立场
最直接的"想被记住"型方案。整页底层是 **4 个互不相同的彩色模糊球**在背景里持续慢慢飘动（CSS `@keyframes` 22–30 秒一圈），所有面板都漂浮在这层流光上面，靠 `backdrop-filter:blur(28px) saturate(160%)` 把背后的色彩柔化成"被磨砂玻璃滤过的极光"。

与 01·极地玻璃的区别：
- 01 是**冷调静态**（蓝粉浅渐变 + 噪点），用衬线大数字、克制；
- 20 是**热情动态**（紫青粉金 4 色极光 + 真在飘动），大数字用**渐变文字**而不是渐变 sparkline，Hero 还有一个流光圆环 SVG。

## 配色
| 角色 | 取值 |
| --- | --- |
| 底色 | `#F5F4FF → #FFF4F8` 极淡 |
| 玻璃 | `rgba(255,255,255,.65)` + 28px 模糊 + 160% 饱和 |
| 主文字 | `#0E1130` |
| 次文字 | `#5B5F86` |
| 极光紫 | `#7C5BFF` |
| 极光青 | `#3DC2FF` |
| 极光粉 | `#FF6FAE` |
| 极光金 | `#FFD06F` |
| 成功 / 警告 / 错误 | `#28C285` / `#FF9442` / `#FF4E6E` |

4 个极光色被反复组合：品牌 mark 是从紫到青到粉到金的 conic 渐变；KPI 图标分别用紫青 / 青粉 / 粉金 / 金紫；按钮是紫青 110° 渐变；账单合计 box 也是。

## 字体
- 全局：**Manrope**（带轻微圆角的现代几何无衬线，weight 跨度 500–800）
- 数据：**JetBrains Mono**

字号最大处是 Hero 的 78px 大数字，下面所有 KPI 都收到 28px——制造视觉聚焦。

## 布局
- 240px 边栏玻璃，圆角 24px
- 顶栏玻璃 + 渐变文字 H1（"这周状态不错"用紫粉渐变）
- Hero 是**双栏**：左 78px 渐变大数字 `2,418,902` + 一段叙述；右一个 **流光圆环 SVG**（中心写 `QUOTA 72% · 2.42M / 3M`，外环是紫青粉金的 conic 渐变 stroke）
- KPI 4 列玻璃卡，每张左上小渐变方块图标
- 主区两栏：日志（玻璃 + 渐变状态徽章）+ 成员/账单
- 账单"合计"是**饱和紫蓝渐变块 + 阴影**

## 签名元素
1. **真在动的极光**——背景 4 个彩色球各自有 22–30 秒长的 `transform translate + scale` 动画，且 `mix-blend-mode:multiply`，互相穿过时颜色会变浊；这是**唯一一套真使用动画背景**的方案
2. **Hero 的渐变文字大数字 + 流光圆环 SVG 双签名**——两套渐变（120° 文字渐变 + 圆环 conic 渐变）协奏
3. **conic-gradient 头像环**——每个成员 avatar 外圈是紫青粉金的 conic 描边

## 适用场景
AIGC / 设计工具 / 创作型 SaaS / 出海消费品控制台。气质偏年轻、有情绪、想表达"我们是有美感的产品"。**不适合**：政企 / 工业 / 严肃 B2B；同时**渲染开销最高**（4 个 blur(80px) 的 blob + 全页 backdrop-filter），低端设备上要降级。
