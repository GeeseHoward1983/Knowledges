# 12 · 沙丘 / Dune-Pastel

> 暖沙漠调色板 + 手绘 SVG 沙丘 + 圆角"鹅卵石"图标，把后台做得像一本插画绘本。

## 设计立场
注意：AI 默认套路 1 是「奶油背景 + 衬线 + 赤陶」。本套**借用了暖底色**，但用以下手段彻底拉开距离：

1. 配色不是奶油白 (`#F4F1EA`) 而是**沙色** `#EFE4CF`——更暖、更黄、更"植物染"
2. 衬线字 Fraunces **不用于大数字**（避开 AI 默认那个 64px serif 大数字模板）；改用作 H1、卡片标题这种"轻发声"的场合
3. 主色不是赤陶/橙红，而是**橄榄 + 奶酪 + 陶土**三色组——一组真正属于沙漠植物学的配色
4. Hero 里放了一张**手画的卡通沙丘 + 骆驼 + 仙人掌 SVG**——AI 默认套路绝对不会画卡通插画
5. 图标和头像用**不规则 14/26 圆角的"鹅卵石"形状**（`border-radius:14px 26px 14px 26px`）

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#EFE4CF` 沙 |
| 浅 / 卡纸 | `#F8F1DF` |
| 主文字 | `#3A2E1F` 棕墨 |
| 次文字 | `#7A6748` |
| 橄榄 | `#7B8D55` → `#5E6D3D` |
| 奶酪 | `#F3C97C` → `#D9A745` |
| 陶土 | `#C56A4A` |
| 玫瑰 | `#D67A8C` |
| 淡紫 | `#9A7CA6` |

陶土只是 5 个颜色之一，且只在 hero 段落 / 错误 chip / 极少处出现，不是 AI 默认套路里"一抹赤陶救全场"的角色。

## 字体
- 显示字：**Fraunces**（仅用于 H1、卡片标题、KPI 数字、合计金额）
- UI / 正文：**Quicksand**（带圆角的几何无衬线，搭配鹅卵石图标）
- 数据：**JetBrains Mono**

字体角色严格分工，避免衬线泛滥。

## 布局
- 240px 边栏，底部画了 3 个**沙丘剪影**（径向渐变拼出来），是签名细节
- Hero 是**左文 + 右插画**的对称构图，插画占近 40% 面积
- KPI 3 列横排，每个 KPI 左边都有一颗**鹅卵石图标**
- 主区两栏：调用日志 + 成员 + 账单
- 通讯录头像也是鹅卵石形

## 签名元素
**整张手绘 SVG 沙漠插画**：远沙丘 + 近沙丘 + 太阳 + 云 + 仙人掌 + 站着的卡通骆驼。这是其它 19 套都没有的——它把"暖色后台 = AI 默认套路"翻转成"暖色后台 = 一本绘本"，让人无法误认是模板。

## 适用场景
独立咖啡 / 茶 / 香薰 / 手作品牌的电商后台；亲子 / 教育 / 旅行 SaaS；任何想表达"温暖、慢、有故事"气质的产品。**不适合**：金融、政企、运维、严肃 B2B。
