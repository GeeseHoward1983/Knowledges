# 02 · 苔原 / Tundra

> 一套面向「需要让客户读得下去大量数据」的报刊感后台风格，温暖、严谨、不刺眼。

## 设计立场
后台不一定要冷。把控制台当作一份印在再生纸上的内部周报：暖灰底纸、深苔藓绿主色、细虚线分隔、衬线大标题里直接嵌入 sparkline。读起来像翻一份精心排版的内部刊物，而不是登录一台机器。

避开了 AI 默认套路 1（奶油+衬线+赤陶）——同样是暖底色 + 衬线，但配色压根没用赤陶/橙红，主色是低饱和的苔藓绿，整体偏植物学家的笔记，不是手作品牌的 landing page。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#E8E4DA`（暖灰） |
| 面板底 | `#F2EFE7`（米纸） |
| 边栏底 | `#DDD8CB` |
| 主文字 | `#2C3A2E`（墨绿黑） |
| 次文字 | `#5A6657` |
| 分隔实线 | `#A89F88` |
| 主色 | `#4A6B3A` 苔藓绿 / 辅 `#6B8F4E` |
| 数据条 | `#C4D2A8`（浅地衣绿） |
| 警告 | `#C28A2C` 琥珀 |
| 错误 | `#9B3F3F` 莓红 |

整页没有任何饱和度高于 60 的颜色，是有意压抑的——给客户看一整天眼睛也不疲劳。

## 字体
- 显示字 / 大标题 / 大数字：**IBM Plex Serif**（理性、不抒情、IBM 自家给数据可视化定的衬线）
- 正文 / UI：**IBM Plex Sans**
- 时间戳、端点、用量数字：**IBM Plex Mono**

整个 Plex 家族都来自同一支团队，混排不打架；用衬线做"读物感"，但把它压在 30–34px，不滥用到正文里。

## 布局
- 220px 边栏 + 流式主区
- 标志性的"指标横条"——4 列 KPI 横跨整宽，上下双实线、列间虚线，模仿报纸数据栏
- 主区下方 1.55:1 的双栏：左侧日志表，右侧 成员 + 账单 纵向堆叠
- 信息密度偏高，但行高、虚线、留白都按印刷规范排过

## 签名元素
**句子里直接嵌的 sparkline**。页面 H1 不是冰冷的"仪表盘"三个字，而是一句话："早安，林安琪。本月调用量正在 ▁▁▂▂▃▃▄▄ 稳步上升。"——那个 sparkline 是行内 SVG，跟着文字基线走。这是其它 19 套都不会做的事情。

## 适用场景
信息密度大、客户每天要读的后台：财务对账、调用日志、订单流水、合规审计。不适合需要"科技感/酷感"的产品，也不适合给非读者型用户。
