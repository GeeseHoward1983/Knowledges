# 17 · 复古运算 / Retro-Compute

> 一套 1995-1998 PC-98 / Win 3.1 风格的后台：双线像素窗口、米黄窗体、米/红/蓝四色限定。

## 设计立场
不是模拟"现代复古"——是直接做成 **NEC PC-98 + Windows 3.1 上的应用程序**。所有 KPI 都是一个独立"窗口"：标题栏蓝色渐变、右上角『— □ ×』、菜单栏 `_F_ile _E_dit ...`、状态栏分割成多个 cell、底部任务栏 + `▣ Start` 按钮。一切元素都靠 `box-shadow:inset` 的双线高光实现"凸起 / 凹陷"的硬质阴影，零圆角、零渐变，完全像素感。

桌面背景是 PC-98 经典深蓝 + 8px 点阵网格。左侧"程序图标"模仿桌面快捷方式：每个图标是一个浮起的米黄方块，下面的"label"被选中时变成蓝底白字。

只有 5 种颜色变体——硬件调色板限制感。

## 字体
- 像素感大数字：**VT323**（开源版 VT220 终端字）
- UI / 菜单 / 标签：**MS PGothic** / **Microsoft YaHei**（中文等宽兜底）

VT323 用在 KPI 数字、状态码、时钟、表格等宽栏。MS PGothic 用在窗口标题、菜单、正文，是真正的"Win 3.1 + PC-98 UI 字"组合。

## 布局
- 桌面 14px 留白
- 左侧 220px"桌面图标"竖列（仪表盘.EXE / 实时调用 / API_KEYS / WEBHOOKS / 成员名册 / 计费.TXT / CONFIG.SYS / 回收站）
- 主区是一个大窗口 `NORTHWIND.EXE — 控制台 / 仪表盘 / 生产 / ap-southeast-1`
  - 标题栏 + 菜单栏 + 状态栏（用户 / 环境 / 区域 / Stream / 时钟）
  - 4 个独立子窗（KPI）平铺
  - 下面两栏：左 `access.log — Notepad`、右上 `members.dbf — Roster`、右下 `billing.txt — Notepad`
  - 底部"任务栏" + `▣ Start` 按钮 + CAPS NUM 时钟指示

每一个面板都是一个完整窗口，自带标题栏 + 控制按钮。

## 签名元素
1. **每个 KPI 自己也是一个完整窗口**——4 个并排的"打开着的小程序"。AI 默认绝不会做这种"窗中窗"嵌套。
2. **底部任务栏 + Start 按钮**——是完整桌面环境的还原，不是单页应用。
3. **像素进度条用 `repeating-linear-gradient` 画双色条纹**——模仿真实 DOS 应用里"满槽 = 蓝白条纹"的视觉。

## 适用场景
极客向 / 工具复古党 / 游戏 / 老学校 IT 工具 / 复古 dev tools 的高级模式或 "Nostalgia toggle"。也适合做 hackathon / dev community 的副业项目门面。**不适合**：面向严肃企业客户、需要专业感的场合——会被当成"在装可爱"。
