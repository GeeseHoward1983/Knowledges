# 21 · 莫奈花园 / Monet-Garden

> 印象派油画美学 + 厚涂玻璃 + 抒情衬线大字。

## 设计立场
borrowed inspiration：**Apple Vision OS** 的"用玻璃浮在自然图像上"思路 + **莫奈睡莲池**的色彩学。整页底层是 4 团水池色色斑（睡莲粉/池蓝/柳绿/日金/鸢尾紫）+ 笔触椭圆 SVG + 噪点，**像一块没干透的颜料**。所有面板用厚玻璃（24px 模糊 + 140% 饱和）漂在上面。

与 01·极地玻璃的区分：
- 01 是冷调静态、噪点弱、用 Fraunces；
- 21 是**多彩有机色斑 + 真笔触椭圆**、用 DM Serif Display 抒情大字。

与 20·渐变流光的区分：
- 20 是**单一光滑渐变球**在动；
- 21 是**笔触斑点是静态的、有不同方向旋转的椭圆**——绘画感而不是数字感。

## 字体
- 显示字 / KPI / 大数字：**DM Serif Display**（带浪漫意味的现代衬线，weight 400 即可)
- UI / 正文：**Manrope**
- 数据：JetBrains Mono

衬线字只用在"被瞻仰"的位置，UI 控件全用 Manrope。

## 布局
- 240px 玻璃边栏，导航项前是小色圆点（活跃时变粉 + 光晕）
- Hero 把 KPI 写成一句**抒情句子**："晨光里的 *240 万次* 正在往岸上轻轻爬。"
- 4 张 KPI 每张右上角藏一颗**糊掉的色块**（绝对定位 + blur(20px)）
- 主区两栏：日志 + 名册/账单
- 头像用径向渐变（睡莲粉/池蓝/柳绿/鸢尾紫）+ DM Serif 大字"林/陈/蒋/袁"

## 签名元素
1. **油画笔触背景** —— body::before 是 SVG 嵌入的 8 颗椭圆笔触，每颗不同旋转角、不同颜色
2. **KPI 卡片右上角糊掉的色块** —— 像调色板上滴下的颜料
3. **抒情衬线 H1** —— 不喊数字，讲"晨光里的 240 万次正在往岸上轻轻爬"

## 适用场景
艺术、文创、香水、花店、设计、画廊、独立精品酒店等审美型客户。**不适合**：开发者后台、运维监控，会显得太抒情。
