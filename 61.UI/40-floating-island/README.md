# 40 · 浮岛 / Floating-Island

> 游戏 UI / 起源岛屿美学：粉蓝渐变天空 + 卡片悬浮 + 模糊投影光斑 + 手绘浮岛插画。

## 设计立场
灵感：《纪念碑谷》、《Sky 光遇》、Mac OS Big Sur 浮岛壁纸、Apple Pages 模板。整页核心：
- 三色天空渐变（粉蓝→淡粉→蜜黄）+ 2 团巨大柔光（绿岛/粉岛）
- 所有面板都是真正"浮"在天空上：圆角 26px + 0 24px 投影 + 底部 22px 椭圆模糊投影（让卡片像漂浮）
- Hero 插画是手绘 SVG **真浮岛**：1 大（绿草地 + 房子 + 2 棵树）+ 2 小（蓝/橙）+ 太阳 + 云 + 飞鸟
- H1 是温情对话："本月已经飞过 240 万次云"（不是冷数据）
- KPI 4 张浮岛卡片各自有彩色渐变图标 + 长投影

与 15·韩系明亮、20·渐变流光、12·沙丘的明确区分：
- 15·韩系是 Toss 白蓝平铺 + 笑脸；
- 20·渐变流光是 4 团暗紫极光在动；
- 12·沙丘是手绘沙漠骆驼插画；
- 40·浮岛是**真浮岛 + 蓝粉蜜黄三段天空**——气质是日间游戏开场画，每张卡都有"底部投影 + 悬浮感"。

## 字体
- 全页：**Nunito**（圆润几何无衬线，weight 600-800，适配浮岛感）
- 备选：Plus Jakarta Sans / Inter
- 数据：JetBrains Mono

字重整体粗（700/800），适配浮岛圆角的柔软。字号 H1 22-42px。

## 布局
- 240px 边栏（圆角 26px 浮岛卡）：品牌 mark 是 4 色渐变方块，nav 项前彩色渐变图标，active 项是 110° 渐变 banner + 6px 投影
- 顶 toolbar 浮岛：H1 "下午好，林安琪 — *今天有云，向阳。*"
- Hero 两栏：左侧 42px H2 + italic 副标 + 友好建议；右侧**手绘 SVG 真浮岛**（绿大岛 + 蓝/橙小岛 + 太阳/云/飞鸟）
- KPI 4 张浮岛：左上彩色渐变方块图标 + 30px 数字 + delta pill
- 主区两栏：日志 + 名册/账单，每张都有 0 24px 48px 投影 + 底部椭圆模糊投影
- 账单 Total 行：渐变粉蓝大色块 + 0 12px 28px 投影

## 签名元素
1. **`.float::after` 底部椭圆模糊投影**：每张卡底部 `bottom:-12px` 处加一道 22px 椭圆 + 12px 模糊 + 蓝紫 0.16 透明度，造成"卡片漂浮"的视觉
2. **手绘 SVG 浮岛插画**：3 块浮岛（草地房子 + 蓝 + 橙）+ 太阳 + 云 + 鸟，全部自绘
3. **天空 3 段渐变 + 2 团柔光 blob**：粉蓝→淡粉→蜜黄叠加绿/粉 240px/180px 大 blur(50px) 圆
4. **彩色渐变图标**：4 套 nav + 4 套 KPI 图标都是 4 种岛色的 135° 渐变方块

## 适用场景
游戏 / 教育 / 儿童 / 内容平台 / 旅行 / 健康 / 创意工具 / 友好型 SaaS。**不适合**：严肃 B2B、金融、政企、运维监控。
