# 13 · 草图 / Sketch-Wireframe

> 一套故意做成"刚画完的草稿本"的高保真后台，所有元素都有手写感、抖动、便签注释。

## 设计立场
绝大多数后台都用力把自己装得"很专业、很整洁、很完美"。**故意反过来**：用方格本背景、手写字体、不规则圆角（每个圆角四个值不同：`5px 7px 4px 8px`）、卡片轻微倾斜（旋转 -1.2°、+0.4°）、便签纸、手写注释、马克笔色块。客户打开它的感觉是"这是产品经理刚和我聊完，从笔记本上撕下来给我看的方案"——亲切、降低距离感。

但底层信息架构和其他套一样：边栏 / 顶栏 / KPI / 日志 / 成员 / 账单都齐全，仅仅是**视觉层**是草图。

## 字体
- 显示字 / 标题 / KPI 数字：**Caveat**（手写圆珠笔感）
- 正文 / 标签：**Kalam**（更工整的手写）
- 端点 / 时间戳：**JetBrains Mono**（保留可读性 —— 草图不代表牺牲专业性）

字号都偏大（H1 46px、KPI 42px），手写字本身需要尺寸来承载性格。

## 布局
- 230px 边栏整块是一个"草图"sketch 边框（双层：实线 + 内层虚线）
- 边栏品牌方框略微旋转（-3°）、贴一片"荧光笔"色块
- 顶部 H1 是手写句子 + 黄色荧光笔下划线 + 旁边贴一张**真便签**（旋转 -1.2°，带阴影）
- 4 块 KPI 每个旋转角度不同（-0.6° / +0.4° / -0.3° / +0.7°）
- 调用日志里**500 错误那一行**用淡红色高亮 + 红色手写箭头注释"↑ 又是这个！"
- 账单的"合计"是一个带荧光笔色块、稍微转 -0.6° 的方框，强调"这是手写圈出来的总数"

## 签名元素
1. **便签纸** + **手写红笔注释**："顺丰那个 500 错误你看到了吗？最近三天集中在 14:00 前后。↗ 我标了一下。" —— 模拟一个同事在屏幕上贴了张便签留言
2. **进度条用 45° 斜线条纹**（`repeating-linear-gradient`）画，不是实心填充——一目了然是"用笔涂的"
3. **角色徽章用波浪下划线**（`text-decoration-style:wavy`）——手写圈定的感觉

## 适用场景
内部 demo、原型评审、设计公司面向客户的看板、教育 / 创意 / 启动期产品。**绝对不适合**：金融、医疗、政企，看了会觉得"还没做完？"
