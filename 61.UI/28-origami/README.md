# 28 · 折纸 / Origami

> 折纸艺术 × 现代 Material/Memphis：每张卡片像一张折过角的彩纸，每个面是不同色。

## 设计立场
灵感：日本折纸（origami）+ Memphis Design + 平面化的 Material 风格。整页核心视觉语言：
- 每张卡片右上角有一道 **64px 的实体折角**——用 `border-style:solid; border-width: 0 64px 64px 0; border-color: transparent var(--ink) ...` 实现真正的三角斜面
- 每个面板都有 4-6px 的硬投影（无 blur），像贴在桌上的彩纸
- KPI 用四张大色块（朱橙 / 群青 / 柠黄 / 松绿 / 紫）+ 折角，像四种颜色的彩纸正准备被折成纸鹤
- Hero H1 是真情绪："本月已折出 240 万张纸鹤——继续。"

与 23·苏维埃构成、09·瑞士格的区分：
- 23 是宣传海报红黑黄 + 倾斜几何块 + 大色块对撞，气质是革命；
- 28 是折纸彩纸 + 顶部折角 + 硬投影，气质是手工；
- 28 的"折角"是**真三角形 CSS**，不是 SVG。

## 字体
- 全局：**Plus Jakarta Sans**（带轻微现代感的几何无衬线，weight 600-800）
- 数据：JetBrains Mono

字重整体粗（700/800），适配硬投影的厚重感。字号跨度大（11px label → 46px H1）。

## 布局
- 240px 米色边栏，分区标题前有一颗 8px 朱橙小三角（`clip-path:polygon(0 0,100% 0,100% 100%)`），active 项有 1.5px 黑底反白 + 右上柠黄折角
- 顶 toolbar：crumb + 搜索 + 3px 硬投影按钮（点击时投影消失，按钮"按下去")
- Hero 是一张朱橙折纸：双层折角（深朱+黑色叠加），H1 中"240 万"用柠黄底盖章
- KPI 4 张彩色折纸，每张右上角都有一个 64×64 黑色折角（透出底色）
- 主区两栏：日志 + 名册（头像是五边形 `clip-path` 折角剪裁）+ 账单（合计是柠黄大块带 4px 硬投影）

## 签名元素
1. **真折角 `.crease.tr` + `.crease.tr-inner`**——4 张 KPI 每张右上角的两层三角形（黑底 + 米色叠加）模拟"折过的纸角"
2. **硬投影 `box-shadow: 6px 6px 0 var(--ink)`**——所有按钮、所有面板都有这种 0 blur 的实体投影
3. **五边形折纸头像**（`clip-path:polygon(0 0,100% 0,100% 70%,70% 100%,0 100%)`）—— 右下被折掉一角

## 适用场景
教育 / 儿童产品 / 创意工具 / 文具 / 设计 SaaS / 出版。**不适合**：金融、政企 To B、运维监控。
