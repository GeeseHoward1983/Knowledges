# 05 · 信笺 / Letterpress

> 一套面向「面向有阅读门槛的客户、需要让后台看起来像一封郑重的来信」的中式信笺风格。

## 设计立场
把控制台**翻译**为一封系统发给客户的中式公函。页面整体是米黄信纸 + 横向罫线，正文用 H1 写敬称、用一段引言交代要点，然后才是邮票样式的 KPI 和流水实录、通讯录、本期账目；最底有"敬颂时祺"和签名。把"管理后台"这种工具拟人成"系统的一封信"。

绕开 AI 默认套路 1（奶油 + 衬线 + 赤陶橙）的方式：
1. 主点缀色不用赤陶/砖橙——用**酒红印章 `#7C3A2E`** + **钢笔墨蓝 `#2E466E`** 的中式公文配色。
2. 衬线字用思源宋体，不是 Fraunces/Cormorant，气质从"现代西文优雅"变"中式公文"。
3. 状态徽章用"已受 / 限流 / 骤断"这样的措辞，不是 "Success / Failed"。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#F6F1E4` 米黄信笺 |
| 卡纸 | `#EEE7D4` |
| 主文字 | `#2A2620` 墨黑 |
| 次文字 | `#6B5F4E` |
| 罫线 | `#C7BB9E` 实 / `rgba(42,38,32,.12)` 点 |
| 印章酒红 | `#7C3A2E` |
| 钢笔墨蓝 | `#2E466E` |
| 成功 / 警告 / 错误 | `#5B7A47` / `#B58A1F` / `#9B362E` |

底层有信笺横线（每 32px 一道）+ SVG fractalNoise 纸纹，让屏幕看起来真的像纸。

## 字体
- 显示字 / 大标题 / 大数字：**Source Han Serif SC**（思源宋体）
- 正文：思源宋体常规
- 数据 / 时间戳 / 端点：**JetBrains Mono**
- 标签 / Eyebrow：**Inter** 极小号、字间距大

中英文混排里，英文用 Lora 兜底，但绝大多数面向用户的文字是中文，让宋体唱主角。

## 布局
- 240px 左侧装订条（背景渐入 + 虚线钉孔）
- 主区一上来不是 KPI，而是"敬启者"信文开头 + 日期落款 + 一整段叙述性引言
- ❦ ❦ ❦ 花饰分隔之后才是邮票卡片（边缘有齿孔切割）
- 流水实录每一行都写成"主语 · 谓语 · 端点 · 状态徽章 · 耗时"的句子形式，而不是干巴巴的表格
- 末尾还有"敬颂时祺"+ 系统签名

## 签名元素
**圆形印章**——左上角的"北"字红色印章，以及通讯录右侧每个成员都有一枚独立角色印（主 / 管 / 研 / 阅）。印章用半透明径向渐变 + 内嵌一道细圆边模拟印泥效果。

## 适用场景
面向中老年客户、政企对接人、法律 / 财税 / 文教这类气质偏文雅、需要"被郑重对待"的场景。**不适合**面向开发者或年轻 To-C 用户的后台——会显得过分文绉绉。
