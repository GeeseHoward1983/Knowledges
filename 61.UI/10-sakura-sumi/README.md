# 10 · 樱与墨 / Sakura-Sumi

> 一套以日式和纸 + 墨 + 一抹樱粉为底层语义的极克制后台。

## 设计立场
"侘寂"（wabi-sabi）的工业版。整页：和纸米白底 + 墨黑字 + **唯一彩色 = 樱粉**。结构上借鉴日式杂志：横排正文 + 右上一栏**竖排日期**（writing-mode: vertical-rl）作为视觉锚点。这是其他 19 套都没有的东西。

和 05·信笺的区分点：
- 信笺是"中式公函"，开篇是"致 ⋯ 启："+ 印章；
- 樱与墨是"日式杂志"，开篇是"本月运行小记 — 晴"+ 竖排日期；
- 信笺用酒红印章，樱与墨用单色樱粉，且樱粉**只在 5 个点**出现：品牌印章、活跃导航项、关键 KPI 后三位数字、500 状态徽章、合计金额。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#FAF7F2` 和纸米白 |
| 卡纸 | `#F2EDE3` |
| 主文字 | `#1A1A1A` 墨黑 |
| 次文字 | `#5C5852` |
| 实线 | `#1A1A1A` |
| 细线（点 / 虚） | `#D8D2C5` |
| **唯一彩色** | `#E66985` 樱粉 / 浅 `#F2A8B8` |

底层有一层 SVG fractalNoise 和纸纹理。

## 字体
- 全局显示：**思源宋体（Source Han Serif SC）** + 兜底 Noto Serif JP
- 数据：**JetBrains Mono**
- 标签 / Eyebrow：**Inter** 字间距 0.2em

宋体是绝对主角，字号跨度 11px–38px；不像 05·信笺还有"印章 / 通讯录"那种章法元素——本套更素，更"留白"。

## 布局
- 200px 边栏（极简，类型为王）
- Header 是横排 + 竖排日期的 split：左占 8 栏写正文，右占 4 栏的「令和八年 / 六月十九日 / 星期五 · 14:02」竖排
- KPI 是 4 列等宽 + 单根 1px 细线分隔，没有色块
- 名册（Roster）每个人用"姓"字单独装在小方框里——签名细节
- 调用日志的状态徽章：200 是黑字 + 无线，429 是黑字 + 下方一根樱粉短线，500 直接樱粉本色

## 签名元素
**右上的竖排日期 + 名册"姓字方框"**。两者都属于本套独有，且**只有日式排版会自然出现**。竖排不仅是装饰——它把"现在是哪天"做成了视觉锚点，告诉用户"这是一封一封产生的报告"。

## 适用场景
设计、文创、出版、香水 / 茶 / 酒精品类、内容平台等对审美苛刻的客户。**不适合**重度数据 / 大量交互的运维场景。
