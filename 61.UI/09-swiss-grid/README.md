# 09 · 瑞士格 / Swiss-Grid

> 严格 12 栏 + 极致类型纪律 + **单一红色焦点**的瑞士国际主义后台。

## 设计立场
向 Müller-Brockmann 致敬。整页只用：
- 纯白底
- 纯黑字
- **一种**点缀色：瑞士红 `#E63A2E`
- 真正的 12 栏网格 + 实线 / 细线两级分隔
- 极简类型层级：超大数字、小号标签、tabular 数字对齐

并且**明确避开 AI 默认套路 3（报纸排版）**——AI 默认套路用的是衬线显示字、密集文字栏、复古信纸感；本套**全程无衬线**（Inter）、并把大数字推到极限（128px），让信息层级是"数字 → 标签"而不是"标题 → 段落"。点缀色只在 4 处出现：本月数字的后六位、错误率 KPI、500 状态码、合计金额的小数。其他地方都被克制下去。

## 配色
| 角色 | 取值 |
| --- | --- |
| 背景 | `#FFFFFF` |
| 主文字 | `#0A0A0A` |
| 次文字 | `#5C5C5C` |
| 实线 | `#0A0A0A`（2px 双重作用：分章节 / 重点 KPI） |
| 细线 | `#D6D6D6` |
| **唯一点缀** | `#E63A2E` 瑞士红 |

没有渐变、没有阴影、没有圆角（border-radius 全 0）。

## 字体
- 全局：**Inter**（开启 `font-variant-numeric:tabular-nums` 和 stylistic set，让数字对齐如表格）
- 数据时间戳：**JetBrains Mono**

Inter 字重 500/600/700，无其他。大数字 128px、KPI 38px、Eyebrow 10.5px——三个层级、字间距精算。

## 布局
- 200px 边栏（极简，导航是 `<a>` + 编号）
- 主区严格 12 栏：
  - Hero 8 + 4 拆分，左侧 128px 大数字 "2,418,**902**"，右侧加边竖线再分一段元信息
  - KPI 行 4 × 3 列，列之间细线分隔
  - 主内容 8 + 4：左侧调用日志（占主导），右侧成员 + 账单纵向堆
- 章节标题之上一律 2px 黑线，下面是 14px H3 + 标题旁边小型工具组

## 签名元素
**Hero 的大数字 + 红色焦点**。128px 的数字 "2,418,**902**" 把后六位用瑞士红着色，是整页**最大且最响的**视觉符号——读到 902 时眼睛会自然把它们和后面 "+12.4%" 的红色 delta 串起来，构成视觉因果链。

## 适用场景
工业设计、建筑、出版、印刷、咨询等审美要求高、客户本身有设计鉴赏力的场景，或者面向开发者文档站的"专业控制台"。**不适合**：信息密度极大需要彩色编码的运维场景；面向不熟悉数据的小白用户。
