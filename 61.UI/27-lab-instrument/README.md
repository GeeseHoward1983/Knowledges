# 27 · 实验室仪表 / Lab-Instrument

> 老 HP 测试仪 / 示波器机柜面板美学：拉丝铝 + 内嵌 CRT 屏 + 旋钮 + 螺钉 + LED 指示。

## 设计立场
灵感：1970s HP/Tektronix/Fluke 实验室仪器面板。每个模块是一块**拉丝铝外壳**（4 个角带螺钉 `.bolt`），上面挖出一个**深绿 CRT 屏**（自带扫描线 + 内辉光），屏内是 VT323 等宽磷光绿字。整页就像一面工业测试机柜——左侧机箱有 4 颗银色旋钮，4 个 KPI 是 4 个表头模块，主区两个大屏是"通道 CH-01 / CH-02 / CH-03"。

与 07·终端 CRT、16·暗黑材料、19·暗色实验室、26·像素彩窗的明确区分：
- 07 是**全屏终端**——所有字都是磷光绿等宽，没有外壳；
- 27 是**机柜+屏的两层**——金属拉丝外壳上**挖出**屏窗，磷光绿只在屏窗内，外壳上的标签是工业感无衬线（Orbitron / Roboto Condensed）；
- 16·暗黑材料是石板灰 + 工程橙工业感，**没有真屏**；
- 19·暗色实验室是学术 italic 衬线 + 公式 KPI，**没有任何机械感**；
- 26·像素彩窗是教堂彩绘玻璃高饱和色块。

机壳上的标签是浅米灰，**只有屏窗里**是磷光绿。

## 字体
- 机壳标牌 / 模块标签：**Orbitron**（科技感几何无衬线，1970s 工业仪器面板风）
- 仪器副标 / 状态 / 单位：**Roboto Condensed** + 大字间距大写
- 屏内数字 / 表格 / 日志：**VT323**（等宽磷光感）
- 中文：PingFang SC

Orbitron 给品牌牌「NORTHWIND · CLOUD · MOD. 2.18」、Roboto Condensed 给所有 channel 标签 `CH-01 · ACCESS LOG`、VT323 仅在屏窗内出现——三段式字体分工，像真测试仪。

## 布局
- 230px 左侧"机柜"：四颗银色旋钮（CSS 径向渐变 + 内阴影 + 一根磷光指针）+ 品牌铭牌 + 三段 nav（SECT · A/B/C），每条 nav 前一颗 LED（active 时变磷光绿 + 0 0 6px 光晕）
- 顶部 header bar 也是金属面板：4 颗 bolt 角钉 + 5 个小窗 meter（USR / ENV / RGN / P95 / UPTIME）+ STREAM / PAUSE toggle 开关（active 时变绿）
- 4 个 KPI 模块：每个上半是标签 + LED，下半是嵌入的 CRT 屏（带扫描线 + 顶部高光）
- 主区两栏：左 CH-01 ACCESS LOG（带 LED 灯带亮 3/5）+ 右 CH-02 ROSTER + CH-03 BILLING
- 名册头像是 38×38 屏窗，里面亮一个磷光绿汉字"林/陈/蒋/袁"
- 账单合计带琥珀色边框（错误超过阈值时的"警示色"）

## 签名元素
1. **`.panel-metal`**：高光顶部 + 拉丝竖纹 + 底部阴影 + 4 颗 `.bolt` 角钉（每颗 radial-gradient + 内"+"形十字纹）
2. **`.screen` CRT 屏**：扫描线 + 内辉光 + 边框磷光描边 + 1px 内反光
3. **4 颗实物旋钮**（CSS 纯渐变 + inset shadow + 旋转过的磷光指针）
4. **LED 灯带 led-strip**：5 个小圆点，部分亮，模仿仪器面板的电平指示

## 适用场景
工业 SaaS、SRE、IoT 网关、能源 / 制造 / 半导体后台、测量仪器云端控制台、网络运维。**不适合**：消费 / 教育 / 文创——气质会显得过分硬核。
