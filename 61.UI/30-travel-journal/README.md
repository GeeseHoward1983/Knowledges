# 30 · 旅行手账 / Travel-Journal

> 把控制台装订成一本牛皮封皮的旅行手账：邮票 KPI + 行程时间线 + 圆形邮戳。

## 设计立场
灵感：Moleskine 旅行手账 + Lonely Planet 老地图册 + 老式邮政邮票。整页核心比喻：把"本月调用"**翻译成"本月里程"**——
- 牛皮封面（左侧边栏，深棕 + 噪点 + 金色缝线 + 烫金 N 印章）
- 主区是手账内页（米黄纸）
- KPI 是 4 张邮票（每张带齿孔 + 邮值 № 01 · ¥ 4.20）
- 调用日志是"行程日记 / Itinerary"：每条变成一句话（"京东数科 来访 · 顺 92ms"，"顺丰 查单失败 · 颠 1.42s"），状态徽章用汉字"顺 / 缓 / 颠"代替"200 / 429 / 500"
- 成员叫"同行人"，角色叫"领队 / 协理 / 伴行 / 观光"
- 账单叫"旅费"，套餐叫"月票"，超量叫"超量里程"，发票叫"票据"
- 大邮戳：右上角倾 -12° 的红色圆章"已抵 SHANGHAI 06·19"

与 13·草图、05·信笺、22·鎏金的明确区分：
- 13·草图：方格本 + 手写抖动 + 便签贴；
- 05·信笺：米黄信纸 + 中式公函体；
- 22·鎏金：深松石绿 + 鎏金线 + 朱印 + 古文数词；
- 30·旅行手账：**牛皮 + 邮票齿孔 + 行程地图箭头 + 倾斜邮戳**，整页气质是"刚结束一趟出差的旅行本"。

## 字体
- 手写主显示：**Caveat**（自然圆珠笔感）
- 中文兜底：思源宋体
- UI 标签 / Eyebrow / 时间戳标签：**Quicksand**（圆角无衬线）
- 等宽（端点）：JetBrains Mono

字号跨度大：手账纸 H1 48px Caveat，邮票 KPI 38px Caveat，正文 19px Caveat，标签 11px Quicksand。

## 布局
- 240px 牛皮封皮边栏：顶部金色 N 烫金圆章 + 分区标题用 Caveat 18px 波浪线下划线 `Itinerary / Supplies / Logbook`，导航项前 `✈`
- 顶 toolbar：手写"日志 · 第 19 日 · ap-southeast-1 · 多云"
- Hero 两栏：左侧手写 H1（"六月十九日，*晴*。这一程已走过 *240 万* 里。"）+ 右上倾斜红邮戳；右侧"This Week's Route" PEK ✈ SHA 路线箭头 + 5 段行程
- KPI 4 张邮票：齿孔上下边（radial-gradient 切圆）+ 邮值 `№ 01 · ¥ 4.20` 标签
- 时间线日志：每行 `14:02 ● 京东数科 来访 · POST /v2/orders/sync · 顺 92ms`
- 名册头像每张倾斜（-3°/+2°/-1°/+3°）+ 2px 米色硬投影，像贴上去的小相片
- 账单合计是 2.5px 双重墨线分隔的红色大手写"¥ 2,879.50"

## 签名元素
1. **倾斜大邮戳** `transform:rotate(-12deg)` + 2.5px 红边 + 内 1px 虚线圆 + 红墨径向辉光，写着"已抵 SHANGHAI 06·19"
2. **邮票齿孔**：`radial-gradient(transparent 3px, leather 3.2px) 0 0/12px 8px` 上下两条
3. **行程地图箭头** PEK ✈ SHA：✈ 字符 + 下方蓝色虚线代表航线
4. **状态汉字"顺 缓 颠"** 替代 200 / 429 / 500
5. **角色汉字"领队 / 协理 / 伴行 / 观光"** 替代 owner / admin / dev / read

## 适用场景
旅行 / 酒店 / 出行 / 票务 / 物流 / 跨境电商 / 户外品牌 / 餐饮探店类客户后台。**不适合**：金融、政企、严谨工业类。
