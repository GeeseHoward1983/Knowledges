# 18 · 文档式 / Notion-like

> 把控制台做成一篇可编辑的 Notion 文档：封面 + emoji 大图标 + 属性面板 + 数据库视图。

## 设计立场
绝大多数后台用"应用 UI"逻辑：左栏 + 顶栏 + 卡片。本套换成**"文档 UI"逻辑**：左栏是工作区树（含 emoji 图标的折叠 page tree）+ 主区是一篇文章——封面色块、64px emoji 大图标、可编辑的 H1、属性面板（状态 / 所有者 / 区域 / 更新时间 / 关联文档）、行内 callout 提示框、数据库表格视图、`/upgrade` 这样的内联斜杠命令。

阅读它的客户感觉是："我在看一份**给我**写的运行报告，而且我可以随时往下接着写。"

## 字体
- 全局：系统字（`-apple-system / SF Pro Text`），完全跟随原生 Notion
- 中文兜底：PingFang SC / Microsoft YaHei
- 等宽（端点、时间戳、邮箱）：JetBrains Mono / SF Mono

没有任何衬线字体。字号最大也只有 40px（H1）和 22px（H2），完全是"阅读节奏"，不是"展示数据"节奏。

## 布局
- 248px 边栏：工作区切换器（`N · Northwind` 头像 + 邮箱 + 折叠 chev） + 快捷栏（🔍/⏱/✦/🏠/📥/⚙） + 三级 page tree（收藏 / 工作区 / 共享，含子页缩进）
- 顶部 breadcrumb：`Northwind / 仪表盘` + 右侧"编辑于 · ★ · ··· · Share"
- 文档头：橙色封面色块 + 64px 📊 emoji + H1 + 5 行属性面板
- "本周概览"是一整段叙述文字（句子里夹蓝/黄色高亮）
- 💡 callout 提示套餐升级
- 📊 关键指标用 Notion 的"内联属性表"（4 列等宽 cell，1px 灰线分隔）
- 📋 数据库视图（access_log）—— 完整复刻 Notion 数据库的：标签页（▦ 全部 / ⚠ 错误 / 🐢 慢请求）+ 筛选 / 排序 / 搜索 / ＋ 新建
- 两栏：成员表 + 账单
- 最末是"📝 本周笔记"，输入"/"提示符——文档**还能继续写下去**

## 签名元素
1. **属性面板**——「状态 / 所有者 / 区域 / 更新于 / 关联」每一行都可点击编辑，是 Notion 的灵魂 UI 组件
2. **emoji 当图标**——表头 ⏱ 时间 / 👤 调用方 / 🔗 端点 / 🏷 状态 / ⌛ 耗时；H2 前 📌 📊 📋 🧑 💳 📝；侧栏树里每个 page 都有自己的 emoji。让控制台读起来像人写的笔记。
3. **行内斜杠命令**——`点击 /upgrade 评估 Scale 套餐` 这种用法只有 Notion / Linear 系产品才会做
4. **底部留了"/输入「/」创建块"的占位**——明确告诉客户"这页是活的"

## 适用场景
内容平台、知识管理、CRM 笔记型工具、设计协作平台、Linear/Notion 系开发工具的控制台。**不适合**：需要交易型严肃感的金融 / 政企。
