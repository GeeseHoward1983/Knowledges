# 15 · 韩系明亮 / Toss-style

> 韩国 Toss / Kakao / 当当车 / Naver 系产品的明亮、友好、对话式后台。

## 设计立场
韩国 fintech 的"明亮派"美学：超白底 + 浅蓝 + 大圆角 + 大字 + 笑脸 emoji + 友好图示 + 对话感文案。所有交互都把"你"放在第一位——H1 直接对你说话："这周的状态不错"、"距离月度目标还差 24%"、"要不要现在就考虑升级？升级后月底可省下大约 ¥640"。

这是 Toss 后台 / 当代韩系 SaaS 最显著的语言：把"统计页"翻译成"和你商量的建议"。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#F5F7FB` 极淡灰蓝 |
| 纸面 | `#FFFFFF` |
| 软底 | `#EEF1F7` |
| 主文字 | `#191F28` |
| 次文字 | `#525965` |
| 弱文字 | `#8B95A1` |
| 主色 Toss 蓝 | `#3182F6` / 软底 `#E7F1FF` / 深 `#1B64DA` |
| 成功 | `#1AB36A` |
| 警告 | `#FF9800` |
| 错误 | `#F04452` |

颜色不饱和、不冷、不闷——像韩国便利店灯光。

## 字体
- 全局：**Pretendard**（专为韩文+中英文混排设计的现代无衬线，weight 跨度大）
- 兜底：Inter / PingFang SC
- 数据：JetBrains Mono

字重整体粗（H1 800、KPI 800、合计 800），是 Toss 的标志做法。

## 布局
- 240px 边栏，分区标题用**韩文 + 中文双语**（"총괄 · 总览" / "자원 · 资源" / "계정 · 账户"）—— 是这套韩系美学的诚意细节
- 顶部 H1 用"em 蓝色突出"做强调：「这周的 *状态不错*」
- Hero 是**对话式建议 + 友好 SVG 插画**（上升的折线 + 笑脸数据点 + 小旗 + 云）
- KPI 4 列大卡片，每个左上角一颗彩色圆角图标
- 主区两栏：日志 + 成员/账单
- 账单的"本月小计"做成**整块蓝色块 + 反白文字**——是 Toss 的标志性"主操作色块"

## 签名元素
1. **Hero 的友好 SVG 插画**——上升折线上夹着一个橙色笑脸数据点，顶点插一面绿色小旗。这是 Toss / Kakao 系视觉里典型的"用情绪标记数据"。
2. **建议式文案**："要不要现在就考虑升级到 Scale 套餐？升级后月底可省下大约 ¥640" —— H1/Hero/CTA 都不是命令式，是商量式。
3. **韩中双语分区标题**——细节但有效。

## 适用场景
面向 C 端 + 小 B 端混合的轻量级 SaaS：财税 / 记账 / 储值卡 / 健康 / 教育。**不适合**：重度运维 / 严肃 B2B，会显得太活泼。
