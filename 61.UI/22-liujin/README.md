# 22 · 鎏金 / Liujin / Goldleaf

> 深墨绿底 + 鎏金细线 + 朱砂印章 + 渐变金字。东方器物质感的暗色后台。

## 设计立场
灵感：故宫文创 / 日本宗教器物 / 老牌精品的"暗中藏金"美学。整页是深松石绿底，所有面板四角带细 1px 鎏金"角线"（用 `::before / ::after` 切出"L 形 + 反 L 形"两个边角）；大字数字、标题都用**线性渐变金**（亮金 → 金 → 暗金），不是单色。点缀色只有朱砂红（用作"主"印章和"取回执"按钮）。

与 05·信笺、22·鎏金 的区分：
- 05·信笺是**米黄信纸**底色，气质是"民国书信"；
- 22·鎏金是**深墨绿**底色，气质是"故宫匣盒 / 日本宗教器具"，金色是**真金的渐变**而不是单色酒红；
- 文案上 22 用了**汉字数词**（"增一成二"、"四‱二"、"十一日后"）+ 表头单字"时来者端点状耗"，制造老中文文档感。

## 字体
- 显示字 / H1 / KPI 大数字：**Cormorant Garamond**（带 italic 的浪漫衬线，用于"鎏金感字"） + **Source Han Serif SC** 中文
- 数据：JetBrains Mono
- 标签 / Eyebrow：Inter（极小号 + 0.22em 字间距）

H1 用**线性 180° 渐变金**填充文字（`-webkit-background-clip:text`）；中英混排时 Cormorant 的 italic 给品牌名、按钮，思源宋体给中文标题。

## 布局
- 240px 边栏：顶部圆形 ❖ 北 ❖ 徽章（双圈金边 + 镭金辉光），分区标题用单字"总 / 资 / 账"+ 左右细金线
- Hero "本月运行 · Sheet 〇一" eyebrow + 一个**渐变金 H1**（"关于本月二百四十一万次调用的一份谨呈"） + 一段对仗"谨呈台览，敬颂时祺"小字
- KPI 4 张鎏金角线小卡，每个左上有汉字标题 + 右上有英文/希腊字母代号（N · MTD / m / M / ε / B）
- 主区两栏：流水实录 + 名册（朱砂印 "主" / 鎏金印 "管 / 研 / 阅"）+ 账目
- 账目"合计应付"行外框有 4 个金色实角

## 签名元素
1. **四角金线工具 `.gilt`**：每个面板四个对角线切一个金色"L"形，仿古匣盒切角
2. **渐变金大字** `-webkit-background-clip:text`：H1 + 合计金额都是真金渐变
3. **朱砂圆形印章**用作"主"角色 + 灯笼放射状的红色径向渐变
4. **汉字单字 nav** + **汉字数词文案**（"增一成二"、"四‱二"、"十一日后"）

## 适用场景
高端品牌、博物馆 / 文博、白酒 / 茶 / 香 / 玉、私人银行、奢侈品后台。**不适合**：开发者工具、运维监控、年轻 To-C 产品。
