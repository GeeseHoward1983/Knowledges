# 32 · 服务器机柜 / Rack-1U

> 数据中心 19" 标准机柜面板美学：1U / 2U / 8U 模块化布局 + LED 灯 + U 位编号。

## 设计立场
灵感：戴尔 / HPE / Cisco 19 英寸标准机柜面板，每个模块都有自己的 1U / 2U / 8U 高度槽位。整页核心比喻——**把控制台拆成机柜里的设备**：
- 左侧边栏顶部一张 "RACK A-01 · 42U" 标签
- 每个导航项是一个 U 位条目（U41 Dashboard / U40 Live Calls / ...）
- 主区顶部一条 42px 状态条 = 1U 模块（PDU / TEMP / FAN / PWR / STREAM / 时钟）
- 4 张 KPI 是 4 个 2U 模块（96px 高，自带 4 颗 LED 电源指示）
- 主面板 access log 是 U24-U18 7U 高
- 名册和账单分别是 U17-U12 和 U11-U08

与 16·暗黑材料、27·实验室仪表、11·黑曜数据的明确区分：
- 16 是石板灰 + 工程橙工业感**单页 UI**；
- 27 是拉丝铝外壳 + CRT 屏的实验仪**机柜**（家用感）；
- 11 是 Bloomberg 4 象限**金融终端**；
- 32 是真**机房 19" 机柜**——所有模块都有 U 位编号 / 4 颗 LED 电源指示 / inset 边框阴影 + 1px 高光。
- 状态条加了机房特有的 `TEMP / FAN / PDU / PWR` 字段，这是其他三套没有的。

## 字体
- 全页：**Roboto Mono**（数据中心 BMC / iDRAC 标准字）
- UI 标签 / 中文：Inter / PingFang SC

字号偏小（9.5 - 13px），机房面板上的字必然小且等宽。

## 布局
- 200px 边栏：顶部 RACK A-01 标签 + 8U 间分区（U41/U36/U30）+ 每条导航右侧 U 位编号
- 顶部 1U 状态条：PDU / TEMP / FAN / PWR / STREAM / 时钟，每两组间 LED
- 4 个 2U KPI 模块：每个右上 4 颗电源指示 LED + 30px 等宽大数字
- 主区两栏：左 U24-U18 ACCESS LOG（含 `port 9001 · iface eth0` 元数据）+ 右 U17-U12 MEMBERS / U11-U08 BILLING
- 名册每行带 U 位编号 + 28×28 LED 屏（暗底辉光绿/蓝/琥珀/红字）+ RW / R- 权限位
- 账单合计有蓝色描边 + 0 0 8px 蓝辉光 + 绿磷光 ¥ 数字

## 签名元素
1. **U 位编号** 贯穿全页（U41, U36, U30, U24, U17, U11 …）
2. **每个 KPI 4 颗电源 LED**（亮 OK / 黄警告 / 蓝信息 / 关）
3. **1U 状态条** 含 PDU / TEMP / FAN / PWR / kW 真实机房字段
4. **名册的 28×28 LED 屏头像** + RW / R- 权限位

## 适用场景
DCIM 数据中心管理、托管云服务商、网络设备 / 物理服务器后台、SRE 平台、机柜环境监控。**不适合**：To C / 内容平台 / 教育。
