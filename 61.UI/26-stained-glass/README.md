# 26 · 像素彩窗 / Stained-Glass

> 教堂彩绘玻璃 × 8-bit 像素美学：黑色铅条 + 高饱和马赛克色块 + Press Start 2P 像素字。

## 设计立场
灵感：哥特教堂的彩绘玻璃窗（lead came + colored panes）+ FC/NES 时代的像素 UI。整页最显眼的是顶部 **Hero 彩窗**：12 × 6 = 72 格的 Bento 网格，每格是一块独立的高饱和琉璃片（钴蓝、红宝石、翠绿、琥珀、紫水晶、玫瑰、湖青、铅黑、纸白），格与格之间是 3px 的黑色铅条缝。每块琉璃上印 KPI 数值或一句标签。

与 17·复古运算的明确区分：
- 17 是 PC-98/Win 3.1 米黄窗体 + 标题栏 + 任务栏，模拟完整桌面环境；
- 26 是**彩绘玻璃马赛克**——纯色块 + 黑缝 + 像素字，气质来自教堂彩窗而不是 90 年代电脑。
- 17 中文文案"流水实录"，26 全英文 + 部分中文，像素字与教堂窗的"圣经经文"美学呼应。

## 字体
- 显示字 / 标签 / 标题：**Press Start 2P**（标志性的 8-bit 像素字）
- 大数字 / 名字 / 正文：**VT323**（终端等宽，比 Press Start 2P 更读得快）
- 中文：DotGothic16 / Microsoft YaHei

字号偏小（8.5–10px 是常用尺寸），全等宽，硬切。

## 布局
- 240px 边栏：品牌 mark 是 4 色 conic 渐变 36px 方块 + 3px 黑边 + 3px 偏移投影
- 上方 toolbar：LIVE 5S / PROD chip + 搜索输入下划线 + ⌘K
- Hero 彩窗：12 列 × 自动行，跨格组合"本月调用 c4r2 + ▲12.4% c2 + TGT c2 + 错误率 c2 + 阈值 c2"等，每个 cell 是一块琉璃，自带 2px 黑边
- 主区两栏：左 ACCESS LOG（绿色头）/ 右 ROSTER + BILLING
- 名册头像是 4 色硬块 + 像素粗字
- 账单总计有 3px 琥珀色厚边框 + 进度条用 4 色（红/琥珀/绿/钴）8px 等宽循环条纹

## 签名元素
1. **12×6 教堂彩窗 Bento 矩阵** —— 这是其他 19 套都没有的形态：72 格不规则跨格 + 3px 黑铅条缝 + 高饱和色块
2. **进度条 = 红/琥珀/绿/钴 4 色等宽循环条**（`repeating-linear-gradient(90deg, red 0 8px, amber 8px 16px, emerald 16px 24px, cobalt 24px 32px)`）——像微型教堂窗的横向切片
3. **Press Start 2P 极小号字（8.5px）+ 1.6 行距**——只有真做过像素游戏才会这样排版

## 适用场景
游戏 / 复古 / Web3 NFT 平台 / 独立音乐 / 极客社区门面 / 二次元 SaaS。**不适合**：金融、政企、医疗——8-bit 字会被认为"不严肃"。
