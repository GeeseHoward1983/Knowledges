# 37 · 杂志 / Editorial

> Kinfolk / Apartamento / Cereal 风的杂志大留白美学：极简衬线 + 居中超大字 + 大照片 + 文章式版面。

## 设计立场
灵感：Kinfolk Magazine、Cereal Magazine、Apartamento 这类极简生活方式刊物的版面美学：**留白 > 字号**。整页核心：
- 主区 64px 大边距（极慷慨）
- 88px 居中超大字 H1 "本月运行 / 一份*简短观察*"
- "Cover Feature · 本期封面" 上下双线 kicker
- 22px italic Cormorant 引文段
- 抽象编辑摄影 SVG（大棕褐色月相 + 横向 9 条数据线 + 嵌入大数字 2,418,902）
- 引用脚注 "— 摄影 / Northwind Studio, 06.19"
- 4 列 KPI 用 54px Cormorant + Inter 极小号脚注
- 主区两栏文章：调用日志 / 名册 + 账目，每篇都有"P. 01-A" / "P. 01-B" / "P. 01-C" 子页号
- footer 上"Northwind Quarterly · Vol. XII · 06.19 · Sheet I / IX"

与 02·苔原、14·数据华尔街、19·暗色实验室、31·装饰艺术、37 的明确区分：
- 02·苔原是报刊周报感（IBM Plex 三件套）；
- 14·数据华尔街是金融日报滚动 ticker；
- 19 是学术 lab report 公式 KPI；
- 31 是装饰艺术深酒红双线对称；
- 37·杂志是**安静慷慨的生活方式刊物**——大留白、棕褐色单点缀、Cormorant + Inter 二元字体、SVG 抽象摄影、Vol/Issue/Sheet 期号脚注，气质完全不同。

## 字体
- 主显示 / H1 / KPI / 大数字：**Cormorant Garamond**（weight 400-500）
- 中文：思源宋体
- UI / 标签 / Eyebrow / 期号 / 按钮：**Inter**（极小号 + 字间距 0.22-0.42em）
- 数据 / 时间戳：JetBrains Mono

字号跨度极大（10px Inter eyebrow → 88px Cormorant H1）。

## 布局
- 200px 边栏 = 杂志目录：分区"Table of Contents" + 9 条 nav 右侧 P.01 / P.04 / P.08 ... 页码
- Hero 居中：上下双线 kicker → 88px 黑色 H1（"简短观察"用 italic + 棕褐）→ 22px italic 引文 → 署名 "文 / 林安琪 · 摄 / Northwind Studio"
- 280px 抽象编辑摄影 SVG：大棕褐色月相 + 9 条横向数据线 + 嵌入大数字
- caption "FIG. 01 / 本月调用走势 · 30 日" + 右下"30 大色块"
- 摄影脚注右对齐 italic
- 4 列 figures：每列 54px 大数字（最后一列 italic"+12.4% MoM · target 3.0M"）
- 主区双栏文章：调用日志 + 名册 / 账目，每篇都有"P. 01-A / B / C"子页号 + italic 短引子
- footer 三列 Vol/时间/Sheet

## 签名元素
1. **88px 居中 Cormorant 大字 + italic 棕褐重点**
2. **杂志期号 + 页码体系**：Vol. XII / Issue 06.19 / Sheet I / IX + 边栏 P.01-P.30
3. **抽象编辑摄影 SVG**：月相 + 9 条横向数据线 + 嵌入大字 + 右下方块
4. **每个章节有 P. 01-A / B / C 子页号**
5. **作者署名 / 摄影脚注** "— 摄影 / Northwind Studio, 06.19"
