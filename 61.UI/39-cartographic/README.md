# 39 · 古地图 / Cartographic

> 大航海时代羊皮纸航海图美学：米黄等高线 + 罗盘 + 红色航线 + 航海术语。

## 设计立场
灵感：1700s 荷兰东印度公司航海图、Ortelius 老地图册、《Treasure Island》海盗藏宝图。整页核心：
- 老地图米黄底 + 棕色等高线（radial-gradient 多层叠加模拟同心椭圆等高线）
- 每张面板是一张钉在地图上的"卡纸"，左上右下各嵌一颗 10px 棕色径向"图钉"
- 边栏顶部一颗 96px **罗盘**：双圈 + N/E/S/W 字母 + 红黑双色指北针
- Hero 是 Cartouche（古地图上的装饰文字框）："Tabula Mensis · Sheet I / IX" + 罗马字标题 + italic 引文段
- KPI 是 4 个"地标"：每张左上挂一颗罗马数字 I/II/III/IV 圆形地标钉
- 调用日志叫"航路实录"，列名 "T / Caller / **Bearing** / Flag / **τ**"，状态徽章叫旗帜 flag
- 名册叫"船员名录"，角色 Capt. / Mate / Bosun / Cabin（船长/大副/水手长/舱员）
- 账单叫"货单"，套餐叫"航线"，超量叫"超载里程"，重试叫"折返"

与 30·旅行手账、24·矿物标本的明确区分：
- 30·旅行手账是 Moleskine 牛皮 + 邮票齿孔 + 倾斜邮戳（个人旅行感）；
- 24·矿物标本是博物馆抽屉 + 拉丁文 + 矿物色块（学术分类感）；
- 39·古地图是**真的航海图**——罗盘 + 等高线 + 图钉 + 航线 + 大航海术语，气质完全不同。

## 字体
- 标题 / 章节 / KPI 标签：**Cinzel**（古罗马碑刻大写衬线）
- 数据 / 客户名 / 副标：**Cormorant Garamond** italic
- 中文：思源宋体
- 数据 / 时间戳：JetBrains Mono

## 布局
- 240px 边栏（米黄稍深）：罗盘 + 品牌 "Northwind · Cartographic · MMXXVI" + 3 段拉丁 nav 标题（Mare / Carga / Crew）+ active 项前 ⚑ 红旗
- Hero Cartouche：上下 b 行 Cinzel eyebrow + 38px Cinzel 大写 H1 + italic 副标
- 4 张 KPI 地标卡片：左上挂 22×22 罗马数字钉
- 主区两栏：航路实录 + 船员名录 + 货单
- 进度条用 135° 红/金双色斜纹
- 货单总计行 4 角金色 corner

## 签名元素
1. **96px 真罗盘**：双圈 + N/E/S/W + 红黑双色指北针 + 中心黑点
2. **等高线背景**：3 层 radial-gradient 同心椭圆 + 透明度变化模拟等高线
3. **每张卡纸的图钉**：左上右下两颗径向渐变 10px 棕钉
4. **航海术语**：Mare / Carga / Crew / Capt. / Mate / Bosun / Cabin / Bearing / Flag / 超载里程 / 折返
5. **罗马数字 I-IX** 章节编号

## 适用场景
旅行 / 航运 / 物流 / 跨境电商 / 历史 / 学术 / 出版 / 高端户外品牌 SaaS。**不适合**：消费电子 / 金融 / 科技工具。
