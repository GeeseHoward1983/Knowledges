# 08 · 黏土 / Claymorphism

> 一套柔软、立体、糖果色的"软立体（neumorphism + 黏土）"风格后台，气质亲切、零侵略性。

## 设计立场
后台不一定要扁平。把每一个面板想象成一块**轻按下去的橡皮泥**：外侧带柔光高光、底部带柔影、面板内部按钮则是从材质里**凸起**的彩色立体小块。Neumorphism（新拟态）一度被批评为可访问性差，本套用更高的对比度（深紫文字 + 浅薰衣草背景）+ 更"实"的黏土立体感修正这个缺点。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#F4ECF7` 淡薰衣草 |
| 凹底 | `#EADDF0` |
| 面板 | `#FFFFFF` |
| 主文字 | `#3D2752` 深紫 |
| 次文字 | `#7B5A99` |
| 主色 | `#A78BFA` → `#7B5BE5` 紫 |
| 桃 | `#FFB58F` → `#FF8466` |
| 薄荷 | `#A8E6CF` → `#5DCB9A` |
| 阳光 | `#FFD66B` → `#F5B43A` |
| 玫瑰 | `#FFA0B8` → `#E66789` |
| 天蓝 | `#A4D2F4` → `#5FA8DC` |

每一种点缀色都有「浅 → 深」的双值，做立体渐变。

## 字体
- 全局：**Nunito**（带温暖圆角的无衬线，weight 600 起步——黏土风格不能用细字）
- 数据：**JetBrains Mono**（仅时间戳、端点等真正需要等宽的场合）

字重整体偏粗（600 / 700 / 800），来配合"鼓鼓的"视觉体感。

## 布局
- 240px 边栏带圆角 28px 的大黏土面板
- 顶栏 H1 用 emoji（👋）+ 渐变文字混合
- KPI 4 列，每个 KPI 左上角有一颗渐变彩色"小球"图标
- 主表格行不是底色 + 分隔线，而是每一行单独一个"凹槽"圆角块（用 `border-spacing:0 6px` + 内阴影实现）
- 账单卡片底部的 Total 行做成**凸起的紫色按钮状**——视觉层级达到顶峰

## 签名元素
**双向阴影体系**：
- `.clay`（凸起）：`8px 8px 24px` 外柔影 + `-6px -6px 16px` 高光 + 内 1px 反光
- `.clay-press`（凹下）：纯内阴影
- 表格每一行用 `clay-press`，按钮用 `clay`，卡片用 `clay`——同一页面里"按下去"和"凸出来"互相区分功能。

## 适用场景
面向中小企业、教育、健康、宠物等需要"温暖 / 亲切 / 没有压力"气质的 SaaS 后台。**不适合**金融、合规、安全等需要权威感的产品，也不适合数据极度密集的场景（黏土阴影会吃掉很多空间）。
