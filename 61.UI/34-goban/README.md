# 34 · 棋谱 / Goban

> 围棋棋谱 × 棋盘格 × 黑白棋子标记。把"调用日志"翻译成"棋谱第几手"的雅致后台。

## 设计立场
灵感：日本《棋经》古谱、《吴清源 vs 木谷实》棋谱集、围棋棋盘的木纹。整页核心比喻：
- 把"控制台"翻译成棋盘 + 棋谱：
- 边栏 = 棋谱目录（卷一 / 卷二 / 卷三 = 总 / 资 / 账）
- KPI 区是一块真**棋盘格背景**（每 56px 一条墨线 + 左上、右下"星位"小黑点）
- 每张 KPI 左上角嵌一颗**黑/白/红/黑棋子**作为坐标标识（A1/B1/C1/D1）
- 调用日志变成"本谱"——每一行的左侧是棋子（黑/白交替表示先手/后手，500 异常用红子）+ "第 19 手 / 第 18 手 / ..."
- 名册叫"对座"，角色叫"先手 / 协着 / 研着 / 观谱"，头像直接是 38×38 棋子
- 账单叫"账目"，套餐叫"段位"，账单分项叫"超量手数 / Webhook 复盘"

与 10·樱与墨、25·唐风山水、22·鎏金的明确区分：
- 10 是和纸罫线 + 单点樱粉；
- 25 是远山泼墨 + 朱印；
- 22 是深松石绿 + 鎏金细线；
- 34 是**木质棋盘 + 黑白棋子 + 棋谱编号 + 朱砂错手记号**，气质是真正坐下来对弈的棋室。

## 布局
- 230px 边栏（谱纸米黄底 + 右侧虚线钉孔）：顶部"北"黑棋徽（径向渐变 + 内阴影模拟磨砂釉）+ 单字分区"总 资 账" + 每条 nav 前一颗 14×14 黑/白棋子 + 右侧罗马小写 i-ix
- 主区是谱纸米黄 + 左侧 1px 虚线"装订线"
- KPI 区是真棋盘：56px 网格 + 左上右下星位 + 4 张 KPI 浮在棋盘上方，每张左上挂一颗坐标棋子（A1/B1/C1/D1）
- 主区两栏：本谱（带"手"编号棋子 + 着点 + 状态符号 ○ ! ×）+ 对座 + 账目
- 状态符号：成功用空心 ○，限流用 !，错误用红色实心 ×
- 名册头像：黑/白/黑/白交替的真棋子（径向渐变模拟磨砂釉）

## 签名元素
1. **真棋盘格背景**：56px 网格 + 4 角星位
2. **每张 KPI 左上的坐标棋子**（A1/B1/C1/D1 字母嵌在棋子里）
3. **调用日志每行的"第几手"棋子**：黑/白交替表示先后手，红子表示"丢子" (500)
4. **对座 / 先手 / 协着 / 研着 / 观谱** 棋术词汇替代 "成员 / Owner / Admin / Dev / Read"
5. **状态符号 ○ ! ×** 而不是数字状态码

## 适用场景
围棋 / 象棋平台、博弈论 / 策略游戏、咨询顾问公司（"商场如棋"修辞）、文房四宝 / 茶道、安静的高端 B2B。**不适合**：To C 大众、运维监控。
