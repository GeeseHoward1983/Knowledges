# 16 · 暗黑材料 / Material-Dark-Pro

> 工业 / SRE / DevOps 暗色控制台风：石板灰底 + 工程橙焦点 + 厚边按钮 + 重分隔线。

## 设计立场
"暗黑模式"已经被 AI 默认套路 2 用滥。本套用两个手段拉开：
1. 底色不是 `#000`，是带蓝灰的工业石板灰 `#1A1D22`（接近 Material You 的 surface dim）
2. 焦点色不是酸绿，而是**工程橙 `#FF7A1A`**——挖掘机/塔吊/工程车的颜色，传达"我在做正经事"

并刻意把"工业感"渗透到每个细节：品牌 mark 和成员头像都是**梯形剪裁**（`clip-path:polygon`，像金属铭牌斜切边），KPI 标签前的小色块也用同样的梯形 dot；分隔线全部是 2px 实线（不是 1px），让信息组之间有"金属结构"的厚重感。

## 字体
- UI / 标题：**Roboto**（Material Design 原生字体，本套唯一合适的"工程感"无衬线）
- 数据 / 时间戳 / 标签：**Roboto Mono**

字重偏粗（700/800），KPI 数字 34px 800 weight；按钮全部大写 + 字间距 0.04em，像工业铭牌。

## 布局
- 230px 边栏，分区标题中英双语（"总览 · OVERVIEW"），左侧 active 项有 3px 橙色侧条
- 顶部一条"工业仪表盘"信息条：左侧标题 + 右侧 4 格状态（UPDATED / STREAM / P95 / UPTIME），每格之间 1px 实线
- 第二行 toolbar：搜索 + LIVE STREAM chip + 大写橙色 CTA
- KPI 4 列横排，每列前有一个梯形小色块作为"装置标识"
- 主区两栏（无圆角、无缝隙、靠 1px 实线分隔），左日志、右成员 + 账单
- 底部 footer status bar：用户 / 组织 / Token / LAT / LOAD

## 签名元素
1. **梯形 clip-path** —— 品牌 mark、成员头像、KPI 前的小色块全部是 `polygon(15% 0,100% 0,85% 100%,0 100%)` 的梯形，像金属铭牌。AI 默认套路绝对不会用 clip-path 切非矩形。
2. **账单合计是黑底橙边框**——`background:#1A1D22;border:2px solid var(--orange)`，看起来像被铆在面板上的"金属铭牌"。
3. **进度条上的 45° 阴影斜纹**——`repeating-linear-gradient(135deg,transparent 0 6px,rgba(0,0,0,.15) 6px 9px)`，工业警示带的感觉。

## 适用场景
SRE 控制台、IoT 网关、工业 SaaS、运维监控、矿机算力管理、能源/制造数据中台。**不适合**：面向 C 端 / 非技术用户，气质太工程师，会有距离感。
