# 07 · 终端 / Terminal-CRT

> 一套面向「开发者 / 平台运维 / 极客客户」的复古终端风格后台，整页就是一台 CRT 显示器。

## 设计立场
把控制台直接做成 `tail -f` 的实时终端：磷光绿底、扫描线、闪烁光标、`$ nwctl dashboard --watch` 命令行开场。所有"卡片"都是带标题的 ASCII 盒子；KPI 名变成 `calls.month` `error.rate.24h` 这种点分键；账单是 `df` 风格的等宽对齐表。

为什么不是 AI 默认套路 2（近黑+酸绿）？
- 那个套路里的"酸绿"是 #00FF88 这种**色彩学意义的纯绿**，给"卡片标题色"用。本套绿是 `#7EE787`（GitHub 暗主题里的绿）和 `#B5FFC0`（高亮），且只用在**等宽字本身**上，背景是带饱和的暗绿黑而不是 #000。
- 整页**全屏全等宽字**，没有任何无衬线 UI 字。这才是真正的终端美学，而 AI 默认的"近黑+酸绿"通常仍然用 Inter 做大字。
- 增加了 CRT 扫描线、光晕、`text-shadow` 磷光效果，是真复古而不是装饰复古。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#0A0F0A` 暗绿黑 |
| 面板底 | `rgba(15,26,15,.55)` |
| 主磷光色 | `#7EE787` |
| 高亮 | `#B5FFC0` |
| 暗淡 | `#3A8A4A` |
| 警告（限流） | `#FFB454` 琥珀 |
| 错误（500） | `#FF6B7E` 警示粉 |

`text-shadow:0 0 1px rgba(126,231,135,.4)` 给所有字加了一层极弱光晕，模拟磷光衰减。

## 字体
**全屏只有等宽字**：JetBrains Mono / Cascadia Code / Source Code Pro 任一。没有任何衬线、无衬线 UI 字混入。

字号 13px，行高 1.55，刻意接近 iTerm 的默认手感。

## 布局
- 左侧 240px 的"命令树"：分 overview/resources/account/danger 几个区，每条命令带编号或快捷键
- 顶部细 status-bar：用户、组织、环境、时间 + 闪烁 `LIVE` 光标
- 然后是模拟的命令提示符面板（$ nwctl dashboard …）
- KPI 是 4 个标题嵌在边框上的 ASCII 盒子
- 主面板是 `tail -f` 风格的实时日志窗，带"红黄绿"窗口控制点
- 双栏：`nwctl members ls`（ps 输出感）+ `nwctl billing show`（`<pre>` 等宽对齐 + ASCII 进度条）
- 底部 footer：`? / n r q` 单字符快捷键提示，右侧 `load average` `uptime`

## 签名元素
1. **闪烁的 `LIVE` 光标**（`@keyframes blink`）
2. **`<pre>` 块里的 ASCII 进度条**（`██████████████▌▒▒▒▒▒  72%`）——账单卡片不画图，画 ASCII

## 适用场景
开发者平台（云原生 / 数据库 / CI / 监控）的"高级控制台"，或给极客用户的"高级模式"toggle。**不适合**：B 端非技术用户，看了会困惑甚至害怕；也不适合 To-C 用户。
