# 38 · 化学元素 / Periodic

> 元素周期表美学：每个 KPI 是一颗"元素方块"，符号 + 序号 + 原子量 + 中文名 + 类别色边框。

## 设计立场
灵感：门捷列夫元素周期表、Aatish Bhatia 等设计师做的"互动周期表" + Material Design For Data 的色块系统。整页核心比喻：
- 把每个指标当作一颗化学元素
  - **Vol 01** = 本月调用量 / 碱金属青（族 1A）
  - **Cr 02** = 名册 / 过渡金属绿
  - **Er 03** = 错误率 / 类金属琥珀
  - **Bl 04** = 账单 / 惰性气紫
  - **Lg 05** = 调用日志 (Log)
  - **Mb 06** = 名册 (Members)
  - **Bl 07** = 账单 (Bill)
- 边栏品牌也是一颗大元素方块 `Nw / Northwind / 2.18.0`
- 每条 nav 前是一颗小元素方块（Db / Tc / Rg / Ky / Wh / Ex / Mb / Bl / Cf），每颗用所在族的颜色描边
- 整页顶部有真正的 **legend 图例**（Volume / Crew / Error / Billing / Latency / Critical 六族色）
- 状态码用 `iso 同位素` 命名，耗时叫 τ（tau, 化学半衰期符号）

与其他暗色方案的明确区分：
- 11·黑曜数据是 Bloomberg 金融琥珀；
- 16·暗黑材料是工程橙石板灰；
- 19·暗色实验室是 italic 衬线学术；
- 36·全息 HUD 是单色青多边形剪裁；
- 38·周期表是**6 色族系分类 + 元素方块栅格**，所有彩色都有"族"意义，不是装饰。

## 字体
- 元素符号 / 大标题：**IBM Plex Sans** 700（化学元素的标准 Sans 显示字）
- 数据 / 序号 / 原子量 / 时间戳：Roboto Mono / IBM Plex Mono
- 中文：PingFang SC

## 布局
- 220px 边栏：顶部 96×96 大元素方块"Nw / Northwind / 2.18.0"（左上序号 01 + 中央 38px 符号 + 中部 9px 大写名 + 底部原子量）
- 3 段 nav（Overview · 1A / Resource · 2A / Account · 3A）+ 每条 nav 前 28×28 元素方块
- 顶部 legend 图例横条：6 色族边框小方块 + 时间戳
- 4 张 KPI 是 4 颗大元素方块（每张：左上序号 + 右上原子量 delta + 中央 44px 大符号 + 中部 11px 大写名 + 18px 数值 + 12px 注脚）
- 主区两栏：log / members + bill，每张面板标题前一颗序号 + 2 字符元素符号（Lg 05 / Mb 06 / Bl 07）
- 名册头像是 40×40 小元素方块：左上序号 + 中央汉字符号 + 4 种族色
- 状态码徽章是 32×24 矩形 + 1.5px 族色描边
- 进度条是**4 色族色循环条纹**（青/绿/琥珀/紫四等分）

## 签名元素
1. **元素方块**贯穿整页：品牌、KPI、头像、nav 图标都是 element box
2. **6 色族系图例**：legend 横条明确告诉用户"哪个颜色代表什么族"
3. **化学符号命名**：Vol / Cr / Er / Bl / Lg / Mb / Db / Tc / Rg / Ky / Wh / Ex / Cf —— 全部都是 2 字符（符合元素周期表规则）
4. **τ (tau) 耗时** + **iso 同位素**状态 + **Σ Total** 求和符 —— 全数学/化学符号
5. **进度条 = 4 族色循环条**

## 适用场景
化工 / 医药研发 / 生命科学 / 学术机构 / 教育（化学/物理/生物）/ 实验室管理 SaaS。**不适合**：消费品 / 文创 / 时尚类。
