# 04 · 子夜霓虹 / Midnight-Neon

> 一套面向「需要让客户觉得这是一款 hot 产品」的赛博/夜店感后台风格。

## 设计立场
深夜东京街头被霓虹灯打湿的玻璃。深紫黑底，所有"信号"——状态徽章、KPI 数字、按钮、头像环、品牌徽标——都靠双色（紫红 → 青绿）霓虹辉光说话。但用克制：辉光只给真正需要被读到的东西，正文和表格本身仍然安静、可读。

绕开 AI 默认套路 2（近黑 + 单色酸绿）的方式：1）底色不是死黑，是带饱和度的子夜紫 `#0B0820`；2）点缀不是单色，是紫红/紫/青三色霓虹梯度；3）大数字用渐变文字而不是单色。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#0B0820` 子夜紫黑 |
| 面板 | `#1A1438` → `#231A4A` |
| 主文字 | `#EDE9FF` |
| 次文字 | `#9A8FD8` |
| 霓虹 1（焦点） | `#FF4FD8` 紫红 |
| 霓虹 2（次焦点） | `#7B5BFF` 紫 |
| 霓虹 3（数据） | `#36E2FF` 青 |
| 成功 / 警告 / 错误 | `#36FFC4` / `#FFB95C` / `#FF6B8A` |

主背景还叠了三层径向渐变（左上紫红、右上青、底部紫），模拟霓虹光晕。

## 字体
- 显示字 / 大数字 / 标题：**Space Grotesk**（几何无衬线、棱角分明，适合发光）
- 正文 / UI：**Sora**
- 数据 / 时间戳：**JetBrains Mono**

显示字本身不加 weight；视觉重量靠渐变 + box-shadow 给出。

## 布局
- 236px 边栏带玻璃毛感（backdrop-filter blur）
- Hero 左侧大数字 + 渐变 sparkline，右侧两块 KPI 纵向堆
- 调用日志、成员、账单都是同款"霓虹边框"卡片：用 `mask-composite` 在 1px 描边里放渐变

## 签名元素
**双重霓虹辉光的渐变描边**。每个 hero-card 的边框是用 mask-composite 切出来的 1px 渐变细线（紫红→青），里面的发光只在 hover/active 状态加深；同时大数字用 `-webkit-background-clip:text` 实现渐变文字，sparkline 用 `drop-shadow` 给一层柔光。

## 适用场景
面向开发者、游戏、Web3、电商出海、AIGC 这类气质偏年轻、想表达"我们是前沿玩家"的产品。**不适合**金融、医疗、政企客户——会显得不够稳重。
