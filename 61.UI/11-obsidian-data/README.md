# 11 · 黑曜数据 / Obsidian-Data

> 一套面向「看一整天的数据狗」的 Bloomberg / 交易终端风高密度后台。

## 设计立场
不向"亲切感"妥协。整页是一个 4 象限的工作台：左上 KPI 矩阵、右上调用日志、左下成员订单簿、右下账单 + 7×24 调用热力图。配色是深石黑底 + Bloomberg 琥珀点缀（`#E8A547`），不是 AI 默认套路 2 那种"近黑+酸绿"。所有数字都开启 `tabular-nums` 严格对齐，所有字号都偏小（11px 12px），保证一屏装得下尽量多的信号。

## 字体
- UI：**IBM Plex Sans**
- 数据 / 所有表格 / 状态码 / 时间：**JetBrains Mono**

所有 KPI 数字、价格、ms、% 全是等宽字 + tabular-nums。这是交易终端的精髓——眼睛沿着数字列扫描时不能跳。

## 布局
- 左侧 200px 边栏：F 键功能列表（F1–F12）+ DANGER 红色分区
- 顶部 toolbar：组织 / 环境 / 区域 + 实时流状态 + 服务器时间
- ticker 横条：滚动式关键指标条（CALLS.M / CALLS.D / ERR.24H / P95.LAT / QPS.NOW / ...）
- 主区 4 象限：
  - **PANE 1** KPI 4×2 矩阵，每个 cell 含小型 sparkbar
  - **PANE 2** 调用日志，每行右侧附带 3 像素的微型条形图（耗时三段的近期趋势）
  - **PANE 3** 成员"订单簿"风格表格
  - **PANE 4** 账单（左）+ 7×24 调用热力图（右）
- 底部状态栏：用户 / Token / TTL / Stream OK / 服务器 load average / uptime

## 签名元素
1. **表格行内的 3 像素微型条形图**（`.micro-bar`）——AI 默认套路里没人这么做，因为它要求 CSS 里嵌一个 `display:inline-flex` 的小柱状图。
2. **底部 7×24 = 168 格的调用热力图**——直接用 168 个 `<i>` div 拼出，颜色梯度走"暗石黑 → 暗黄 → 琥珀 → 浅金，仅极端时段出现红"。

## 适用场景
24/7 监控、运维、SRE、量化交易、金融风控、API 平台等数据狗每天盯着不下屏的场景。**绝对不适合**：偶尔登录一次的轻量管理员；不熟悉数据术语的用户（信息密度太高会劝退）。
