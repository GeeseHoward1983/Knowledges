# 01 · 极地玻璃 / Polar-Glass

> 一套面向「需要让客户觉得后台轻、透、有呼吸感」的现代 SaaS 控制台风格。

## 设计立场
拒绝把"管理后台 = 灰白工业感"。把页面想象成一块漂浮在极地天空上的薄冰：背景是冷蓝到淡粉的渐变天光，所有面板都是磨砂玻璃浮在上面，靠模糊和细微的内高光来区分层次，而不是靠粗黑的边和阴影。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景渐变 | `#A9C7E8 → #D6E3F2 → #F2E4F0` |
| 玻璃面板填充 | `rgba(255,255,255,.55)` + 22px 模糊 |
| 主文字 | `#0B1726`（近黑靛） |
| 次文字 | `#4A6182` |
| 主色（动作） | `#3D7BFF`（极地蓝） |
| 高光辅色 | `#7EC8FF` |
| 成功 / 警告 / 错误 | `#3BD49F` / `#FF8A3D` / `#FF5E7E` |

整张页面没有一处用到纯黑、纯灰；分隔线全部走 `rgba(255,255,255,.45)` 的高光线和 `rgba(11,23,38,.08)` 的极淡虚线。

## 字体
- 显示字 / 大数字：**Fraunces**（现代过渡衬线，带轻微光学切割，用来把指标值变成"被展示的展品"而不是冷冰冰的数据）
- 正文 / UI：**Inter**
- 数据列（端点、时间戳）：**JetBrains Mono**

显示字只在指标数值、账单金额这类"被瞻仰的数字"上出现，其它地方一律 Inter，避免到处衬线变成 AI 默认套路。

## 布局
- 12 栏隐形网格，外圈 16px 留白，玻璃面板之间 18px 缝隙
- 左侧 240px 玻璃边栏，主区右上 Hero + KPI 双区，下面整行调用日志，再下面成员 + 账单双栏
- 信息密度中等：让玻璃和留白说话，表格采用 1 像素虚线分隔行

## 签名元素
**磨砂玻璃 + 极轻噪点**。整页底层有一个 SVG fractalNoise 噪点层（opacity 0.6），让所有玻璃面板下面都有一种"印刷颗粒"的实物感，避免纯渐变带来的 AI 默认感。

## 适用场景
面向终端客户的开发者后台（API 调用监控、计费、Webhook 调试），公司气质偏现代、年轻、北欧/极简感的产品。不适合工业控制、运维监控、安全合规这种需要"重"的场景。
