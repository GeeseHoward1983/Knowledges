# 19 · 暗色实验室 / Lab-Mono

> 一套学术论文 / 实验室报告气质的暗色后台：意大利体衬线 + 公式化 KPI + 摘要文风。

## 设计立场
把控制台**装订成一份本期的实验室工作报告（Lab Report）**。整页围绕「学术写作」的视觉语言：
- 顶部不是"Hello"，是 `Working Report · Sheet 01 · 2026 / 06 / 19` 的 Eyebrow
- H1 是斜体衬线 + 小型版本号脚注 `<sub>v 2.18</sub>`
- 紧跟一段 **Abstract** 摘要（"摘要 · Abstract." 标记前置）
- KPI 不是卡片，是 4 个**公式**：`N = 2.42M`、`m / M = 38/50`、`ε = 0.42%`（错误率）、`B = ¥ 2,879.50`（账单）
- 章节标题前缀 `§`（论文章节符号）
- 账单"用量"展开成真正的 `ρ = N / N_max = 2,418,902 / 3,000,000` 分式
- 底部一个学术引用样的 `Cite as:`

气质和 04·子夜霓虹、11·黑曜数据、16·暗黑材料完全错开——同样是暗色，但本套是**安静的、智识的、reading-room 感**，不是工作中的，不是夜店感。

## 字体
- 主显示 / H1 / 大数字 / 名字 / 公式：**EB Garamond**（学术老衬线，italic 大量使用）
- 中文兜底：STSong / 思源宋体
- 数据 / 时间戳 / 标签 / 数字脚标：**JetBrains Mono**
- Eyebrow / 角色标签 / "Abstract" 字头：**Inter**

衬线占 60%、等宽占 30%、无衬线只占 10%。其中**EB Garamond 的 italic** 是核心——侧栏导航项、调用方名称、章节小标题都用 italic，让整页读起来像翻论文。

## 布局
- 230px 边栏，分区 `Overview / Resources / Account / Appendix` 四级；每条 nav 都用 italic 衬线 + 右侧 `§ n` 编号
- 顶 Header：左侧 H1 ("关于本月运行情况的一份*简短观察*") + 右侧元数据栏，最下面有一行手写体签名 `— L. A. 林安琪 谨记`
- Abstract 段：单栏，最大宽 780px（论文常规版心宽度），段内嵌等宽 `ε = 0.42%` 这种公式
- 4 个 Equation 卡：每张左右两道"书页装订竖线"，里面是公式
- 主区两栏：调用流水（带变量字头 `t / endpoint / Δt`）+ 名册 + 账目
- 账单底部嵌一个**真正的分数 ρ = N / N_max**（用嵌套 `.frac` 的 `top` `bot` 分子分母布局）
- 最末是 `Cite as:` 引用脚注

## 签名元素
1. **公式化 KPI**——每个指标都有一个变量名（N / m / ε / B），不是"本月调用量"这种白话
2. **底部那个真分式 ρ = N / N_max = 2,418,902 / 3,000,000**——用纯 HTML/CSS 写出一个数学分式，是其他 19 套都不会有的细节
3. **章节符号 § + 论文 Sheet 编号 + 引用脚注**——学术文献体的视觉骨架

## 适用场景
科研 / 高等教育 / 临床数据 / 行业研究 / 投研报告 / 法律案例库等。也适合做 PhD 创办的 SaaS 产品后台（生物信息、量化、AI 平台）。**不适合**：to C、营销、电商等需要"热度"的场景。
