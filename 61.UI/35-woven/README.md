# 35 · 编织 / Woven

> 北欧布艺 / 织物纹理 + 暖色块 + 抒情衬线 + 圆角胶囊。

## 设计立场
灵感：北欧设计杂志 Kinfolk 的封面、Marimekko 的纺织印花、Pendleton 印第安羊毛毯。整页核心比喻：把"控制台"翻译成"织造工坊（Atelier）"——
- 行数 = 调用量（本月织出 240 万行布幅）
- 织工 = 成员（织长 / 组长 / 工匠 / 学徒）
- 织线日志 = 调用日志（纹样 = 端点，打结 = 错误）
- 单据 = 发票，套餐 = 行数包，重织 = retry

底层有非常细腻的经纬交织条纹（双向 2px on / 4px off 的细线），每张面板上面又叠一层细 1px 经纬线（4px 周期），制造真正的"亚麻布面"质感。

与 12·沙丘、08·黏土、15·韩系明亮、28·折纸的明确区分：
- 12 是暖沙漠 + 鹅卵石图标 + 沙丘剪影；
- 08 是双向阴影 + 糖果色立体；
- 15 是大圆角 + 友好 SVG + 韩系蓝；
- 28 是折角硬投影；
- 35 是**真正的纺织纹理**（双层 repeating-linear-gradient 经纬线 + SVG 织物挂毯 + 织线条纹进度条 + 编织头像）。

## 字体
- 显示字 / H1 / 大数字 / 名字：**Spectral**（现代衬线，weight 500，有抒情人文味）
- 中文：思源宋体
- UI / 标签 / 按钮：**Outfit**（带轻微圆角的几何无衬线）
- 数据：JetBrains Mono

## 布局
- 240px 边栏（亚麻面板）：品牌 mark 是斜 45° 织线条纹 + 中央米黄方块写 "N"，分区标题右接 1px 织线分隔
- 顶部 toolbar 是织物面板：H1 "下午好，林安琪 — *这周织得不错*" + 副标
- Hero 两栏：左侧抒情段落（"已织出 *240 万行* 布幅"）+ 右侧 **4×4 SVG 真织物挂毯**（4 种 pattern 棋盘交错 + 底部流苏线）
- KPI 4 张织片：每张顶部 6px 双色织线饰边（4 种不同组合）+ 左上方色块图标
- 主区两栏：织线日志（表头"时来者纹样状耗"）+ 织工名册（圆形编织头像 = 45° 双色斜纹）+ 本月成本
- 账单合计是**赤陶大色块 + 长投影**

## 签名元素
1. **经纬交织底纹**：body 是 4px 周期的双向 2px 细线；每张面板再叠一层 4px 周期 1px 细线 —— 双层经纬制造真亚麻感
2. **4×4 SVG 织物挂毯**：4 种 pattern（赤陶/橄榄/莓红/天蓝），每 pattern 用 45° 旋转的斜纹 + 流苏底
3. **编织头像** = 45° 重复双色斜纹（terracotta + rust / olive + lightolive ...）
4. **进度条 = 织线条纹**（90° 6px 三色 repeating-linear-gradient）
5. **职业称谓"织长 / 组长 / 工匠 / 学徒"** + "纹样" / "打结" / "重织" / "招新工"

## 适用场景
家居 / 软装 / 服饰 / 手作品牌 / 设计工作室 / 文创工坊 / 民宿 / 茶饮 / 独立咖啡 SaaS。**不适合**：技术工具、运维、金融。
