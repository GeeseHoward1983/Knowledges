# 14 · 数据华尔街 / Tickertape

> 一份金融日报式后台：顶部"报头"+ 滚动股票条 + 头版头条 + 报纸两栏排版。

## 设计立场
把控制台**装订成一份本期的金融日报**。开页是一个"Northwind Daily"报头 + 黑色横向滚动 ticker 条（一直滚动），下面是"头版头条"——大字标题 + 双栏正文 + 旁边一个 68px 大数字。指标行模拟金融指数；调用日志的状态码用绿/金/红的金融 +/- 配色。

避开 AI 默认套路 3（报纸排版）的方式：
- 套路 3 是"奶油白纸感 + 衬线 + 整页报纸感"，目的是装作"文化人"
- 本套是**金融日报的报纸感**：底色是带点黄的米麻底 (`#F4F0E6`)，主色靛蓝 `#15203E` 而不是棕墨，点缀金 `#A88728` + 涨绿 `#1E7A4F` + 跌红 `#B83838`
- 加了一个**真在滚动的 ticker 条**——AI 默认套路 3 不会动
- 信息密度上**比套路 3 高很多**——指数 4 列 + 日志 8 行 + 名册 4 人 + 账单全展开，是真在工作不是装文化

## 字体
- 报头 / 大标题 / 大数字：**Playfair Display**（字怀庄重的现代衬线）
- 正文段落：**Source Serif Pro / 思源宋体**（更适合长文段）
- UI / 标签 / 按钮：**Inter**
- 数据：**JetBrains Mono**

四套字体角色严格分工：Playfair 唱头牌 / Source Serif 写正文 / Inter 干 UI 活 / Mono 排数据。

## 布局
- 顶部 3 列 masthead：左 VOL/UTC，中 报名（Playfair 34px），右 日期天气
- ticker 全宽滚动（50s 一圈，CSS 动画无缝循环）
- 200px 边栏：栏目分区上下各一道实线包夹，模仿报纸目录
- Hero 头条：左 H2 + 双栏正文（`column-count:2`），右一个大数字栏被一根细线分开
- "指数行" 4 列 KPI，列间细线分隔
- 主区两栏：左日志（占 1.55fr），右"名册 + 本期账目"

## 签名元素
1. **真在滚动的 ticker**——`@keyframes scroll` 50 秒循环一次，所有指标横向流过
2. **Lede 段落 `column-count:2`**——这是报纸排版的灵魂，让那段叙述真的像头版文章
3. **顶部"Northwind *Daily*"报头**——Daily 用 Playfair italic 撇出来一点装饰，配 EST. 2022 副标，整页就有了"刊物"身份

## 适用场景
金融、咨询、投研、宏观分析、PE/VC、广告投放复盘等"每日一份"型的后台，或者任何想让自己的控制台**看上去像产业内参刊物**的场景。**不适合**：纯运维 / 操作密集场景——读报感会拖慢操作。
