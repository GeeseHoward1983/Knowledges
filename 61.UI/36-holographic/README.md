# 36 · 全息 HUD / Holographic

> 钢铁侠 / F-35 战机平视显示器（HUD）美学：全黑底 + 单色青 + 多边形剪裁描边 + 雷达圆盘。

## 设计立场
灵感：Tony Stark JARVIS 工作台、F-35 闪电 II 头盔 HUD、Cyberpunk 2077 黑客界面、特种部队夜视镜 UI。整页核心视觉语言：
- 几乎全黑底色，唯一色彩 = **单一冷青 #5EE9FF**（+ 警示琥珀 + 错误红）
- 每个面板都用 `clip-path:polygon` 切出多边形八角边缘（左上右上左下右下各切 12px）
- 每个面板四个角再贴 4 个 1.5px 青色 L 形角钉
- 大量 `text-shadow:0 0 8px rgba(94,233,255,.5)` 让所有青字"发光"
- Hero 是一个真正的**雷达圆盘 SVG**：同心圆 + 十字准星 + 进度环 + 雷达扫描指针（127° 旋转）+ NESW 四向刻度 + 几颗数据点 + 中心写 QUOTA 72% / 2.42 / 3.0 M

与 04·子夜霓虹、20·渐变流光、29·蒸汽波、33·太空舱的明确区分：
- 04 用紫红/紫/青多色霓虹辉光；
- 20 用 4 团流动彩 blob；
- 29 用 80s 落日 + 透视网格；
- 33 用胶囊圆角 HUD 青；
- 36 是**只有黑和青**的极简全息 HUD，没有渐变球、没有圆角、没有彩色——所有视觉都靠**多边形 clip-path + 单色辉光 + L 形角钉 + 雷达图**。

## 字体
- 显示字 / 标题 / KPI / 大数字：**Rajdhani**（窄体几何无衬线，HUD 标准字）
- 数据 / 标签 / 时间戳 / 表格：JetBrains Mono
- 中文：PingFang SC

字号偏小（11.5 - 28px），字间距偏大（0.22 - 0.32em）。

## 布局
- 230px 左侧多边形剪裁边栏（八角边缘 + 4 角 L 形角钉）
- 品牌徽：60×60 conic gradient + mask 切环 + 内圈嵌"N"
- 顶部 status bar：USR / ENV / RGN / UPLINK 等左 + P95 / UPTIME / 时钟右，每段前一颗 45° 旋转的小菱形 LED
- 主区两栏：左侧 radar block（雷达 + 7 行数据 + 4 个 KPI 横排）+ 右侧 SCAN LOG / CREW ROSTER / BILLING 堆叠
- 头像是六边形 hexagon `clip-path:polygon(50% 0,100% 25%,100% 75%,50% 100%,0 75%,0 25%)`
- 进度条本身也是切角六边形 `clip-path` 处理

## 签名元素
1. **真雷达 SVG**：220×220 同心圆 4 层 + 十字准星 + 进度环 + 127° 雷达扫描指针 + NESW 字母标注 + 5 颗数据光点
2. **多边形八角面板** `clip-path:polygon(12px 0, calc(100% - 12px) 0, 100% 12px, ...)`，每个面板四角贴 4 个 1.5px 青色 L 形角钉
3. **整页只有 1 种主色（青）**：所有 KPI 数字、徽章、边框、按钮、辉光都是 `#5EE9FF`，黄红只在警告/错误状态出现
4. **菱形 LED 角标**：每段 status 前一颗 45° 旋转的 6×6 青色菱形 + 6px 同色辉光

## 适用场景
军工 / 网安 / 智能驾驶 / 无人机 / 机器人 / 战术分析平台 / 极客向工具的 Pro 模式。**绝对不适合**：日常 To C、消费品、温情场景。
