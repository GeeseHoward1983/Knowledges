# 03 · 蓝图 / Blueprint

> 一套面向「需要让客户感受到工程严谨」的工程蓝图风格后台。

## 设计立场
把控制台当作建筑师/机械工程师的图纸：深蓝底纸 + 等距网格 + 标注尺寸线 + 标题栏（Title Block）+ 引线（Leader Line）。所有 KPI 卡片像被钉在图纸上的视图，四角的"图钉"小圆点是签名细节。

绕开 AI 默认套路 2（近黑 + 单色霓虹绿）的方式：底色是带饱和度的蓝图蓝（`#0F3251`）而不是死黑；点缀色用冷感的青绿 `#7BD5E0`，不是酸绿/赤焰。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#0F3251` 蓝图蓝 |
| 面板底 | `rgba(15,50,81,.45)` 半透叠在网格上 |
| 网格细线 | `rgba(230,239,247,.06)` 每 24px |
| 网格主线 | `rgba(230,239,247,.14)` 每 120px |
| 主文字 | `#E6EFF7` |
| 次文字 | `#94B6D3` |
| 主点缀 | `#7BD5E0` 工程青 |
| 警告 | `#F3C56B` 信号黄 |
| 错误 | `#F08AA1` 警示粉 |

## 字体
- 显示字 / KPI 大数字 / 标题：**Space Grotesk**（有工程感的几何无衬线）
- 数据 / 时间戳 / 编号 / 标注：**JetBrains Mono**

没有衬线字体。所有"标注"信息（坐标、量纲、单位）都跑等宽字。

## 布局
- 240px 边栏，主区由"图纸标题栏（Title Block）"开始：左是 H1，右是 SHEET / REGION / UPDATED / SCALE 四联信息（模仿真实工程图的标题栏）
- KPI 区上方有一条横贯的「· 关键指标 / 24h ·」尺寸引线
- 每张 KPI 四角带小圆点（图钉/铆钉感）
- 调用日志和详情区都是同款图纸感面板

## 签名元素
**两个：1）页面 H1 上下的尺寸引线（虚线 + 中心文字），2）每张 KPI 四角的青色铆钉**。整页所有装饰都来自"图纸语言"——没有彩色渐变、没有玻璃模糊、没有圆角。圆角全部为 0。

## 适用场景
工程、制造、能源、运维、IoT 这类需要传递"严谨/精密/可信"气质的后台。也适合做开发者文档站的控制台延伸。**不适合**面向消费者的轻量 SaaS——会过于硬。
