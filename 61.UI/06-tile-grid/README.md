# 06 · 立方瓷砖 / Tile-Grid

> 一套 Bento Box / 不规则瓷砖网格的后台，整页是一面色彩瓷砖墙。

## 设计立场
后台不一定要"严肃 / 高密度 / 单色调"。把仪表盘当作一面小瓷砖拼贴墙：每一块瓷砖一个颜色、一个圆角、一个信息单元。客户一眼能扫到："今天怎么样、调用多少、谁活跃、账单多少"。Bento 风格近两年很热，但本套刻意用：
- 一块**深黑瓷砖**做主标题（暖色瓷砖之间的视觉锚点）
- 一块**白色调用日志瓷砖**承担信息密度
- 其余暖色瓷砖只携带 1 个数据 + 1 个动作

避开同类 Bento 设计常见的"每块都填满信息"的庸俗版，保留呼吸感。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#F2EEE8` 暖灰 |
| 瓷砖白 | `#FFFFFF` |
| 瓷砖黑 | `#1A1A1A` / `#2A2A2A` |
| 珊瑚瓷砖 | `#FFB59E` / 深 `#FF7A5C` |
| 薄荷瓷砖 | `#B6E0C2` / 深 `#7CC899` |
| 天蓝瓷砖 | `#B4D6F2` / 深 `#5C9BD8` |
| 奶油瓷砖 | `#FFE08A` / 深 `#F2B23A` |
| 紫罗兰瓷砖 | `#D6BFE8` / 深 `#9D6BC6` |
| 玫瑰瓷砖 | `#F5C7D5` / 深 `#E0668A` |

7 种瓷砖色，但同时只有 5–6 块上画面，互相之间用大圆角和留白分开。

## 字体
- 显示字 / KPI / 标题：**DM Sans**（带轻微人文感的几何无衬线，字重跨度大）
- 数据 / 时间戳：**JetBrains Mono**

整页一种字体家族，靠 weight 区分层级（500/600/700）。瓷砖标题 `text-transform: uppercase` + 字间距 0.04em，让色块上的字也有秩序感。

## 布局
- 6 列 × 自动行高 = 16px 缝隙的 Bento 网格
- 大瓷砖：调用数（2×2）、日志表（4×3）、通讯录（2×3）、账单详情（6×2）
- 小瓷砖：成员、错误率、账单、配额 1×1 或 2×1

每块瓷砖右上角统一一个圆形 → 箭头，暗示"可点进去"。

## 签名元素
**整页第一行那块横贯的深黑标题瓷砖**：里面是一句完整的、口语化的句子——"这个月看起来不错——调用量稳步走高，错误率仍在阈值内，账单 ¥2,879.50，距月末还有 11 天。"。色彩瓷砖墙的视觉锚点就是它。其他 19 套都没有这种「以一句完整人话开场」的设计。

## 适用场景
面向中小企业主、市场 / 运营 / 客服等非技术角色的 SaaS 后台。气质轻松、亲切、扫一眼就能完成日常巡检。**不适合**：需要持续盯盘的高密度场景（瓷砖之间的缝隙会浪费屏幕）。
