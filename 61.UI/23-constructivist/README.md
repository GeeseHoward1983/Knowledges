# 23 · 苏维埃构成 / Constructivist

> 1920s 苏维埃构成主义海报美学：红、黑、黄三色 + 倾斜几何块 + 极重无衬线大字。

## 设计立场
灵感：El Lissitzky、Rodchenko 的宣传海报、AIGA 现代复刻的构成主义。整页基于**严格的红/黑/黄三色 + 牛皮纸底** + **倾斜几何块装饰**（右上角一个 280px 红色方块倾 15° + 黑色重投影；底部一个 130px 红色 45° 方块）+ **极重无衬线字**（Archivo Black 900）+ **凯旋柱式标语**（footer `FORWARD! 数据归你所有。`）。

与 09·瑞士格的区分：
- 09 严格瑞士格是**白底 + 黑字 + 单一红**，圆角 = 0，纪律到极致；
- 23 是**牛皮纸底 + 红黑黄三色** + 倾斜元素 + 海报感大字 + 字号跨度更夸张（28px → 72px）；
- 23 用了**Bebas Neue + Archivo Black** 两支海报字，瑞士格只用 Inter。

与 14·数据华尔街的区分：
- 14 是报纸版式衬线 + 双栏正文；
- 23 是宣传海报无衬线 + 大色块 + 投影方块。

## 配色
| 角色 | 取值 |
| --- | --- |
| 主背景 | `#F1ECDB` 牛皮纸 + 噪点 |
| 次纸 | `#E5DDC5` |
| **主红** | `#D63125` 苏维埃红 |
| 深红 | `#8E1F1A` |
| **主黑** | `#0A0A0A` / `#181818` |
| **主黄** | `#F2C82F` |
| 次文字 | `#5A5A5A` |

三色严格限定。除了状态徽章 / KPI 块，所有色都从这三色里出。

## 字体
- 显示字 / KPI 大数字 / H1：**Archivo Black** + **Source Han Sans SC**（中文加粗）
- UI 短文本 / 工具栏 / 时间戳：**Bebas Neue**（细长条状大写无衬线）
- 数据：JetBrains Mono

字号跨度大（11px Bebas → 72px Archivo Black H1）。表头 Bebas + 大字间距 0.22em，是宣传画的标准字法。

## 布局
- 230px 黑底边栏：分区标题是**红色色块上印黄字**（"总览" / "资源" / "账户"）
- Hero banner 是**白纸底 + 极重大字 H1**：`本月调用 已突破 240 万 次`，"240 万" 用黄字 + 黑底盖章
- Hero 左下/右上有真 absolute 几何装饰（红方块、黑短杠）
- 工具栏是**黑底 + 红黄方块 + Bebas 等距大写**
- KPI 4 列硬切——**白 / 红 / 黄 / 黑** 4 个色块逐次出现，48px Archivo Black 大数字，每块右上角一个方块 → 箭头
- 主区两栏靠 5px 黑色实线分隔，从主色到背景再到分隔都是同款厚度
- 名册头像是**红/黑/黄/白 4 色方块**（不是圆形！），里面塞 24px Archivo Black 的姓字
- 账单 Total 行**整块红色 + 反白**
- footer 黑色横条 + 黄色 slogan + 数据中心元信息

## 签名元素
1. **背景右上角倾 15° 的红色大方块 + 8px 黑色平面投影**（无 blur，像版画的实体阴影）
2. **进度条**用 135° 红黑斜纹（`repeating-linear-gradient(135deg,red 0 8px, black 8px 16px)`）——是宣传画里"工业"的具象
3. **footer 标语 `FORWARD! 数据归你所有。`** —— 致敬当年的口号体
4. **5px 黑实线分隔**——每个面板边界都是 5px，强结构感

## 适用场景
新闻 / 政务 / 政论平台、活动 / 演出 / 票务、出版、独立媒体的后台，或者任何想要**强烈视觉发声**的产品。**不适合**：金融 / 医疗 / 政企客户——会觉得过分激进。
