# 25 · 唐风山水 / Tang-Landscape

> 宋元山水画 + 留白主导 + 朱印 + 竖排题字。一份"挂起来读"的后台。

## 设计立场
灵感：宋元山水画的"远山 → 中山 → 近水"墨色递进 + 题款印章美学。整页最显眼的元素是**主区顶部 240px 的远山泼墨 SVG**——4 层墨色由远而近叠在一起，左上角藏着竖排题字"本月·卷一 / 远山 *晴*"，右上有一颗朱砂落日，下方 80px 处压一颗"北"字朱印。

与 10·樱与墨、22·鎏金、05·信笺的明确区分：
- 10·樱与墨：和纸罫线 + 单点樱粉，**没有山水**；
- 22·鎏金：深松石绿 + 鎏金细线，**有金无墨**；
- 05·信笺：米黄信纸 + 横排公函，**没有题款画意**；
- 25·唐风山水：**真有远山 SVG 画 + 红日 + 鸟点 + 印章 + 竖排题字**，整页气质是"挂在书房墙上的小幅水墨"。

## 配色
| 角色 | 取值 |
| --- | --- |
| 宣纸 | `#F4EFE4` |
| 次纸 | `#EAE3D2` |
| 主墨 | `#1F1B17` |
| 次墨 | `#5A5448` |
| 远山苔绿 | `#5D7D5A` |
| 远水靛青 | `#3D4E63` |
| **朱印** | `#A8362C`（仅作"主"印 + 落日 + 强调）|

整页用墨色递进（黑 75% → 灰 55% → 浅灰 45% → 极浅 35%）画远近，色彩极度克制。

## 字体
- 主显示 / 题字：**Source Han Serif SC**（思源宋体）
- 数据 / 时间戳 / 端点：JetBrains Mono
- 标签 / Eyebrow：Inter（极小号 + 字间距 0.22em）

H1/题字字号普遍中等（30px 竖排），不像 22·鎏金那种 56px 大字——本套靠**留白**而不是字号制造视觉。

## 布局
- 220px 边栏：顶部一颗竖长条朱砂"北"印章（44×58，writing-mode 竖排），分区标题单字"总 / 资 / 账"+ 字间距 0.5em
- 顶 status 一行很细的 toolbar：`控制台 · 仪表盘` 左对齐，时间右对齐
- **远山 SVG 横幅**：4 层 path 层叠模拟泼墨远近 + 一颗朱砂红日 + 几只"q5,-6 10,0 q5,-6 10,0"鸟点 + 竖排题字 + 朱印
- 主区一段 16px 抒情段落（"过往三十日… 谨呈台览"，混用 "增一成二"、"五厘"、"十一日后" 等汉字数词）
- KPI 4 列极简：宋体 38px 大数字，列间细虚线分隔
- 主区两栏：流水 + 名册（每个角色对应汉字单字"主 管 研 阅"）+ 账目（合计 32px 朱砂宋体）

## 签名元素
1. **远山泼墨 SVG**——4 层 `<path>` 黑色不同透明度叠加 + 朱砂落日 + 鸟点
2. **竖排题字**：`writing-mode:vertical-rl`，"远山 *晴*" 三字直立题在画面左上
3. **竖长条朱砂印章**（44×58 竖框 + 内套 0.5px 细边 + 浅红径向辉光）
4. **汉字数词文案**：本套和 22·鎏金一样使用"增一成二、五厘、十一日后"等古文数词，但**只用汉字不杂英文**

## 适用场景
书画 / 茶道 / 文房四宝 / 高端中式餐饮 / 私人会所 / 中医药 / 国学教育等。**不适合**：开发者工具、运维监控、年轻 To-C SaaS。
