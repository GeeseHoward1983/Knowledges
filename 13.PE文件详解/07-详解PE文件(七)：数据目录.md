# 详解PE文件(七)：数据目录

> 来源：[CSDN 原文](https://blog.csdn.net/geesehoward20000/article/details/154742543)　｜　发布：2025-11-18　｜　合集《PE文件详解》第 7/26 篇

> [!tip] 一句话核心
> 数据目录是 [[06-详解PE文件(六)：可选头|可选头]] 末尾的一个**16 项数组**，每项只有两个字段：`(VirtualAddress, Size)`——即"**某张功能表在哪、有多大**"。它是 PE 的"总目录"：导入表、导出表、资源表、重定位表……全都靠这 16 个指针来定位。**本篇是整个合集的枢纽**，下面每一项都链到对应详解。

> [!info] 速查
> - **结构体**：`IMAGE_DATA_DIRECTORY`（仅 `VirtualAddress` + `Size` 两个 DWORD）
> - **数量**：16 项（`IMAGE_NUMBEROF_DIRECTORY_ENTRIES`）
> - **位置**：可选头末尾（32 位距可选头起点 `0x60`，64 位 `0x70`）
> - **本质**：一组 (RVA, 大小) 指针，指向散落在各节里的功能表

数据目录是可选头的最后一个成员。它为 PE 加载器提供关键索引，帮助其定位和加载 PE 文件中的各种重要数据结构。

## 数据目录结构

数据目录由 `IMAGE_DATA_DIRECTORY` 结构组成，该结构非常简单，仅包含两个字段：

```c
typedef struct _IMAGE_DATA_DIRECTORY {
    DWORD   VirtualAddress;  // 相对虚拟地址（RVA）
    DWORD   Size;            // 大小（以字节为单位）
} IMAGE_DATA_DIRECTORY, *PIMAGE_DATA_DIRECTORY;
```

- `VirtualAddress`：指向目标数据结构起始位置的 **RVA**（相对虚拟地址）
- `Size`：该数据结构的大小（字节）

> [!note] 这里的地址是 RVA，不是文件偏移
> 数据目录里的 `VirtualAddress` 是 **RVA（相对于 ImageBase 的偏移）**，不是文件偏移。要在磁盘文件里定位这张表，必须借助 [[24-详解PE文件(二十四)：节表|节表]] 做 "RVA → 文件偏移" 的换算。这一步是手写 PE 解析器的必经环节。

## 数据目录在 PE 文件中的位置

数据目录位于可选头的末尾，紧跟其它可选头字段之后：在 32 位 PE 中从可选头起点偏移 `0x60` 处开始；在 64 位 PE32+ 中从偏移 `0x70` 处开始（因 [[06-详解PE文件(六)：可选头|ImageBase 等字段变宽]]）。

```text
可选头 IMAGE_OPTIONAL_HEADER
┌───────────────────────────┐
│ Magic / 入口点 / ImageBase │
│ 对齐 / 子系统 / ...        │
├───────────────────────────┤ ← 0x60(32位) / 0x70(64位)
│ DataDirectory[0]  导出表   │ (RVA,Size)
│ DataDirectory[1]  导入表   │ (RVA,Size)
│ ......                     │
│ DataDirectory[15] 保留     │ (RVA,Size)
└───────────────────────────┘
每项 8 字节 × 16 = 128 字节
```

## 实际示例

在十六进制编辑器中查看 PE 文件时，数据目录部分通常如下所示：

> [!example] 十六进制中的数据目录
> ```
> Offset      Content           Description
> 000000E0                      Optional Header末尾开始
> 000000E0    00 10 00 00       数据目录[0] VirtualAddress = 0x1000
> 000000E4    3C 02 00 00       数据目录[0] Size = 0x23C
> 000000E8    00 20 00 00       数据目录[1] VirtualAddress = 0x2000
> 000000EC    54 01 00 00       数据目录[1] Size = 0x154
> 000000F0    00 30 00 00       数据目录[2] VirtualAddress = 0x3000
> 000000F4    FC 00 00 00       数据目录[2] Size = 0xFC
> ...
> ```
> 每 8 字节为一项：前 4 字节是 RVA，后 4 字节是大小。`VirtualAddress = 0` 表示该项不存在。

## 编程访问数据目录

以下是一个简单的 C 语言示例，演示如何读取数据目录：

```c
#include <windows.h>
#include <stdio.h>
#include <winnt.h>

void PrintDataDirectories(const char* filename) {
    HANDLE hFile = CreateFile(filename, GENERIC_READ, FILE_SHARE_READ,
                              NULL, OPEN_EXISTING, FILE_ATTRIBUTE_NORMAL, NULL);

    if (hFile == INVALID_HANDLE_VALUE) {
        printf("无法打开文件: %s\n", filename);
        return;
    }

    HANDLE hMapping = CreateFileMapping(hFile, NULL, PAGE_READONLY, 0, 0, NULL);
    if (!hMapping) {
        printf("创建文件映射失败\n");
        CloseHandle(hFile);
        return;
    }

    LPVOID lpBase = MapViewOfFile(hMapping, FILE_MAP_READ, 0, 0, 0);
    if (!lpBase) {
        printf("映射文件失败\n");
        CloseHandle(hMapping);
        CloseHandle(hFile);
        return;
    }

    // 获取DOS头
    IMAGE_DOS_HEADER* dosHeader = (IMAGE_DOS_HEADER*)lpBase;

    // 验证DOS签名
    if (dosHeader->e_magic != IMAGE_DOS_SIGNATURE) {
        printf("不是有效的PE文件\n");
        UnmapViewOfFile(lpBase);
        CloseHandle(hMapping);
        CloseHandle(hFile);
        return;
    }

    // 获取NT头
    IMAGE_NT_HEADERS* ntHeaders = (IMAGE_NT_HEADERS*)((BYTE*)lpBase + dosHeader->e_lfanew);

    // 验证PE签名
    if (ntHeaders->Signature != IMAGE_NT_SIGNATURE) {
        printf("不是有效的PE文件\n");
        UnmapViewOfFile(lpBase);
        CloseHandle(hMapping);
        CloseHandle(hFile);
        return;
    }

    // 获取数据目录
    IMAGE_DATA_DIRECTORY* dataDirs = ntHeaders->OptionalHeader.DataDirectory;

    // 打印数据目录信息
    printf("=== 数据目录信息 ===\n");
    const char* dirNames[] = {
        "导出表", "导入表", "资源表", "异常表", "安全目录", "基址重定位表",
        "调试信息", "体系结构数据", "全局指针", "TLS目录", "加载配置",
        "绑定导入", "IAT", "延迟导入", "COM描述符", "保留"
    };

    for (int i = 0; i < 16; i++) {
        if (dataDirs[i].VirtualAddress != 0) {
            printf("数据目录[%d] %s:\n", i, dirNames[i]);
            printf("  RVA: 0x%08X\n", dataDirs[i].VirtualAddress);
            printf("  大小: 0x%08X (%d 字节)\n", dataDirs[i].Size, dataDirs[i].Size);
            printf("\n");
        }
    }

    UnmapViewOfFile(lpBase);
    CloseHandle(hMapping);
    CloseHandle(hFile);
}
```

## 几张最常打交道的表

> [!example] 高频数据目录速览
> - **导出表**（[[09-详解PE文件(九)：导出表]]）：模块向外提供的函数/变量，主要用于 DLL。
> - **导入表**（[[08-详解PE文件(八)：导入表]]）：需要从别的 DLL 拿哪些函数；加载器据此解析外部地址。
> - **资源表**（[[10-详解PE文件(十)：资源表]]）：图标、位图、字符串表、对话框模板等。
> - **基址重定位表**（[[13-详解PE文件(十三)：基址重定位表]]）：无法加载到首选基址时，提供需修正的地址。
> - **导入地址表 IAT**（[[20-详解PE文件(二十)：导入地址表]]）：导入表的"落地"形式，加载时被填入真实函数地址。

> [!summary] 小结
> 数据目录是 PE 的"总目录"：16 个 `(RVA, Size)` 指针，分别指向导出/导入/资源/重定位/调试/TLS/加载配置等功能表。加载器靠它快速定位各结构，而我们靠它（配合 [[24-详解PE文件(二十四)：节表|节表]] 的 RVA 换算）逐表深入。它的上游是 [[06-详解PE文件(六)：可选头|可选头]]，下游是接下来的 08～23 共 16 篇——本篇就是它们的索引页。
